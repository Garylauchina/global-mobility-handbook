# 日本

[返回“数字游民与远程工作”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

> **待补证事项：** 外务省与该名单未载日本主体报酬完整禁止条文；需入管厅活动定义正文补证

## Digital Nomad

- **当前状态：** 开放/限国籍
- **申请者身份限制：** 限入管厅名单中的国籍／地区，主申请人与同行配偶、子女使用不同名单；中国大陆普通护照不在主申请人名单，外国永久居留不能替代国籍条件。主申请人名单含香港、台湾，不能据此把澳门或家属名单自动套用于主申请人。须为境外机构远程工作或向境外客户提供服务。见[官方资格名单](https://www.moj.go.jp/isa/content/001416932.pdf)。
- **最低门槛或收入：** 年收入≥¥10m；医疗保险保额≥¥10m
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 6个月，不可续
- **居住与续签：** 最长6个月且不可延长，不是直接永住安排
- **当地工作：** 不得从日本主体取得报酬
- **家属：** 配偶、子女可随行
- **永居或入籍路径：** 6个月且不可续的专项停留不提供直接永住路径
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 主申请人与随行配偶/子女分别适用官方国籍或地区名单；中国大陆普通护照不在名单。随行家属也须具备至少¥10m医疗保额
- **证据等级：** B
- **主要来源：** [日本外务省专项签证](https://www.mofa.go.jp/ca/fna/pagewe_000001_00046.html)；[出入国在留管理厅主申请人及家属名单](https://www.moj.go.jp/isa/content/001416932.pdf)
