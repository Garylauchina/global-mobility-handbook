# 哥斯达黎加

[返回“数字游民与远程工作”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

> **待补证事项：** 同一主管项目站仍列两个家庭收入金额，需要DGME确认具体标准，不能宣称门槛已完全核验

## Digital Nomads

- **当前状态：** 开放/金额冲突
- **申请者身份限制：** 面向向境外个人或法人提供远程服务并获境外报酬的外国人，不能用哥斯达黎加本地工作替代。所引官方项目页未列完整国籍排除清单；是否需先办入境签证仍须按护照对应规则核对。
- **最低门槛或收入：** 单人US$3,000/月，须提供过去一年境外收入证明；同一官方站详细申请/续期页带家属为US$4,000，宣传首页为US$5,000，递件前书面确认
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 最长1年，可再续1年；可申请少于1年的期限
- **居住与续签：** 续签须在哥斯达黎加累计停留至少80天，并再次提交收入及全程保险；Estancia不等同普通居留卡
- **当地工作：** 不得进入当地劳动力市场
- **家属：** 配偶/同居伴侣、未满25岁未婚子女、任何年龄残障子女及符合亲属/共同生活证明的长者可申请；须分别提交材料及保险
- **永居或入籍路径：** 不通PR
- **税务提示：** 官方专项说明称数字游民不按普通税务居民处理并豁免该安排下所得税义务；其他收入及其他国家税籍仍须分别判断
- **关键限制与变化：** 家属4000/5000冲突可在同一官方站复现；全程医疗保额至少US$50,000，家属亦须覆盖
- **证据等级：** B
- **主要来源：** [官方项目首页](https://www.visitcostarica.com/digital-nomads)；[详细申请](https://www.visitcostarica.com/digital-nomads/requirements)；[续签](https://www.visitcostarica.com/digital-nomads/renewal)；[家属](https://www.visitcostarica.com/digital-nomads/requirements-for-dependents)；[税务说明](https://www.visitcostarica.com/digital-nomads/benefits)；[第10208号法期限解释](https://www.pgrweb.go.cr/DOCS/NORMAS/1/VIGENTE/L/2020-2029/2020-2024/2022/17A12/14E170.HTML)
