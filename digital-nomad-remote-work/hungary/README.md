# 匈牙利

[返回“数字游民与远程工作”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## White Card

- **当前状态：** 开放
- **申请者身份限制：** 适用于不享有EEA自由迁徙权的第三国国民，官方定义包括无国籍人；须为境外公司工作或管理合资格境外企业。不得在匈牙利从事有报酬活动，也不得持有匈牙利公司的股份；既有匈牙利身份和境内转换限制须按OIF规则分别判断。
- **最低门槛或收入：** 净€3,000/月；入境前至少6个月已达到，且整个停留期间持续满足
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 1年，可续1次，总计2年
- **居住与续签：** 最多续签一次；续签前任意180天内须在匈牙利持证居住至少90天，须在到期前90至30天内申请。不得据此获得National Residence Card
- **当地工作：** 不得在匈就业或持股本地公司
- **家属：** 原则不准家庭团聚（在匈出生子女例外）
- **永居或入籍路径：** 不是永居路径
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 原则无家庭团聚；持卡期间及到期后不得在匈牙利境内申请其他目的居留，具体例外与重新从境外申请须另核。
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.oif.gov.hu/factsheets/white-card-residency-for-digital-nomads)
