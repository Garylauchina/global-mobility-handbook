# 匈牙利

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## White Card

- **当前状态：** 开放
- **最低门槛或收入：** 净€3,000/月，申请前连续6月并持续满足
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 1年，可续1次，总计2年
- **居住与续签：** 不得转National Residence Card
- **当地工作：** 不得在匈就业或持股本地公司
- **家属：** 原则不准家庭团聚（在匈出生子女例外）
- **永居或入籍路径：** 不是永居路径
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 期限短且无家属团聚
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.oif.gov.hu/factsheets/white-card-residency-for-digital-nomads)
- **本条核验日期：** 2026-09-02
