# 匈牙利

> **待补证事项：** White Card持有人在匈远程工作所得的税务居民、收入来源及申报规则尚缺税务机关依据

> **复核警示：** 本页尚未完成本轮定期复核；在完成主管机关复核前，不应视为当前开放规则。

## White Card

- **当前状态：** 待复核（原记录：开放）
- **状态说明：** 开放
- **申请者身份限制：** 适用于不享有EEA自由迁徙权的第三国国民，官方定义包括无国籍人；须为境外公司工作或管理合资格境外企业。不得在匈牙利从事有报酬活动，也不得持有匈牙利公司的股份；不适用于享有EEA自由迁徙权的家属；既有学生、保护或其他工作身份还受下列排除规则限制。
- **最低门槛或收入：** 净€3,000/月；入境前至少6个月已达到，且整个停留期间持续满足
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 1年，可续1次，总计2年
- **居住与续签：** 最多续签一次；续签前任意180天内须在匈牙利持证居住至少90天，须在到期前90至30天内申请。不得据此获得National Residence Card
- **当地工作：** 不得在匈就业或持股本地公司
- **家属：** 原则不准家庭团聚（在匈出生子女例外）
- **永居或入籍路径：** 不是永居路径
- **税务提示：** 【待核实】专项居留不自动决定税务身份；该国对在境内履行远程工作的税务居民判定、收入来源及申报义务尚缺当前税务机关依据，不能据本页认定免税或无需登记。
- **关键限制与变化：** 原则无家庭团聚；持卡期间及到期后不得在匈牙利境内申请其他目的居留，具体例外与重新从境外申请须另核。
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://www.oif.gov.hu/factsheets/white-card-residency-for-digital-nomads)

## 既有身份与递件地点

OIF明确排除符合guest self-employment、guest investor、投资就业、就业、guest worker、National/Hungarian/Corporate Card条件者，以及学生或其受监督短期实习者、派遣者、保护申请人或获保护者、容忍身份或暂缓驱逐者、EC长期居留/EU residence card持有人、公司内部调派及高技能就业入境者。不是仅有境外工资就能从这些身份转入。

无现有居留且属于须签证国籍的申请人须从境外递件；无居留的免签国籍可在合法停留期间境内申请。续期须在境内通过Enter Hungary提交。
