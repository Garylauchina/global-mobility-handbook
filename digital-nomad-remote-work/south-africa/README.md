> **待补证事项：** 家属各办访问身份的当前官方手续尚未补证；专项清单未覆盖

## Remote Work Visitor’s Visa

- **当前状态：** 开放
- **最低门槛或收入：** 毛薪≥ZAR650,796/年
- **资金或收入性质：** 外国雇主收入
- **首次身份与期限：** 超过3个月，最长3年
- **居住与续签：** Visitor’s visa不形成PR资格
- **当地工作：** 仅外国雇主；是否接受纯自由职业不明确
- **家属：** 家属各办相应访问身份
- **永居或入籍路径：** 不计PR
- **税务提示：** 如是与南非有有效双重征税协定国家的税务居民，任意12个月在南非累计超过183天须向SARS登记；其他申请人须登记。登记条件不等于最终纳税义务判定。
- **关键限制与变化：** 须外国雇主签署合同及最近3个月资金证明；境内不得变更签证身份，访客签证法定特殊情形除外。
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://www.dha.gov.za/images/notices/8october24/Remote_Work_Visa_-_requirements_-_9_Oct_2024.pdf)
