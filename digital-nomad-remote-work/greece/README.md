## Digital Nomad Visa / Residence Permit Z.1

- **当前状态：** 开放
- **最低门槛或收入：** 净€3,500/月；配偶+20%，每子女+15%
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** D签最长12月；随后居留2年可续
- **居住与续签：** 长期路径需实际连续居住
- **当地工作：** 不得进入希腊劳动力市场
- **家属：** 可随行
- **永居或入籍路径：** 居留许可原则可累计5年长期居民、7年入籍，但须真实居住/融入
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 不能把低居住营销等同永居路径
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.mfa.gr/services/working-in-greece-as-a-digital-nomad/)
- **本条核验日期：** 2026-09-02
