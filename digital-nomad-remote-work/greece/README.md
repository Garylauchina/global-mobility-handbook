# 希腊

[返回“数字游民与远程工作”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

> **待补证事项：** 5年长期居民、7年国籍及Z.1具体计期/离境规则缺完整当前法源，尚未形成全页闭环

## Digital Nomad Visa / Residence Permit Z.1

- **当前状态：** 开放
- **申请者身份限制：** 面向非EU／EEA／瑞士的第三国远程工作者；EU／EEA／瑞士人士应区分其自由迁徙规则。须证明境外雇主、客户或企业关系，不得以本地雇佣关系满足本路线；完整特别国籍限制仍须结合领馆与入境规定判断。
- **最低门槛或收入：** 净€3,500/月；配偶+20%，每子女+15%
- **资金或收入性质：** 境外远程薪资，或足以支持居住期间的资金；工资门槛按税后净额，需境外工作/业务证明
- **首次身份与期限：** D签最长12月；随后居留2年可续
- **居住与续签：** 长期路径需实际连续居住
- **当地工作：** 不得进入希腊劳动力市场
- **家属：** 配偶或同居伴侣及子女可随行，收入依次加20%及每子女15%；不得为希腊本地雇主工作
- **永居或入籍路径：** 居留许可原则可累计5年长期居民、7年入籍，但须真实居住/融入
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 外交部导向Work from Greece官方项目站；续签居留每次2年，长期居民及国籍的年限与该身份具体衔接仍须补法规依据
- **证据等级：** B
- **主要来源：** [外交部专项入口](https://www.mfa.gr/services/working-in-greece-as-a-digital-nomad/)；[外交部指定官方项目站](https://workfromgreece.gr/)；[移民部第6号实施通函](https://migration.gov.gr/wp-content/uploads/2024/10/6%CE%95%CE%B3%CE%BA%CF%8D%CE%BB%CE%B9%CE%BF%CF%82-3JUN2024-%CE%BD_5038_2023-%CE%B7-1%CE%B7-%CE%BC%CE%B5%CE%B3%CE%B1%CE%BB%CE%B7-%CE%9D%CF%8C%CE%BC%CE%BF%CF%85.pdf)
