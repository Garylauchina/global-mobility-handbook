## Digital Nomad long-stay visa / residence

- **当前状态：** 待复核（原记录：开放）
- **状态说明：** 开放
- **申请者身份限制：** 【部分待核实】须证明境外公司雇佣或符合条件的境外公司经营身份及远程工作性质；本页所引移民机关条款未列出完整国籍排除名单。公司所在国、本人国籍与目前合法居留地须分别核对，不能据海外收入认定任意身份均可办理。
- **最低门槛或收入：** 申请前6月及许可期内≥罗马尼亚全国平均毛薪3倍
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 先取得90日长期签证，入境后首次数字游民居留许可为6个月；后续可续，须持续满足收入等条件
- **居住与续签：** 实际连续居住才可能累计5年长期居留
- **当地工作：** 仅境外雇主/自有境外公司
- **家属：** 家属走普通团聚
- **永居或入籍路径：** 原则可累计长期居留，但建议IGI书面确认
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 自有境外公司路线要求申请签证前已持有公司至少3年；后续续签另须主管税务机关收入证明。特定境外雇佣收入的税务待遇需按实际停留和税法另核。
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://igi.mai.gov.ro/alte-scopuri/)
