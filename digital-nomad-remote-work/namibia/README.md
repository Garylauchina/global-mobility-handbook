## Digital Nomad Visa

- **当前状态：** 开放
- **最低门槛或收入：** 主申US$2,000/月；配偶+US$1,000/月；每子女+US$500/月
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 6个月，不可续
- **居住与续签：** 到期12个月后才可重申
- **当地工作：** 仅境外公司/客户
- **家属：** 配偶和未成年子女
- **永居或入籍路径：** 短期签证，不计PR
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 无专项免税承诺
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.nipdb.com/digital-nomad-visa)
- **本条核验日期：** 2026-09-02
