# 阿根廷

> **待补证事项：** 现行完整旅游免签国家范围及第三国签证便利与专项身份的适用边界尚未逐项闭合；专项家属另行申请的具体身份依据未补齐；阿根廷税务居民判定、境内履行远程服务的所得来源及申报义务未取得当前税务机关依据

> **复核警示：** 本页尚未完成本轮定期复核；在完成主管机关复核前，不应视为当前开放规则。

## Residencia transitoria — Nómada digital

- **当前状态：** 待复核（原记录：开放）
- **状态说明：** 开放
- **申请者身份限制：** 只适用于其国籍所属国家获免旅游签证待遇的外国人，依据Disposición 758/2022第1条；须向境外个人或法人远程提供服务。持第三国签证而获入境便利，不应直接解释为满足“免签国家国民”条件。
- **最低门槛或收入：** 无统一数额；证明境外远程工作和足够资金
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 180天，可续1次180天
- **居住与续签：** 续签前须在境内停留原期限至少50%
- **当地工作：** 仅境外主体
- **家属：** 无统一家庭包
- **永居或入籍路径：** 不直接通PR
- **税务提示：** 【待核实】专项居留不自动决定税务身份；该国对在境内履行远程工作的税务居民判定、收入来源及申报义务尚缺当前税务机关依据，不能据本页认定免税或无需登记。
- **关键限制与变化：** 仅限凭国籍可免旅游签证进入阿根廷的外国人；持其他国家签证获得的便利不能直接替代国籍条件。短期身份不得与投资入籍混淆
- **证据等级：** B
- **主要来源：** [移民局现行申请说明](https://www.argentina.gob.ar/servicio/obtener-una-residencia-transitoria-como-nomada-digital)；[DNM第758/2022号规定全文](https://www.argentina.gob.ar/normativa/nacional/disposici%C3%B3n-758-2022-364601/texto)
