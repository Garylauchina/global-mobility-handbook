## Single Permit for digital mobile workers

- **当前状态：** 开放
- **最低门槛或收入：** 银行存款≥ALL300,000/人/年，或月收入≥ALL32,000/人
- **资金或收入性质：** 境外合同收入/存款
- **首次身份与期限：** 初次1年，按条件续
- **居住与续签：** 连续合法居留可累计长期身份
- **当地工作：** 只按境外合同远程，不得超越许可目的本地工作
- **家属：** 可家庭团聚
- **永居或入籍路径：** 连续合法居留5年可申请永久居留（受缺席限制）
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 金额低但审批仍审查保险、住址和真实合同
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://mb.gov.al/en/procedura-dhe-dokumentacioni-per-pajisjen-me-leje-qendrimi-dhe-leje-unike-residence-unique-permit-al-en/)
- **本条核验日期：** 2026-09-02
