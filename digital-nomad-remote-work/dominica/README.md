# 多米尼克

[返回“数字游民与远程工作”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Work in Nature Visa

- **当前状态：** 开放
- **申请者身份限制：** 【部分待核实】主申请人须年满18岁并符合远程工作、收入与良好品格要求；WIN与投资入籍是不同项目，不能直接套用CBI的受限国籍名单。当前WIN公开来源未确认完整的特别国籍限制。
- **最低门槛或收入：** 预计未来12个月收入US$50,000或有足够资金
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 最长18个月
- **居住与续签：** 不直接通PR
- **当地工作：** 只能为非多米尼克主体远程工作
- **家属：** 配偶/伴侣、未成年子女及特定受养亲属
- **永居或入籍路径：** 不直接通PR
- **税务提示：** 官方WIN规则给予合资格远程工作者所得税豁免；持有人仍须履行通常税收居民地或税务住所地的所得税义务，不能理解为全球免税。
- **关键限制与变化：** 与多米尼克投资入籍为完全不同产品
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://windominica.gov.dm/component/content/category/8-program-details)
