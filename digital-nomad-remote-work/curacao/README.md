## @HOME in Curaçao — Remote Worker

- **当前状态：** 待复核（原记录：开放）
- **最低门槛或收入：** 证明足够境外收入，无统一固定数字
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 6个月，可再延6个月，最多1年
- **居住与续签：** 不通PR
- **当地工作：** 不得进入当地劳动力市场
- **家属：** 可随行，但每人分别递交、分别收费；12岁及以上家属须签署申请
- **永居或入籍路径：** 不通PR
- **税务提示：** 项目官方FAQ称该远程工作安排不要求缴纳库拉索所得税；原居住国及其他收入税务仍须另判

- **证据等级：** B
