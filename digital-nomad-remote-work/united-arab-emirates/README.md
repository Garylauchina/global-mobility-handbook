## Virtual Work Residence Visa

- **当前状态：** 开放
- **最低门槛或收入：** US$3,500/月或等值；健康保险和境外工作证明
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 远程工作居留1年可续；入境许可先给60天办理居留手续
- **居住与续签：** 无传统PR/入籍计时
- **当地工作：** 只能为境外组织工作；UAE实体任职需另签证
- **家属：** 可担保同期限家属居留，仍须满足家属申请材料条件
- **永居或入籍路径：** 不通PR或入籍
- **税务提示：** 工资不属于UAE企业税下的经营所得；个人在UAE开展业务且年营业额超过AED1m时可能纳入企业税，具体与原税籍分别判断
- **关键限制与变化：** GDRFA要求境外组织远程工作证明、月入US$3,500、保险和体检；工资豁免不代表公司、经营收入或境外税籍一概免税
- **证据等级：** A
- **主要来源：** [GDRFA远程工作居留](https://gdrfad.gov.ae/en/services/f52024e3-b812-11ed-5210-4cd98f768936)；[GDRFA入境与家属规定](https://gdrfad.gov.ae/en/services/64154a31-ec6d-11ec-140b-0050569629e8)；[FTA自然人企业税](https://tax.gov.ae/en/taxes/corporate.tax/corporate.tax.topics/basis.of.taxation.natural.person.aspx)
