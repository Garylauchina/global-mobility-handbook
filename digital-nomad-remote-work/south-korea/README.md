# 韩国

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Workcation / Digital Nomad Visa

- **当前状态：** 开放
- **申请者身份限制：** 【部分待核实】须按Workcation的境外经营／工作及同行业经历条件判断；青年和地区优惠中的年龄、住所与携家属条件会改变适用档位。本次未完整取得当前特别国籍及境内转换条款，不能将优惠年龄分档或免签入境名单当作申请国籍白名单。
- **最低门槛或收入：** 按年龄、居住地区和是否携家属适用上一年度GNI的1至2倍；现行2025年GNI为KRW52,416,000，适用于2026-04-01至2027-03-31。具体最低年收入见下表；同一行业须至少1年，医疗保险须满足至少KRW100m及递件馆清单
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 首次1年，按年续期；2026-06-30起最长合计3年
- **居住与续签：** 按年审查续期，最长3年；采用地方优惠门槛者须提交规定地区的住宿或工作度假预订证明
- **当地工作：** 不得在韩国本地受雇或从事本地营利活动；以境外公司远程工作为基础
- **家属：** 配偶及未成年子女可随行；携家属时不适用单人青年最低档，首都圈为2倍GNI、地方优惠区为1.5倍
- **永居或入籍路径：** 不直接通PR
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 2026-06-30起新增青年及地区分档并延长总停留上限；首都圈指首尔、仁川、京畿，地方优惠亦涵盖指定人口减少地区。GNI按年度更新，须按年龄、家庭与地址选档
- **证据等级：** A
- **主要来源：** [法务部原始制度说明](https://www.moj.go.kr/bbs/immigration_eng/229/464290/download.do)；[驻德国使馆2026年变更说明](https://overseas.mofa.go.kr/de-de/wpge/m_7236/contents.do)；[驻圣彼得堡总领馆2026年完整门槛表](https://overseas.mofa.go.kr/ru-stpetersburg-ru/brd/m_7886/view.do?page=1&seq=759308)

## 现行收入分档

| 申请情形 | 首都圈最低年收入 | 地方优惠区最低年收入 |
| --- | --- | --- |
| 18–34岁单人申请 | KRW78,624,000（1.5倍GNI） | KRW52,416,000（1倍GNI） |
| 35岁及以上单人申请 | KRW104,832,000（2倍GNI） | KRW78,624,000（1.5倍GNI） |
| 携配偶或未成年子女，主申请人年龄不限 | KRW104,832,000（2倍GNI） | KRW78,624,000（1.5倍GNI） |

地方优惠需证明实际住宿安排；门槛表不替代雇佣、行业经历、保险及无犯罪材料。

## 政策时间线

### 2026-06-30｜收入门槛分档及最长停留延长

- **事件类型：** 已生效政策调整
- **变化内容：** 新增青年、地区及携家属收入分档，最长停留由2年增至3年；仍按年办理续期。
- **适用范围：** Workcation / Digital Nomad Visa 申请与续期，按年龄、家庭及地区分别审查。
- **事件证据：** 韩国驻德国使馆现行签证说明及驻圣彼得堡总领馆2026-07-01公告。
- **来源：** [驻德国使馆](https://overseas.mofa.go.kr/de-de/wpge/m_7236/contents.do)；[驻圣彼得堡总领馆](https://overseas.mofa.go.kr/ru-stpetersburg-ru/brd/m_7886/view.do?page=1&seq=759308)
