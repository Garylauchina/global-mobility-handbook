## Digital Nomad temporary residence permit

- **当前状态：** 开放
- **申请者身份限制：** 适用于非EU／EEA的外国远程工作者，境外雇佣、民事服务合同或境外自雇须符合官方定义；可在驻外机构申请，已合法停留者可按规定在境内提出申请。境内递交资格取决于合法停留事实，不能仅凭境外远程收入推定可转换身份。
- **最低门槛或收入：** 月资金≥最近公布平均净薪2倍
- **资金或收入性质：** 须从事境外远程活动；生活资金证明可来自任何合法收入来源
- **首次身份与期限：** 最长1年，不可续
- **居住与续签：** 届满6个月后才可重申
- **当地工作：** 仅境外雇主/客户
- **家属：** 直系家属可团聚
- **永居或入籍路径：** 仅反复使用本专项因不可续签及6个月间隔，不当然形成连续5年路径；官方允许在有效期内另申请其他目的临时居留，转类后的长期资格需另核
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 动态薪资公式须递件前更新
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.gov.si/en/news/2025-11-21-temporary-residence-permit-for-digital-nomads/)
