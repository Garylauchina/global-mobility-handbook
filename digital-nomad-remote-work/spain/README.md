# 西班牙

[返回“数字游民与远程工作”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## International Teleworker

- **当前状态：** 开放
- **最低门槛或收入：** 主申200% SMI；2026约€2,442/月；首家属+75%，其后每人+25%
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 境外签证通常1年；境内居留3年，续2年
- **居住与续签：** 实际居住可累计长期身份
- **当地工作：** 雇员仅境外雇主；自雇可有西班牙客户但≤总业务20%
- **家属：** 可随行
- **永居或入籍路径：** 合法居留5年永居；一般入籍10年
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 183日通常税籍；符合条件者可另评估入境者特别税制
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.exteriores.gob.es/Consulados/washington/en/ServiciosConsulares/Paginas/Consular/Telework-visa.aspx)
- **本条核验日期：** 2026-09-02
