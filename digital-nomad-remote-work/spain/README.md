# 西班牙

[返回“数字游民与远程工作”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## International Teleworker

- **当前状态：** 开放
- **最低门槛或收入：** 主申请人为最低工资（SMI）的200%；2026年为€2,442/月；第一名家属增加75%（€915.75/月），其后每人增加25%（€305.25/月）
- **资金或收入性质：** 以稳定的境外劳动或专业收入为基础；境外企业须已实际经营至少1年，申请人与企业或客户关系通常须已持续至少3个月
- **首次身份与期限：** 境外签证通常1年；境内居留3年，续2年
- **居住与续签：** 续签须继续满足工作、收入、保险和社会保障条件；连续合法居留满5年后才可能申请长期居留，长期离境会影响连续性
- **当地工作：** 受雇者只能为境外企业工作；专业或自雇人员可服务西班牙客户，但西班牙业务不得超过总专业活动的20%
- **家属：** 配偶或伴侣、未成年子女、经济依赖且未另组家庭的成年子女和受扶养尊亲属可随行；家属居留原则上允许在西班牙受雇或自雇
- **永居或入籍路径：** 连续合法居留5年后可申请长期居留，并非自动取得；一般归化基准为合法、连续且紧接申请前居留10年，特定国籍或身份另有缩短规则
- **税务提示：** 超过183天或经济利益中心在西班牙可能形成税务居民。符合条件者可另行申请入境者特别税制；签证不会自动附带该税制
- **关键限制与变化：** 须有相关学历、职业教育或至少3年专业经验；社保必须落实，受雇者仅在适用协定并取得原属国明确覆盖证明时才可能保留原体系，普通旅行险不足
- **证据等级：** A
- **主要来源：** [BOE《创业者及国际化支持法》](https://boe.es/buscar/act.php?id=BOE-A-2013-10074)；[UGE官方FAQ](https://www.inclusion.gob.es/documents/d/unidadgrandesempresas/digital-nomad-faqs-english)；[BOE 2026年SMI](https://boe.es/buscar/act.php?id=BOE-A-2026-3815)
- **本条核验日期：** 2026-09-02
