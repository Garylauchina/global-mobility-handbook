# 西班牙

[返回“数字游民与远程工作”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

> **待补证事项：** 旧页家属居留允许受雇/自雇的明确当前执行依据尚未读到；UGE附件持续超时

## International Teleworker

- **当前状态：** 开放
- **最低门槛或收入：** 主申请人为最低工资（SMI）的200%，2026为€2,442/月；第一名家属增加75%，其后每人增加25%。华盛顿领馆将家属金额向上取整列为€916及€306/月，递件按具体领馆要求
- **资金或收入性质：** 以稳定的境外劳动或专业收入为基础；境外企业须已实际经营至少1年，申请人与企业或客户关系通常须已持续至少3个月
- **首次身份与期限：** 境外签证通常1年；境内居留3年，续2年
- **居住与续签：** 续签须继续满足工作、收入、保险和社会保障条件；连续合法居留满5年后才可能申请长期居留，长期离境会影响连续性
- **当地工作：** 受雇者只能为境外企业工作；专业或自雇人员可服务西班牙客户，但西班牙业务不得超过总专业活动的20%
- **家属：** 配偶或伴侣、未成年子女、经济依赖且未另组家庭的成年子女和受扶养尊亲属可随行；家属居留原则上允许在西班牙受雇或自雇
- **永居或入籍路径：** 连续合法居留5年后可申请长期居留，并非自动取得；一般归化基准为合法、连续且紧接申请前居留10年，特定国籍或身份另有缩短规则
- **税务提示：** 自然年内超过183天，或主要经济活动/利益中心在西班牙，均可能形成税务居民；不是只按实际停留天数判断。符合条件者可另行选择入境者特别税制，签证不会自动附带
- **关键限制与变化：** 须有相关学历、职业教育或至少3年专业经验，社保覆盖须落实，普通旅行险不足；协定例外须原属国出具适用于远程工作的明确覆盖证明。华盛顿清单明确雇主/客户须商业公司，排除个人、政府及非营利组织等，应核对递件馆对象范围
- **证据等级：** B
- **主要来源：** [BOE专项居留法](https://boe.es/buscar/act.php?id=BOE-A-2013-10074)；[BOE 2026 SMI](https://boe.es/buscar/act.php?id=BOE-A-2026-3815)；[华盛顿领馆现行清单](https://www.exteriores.gob.es/Consulados/washington/en/ServiciosConsulares/Paginas/Consular/Telework-visa.aspx)；[布宜诺斯艾利斯领馆社保说明](https://www.exteriores.gob.es/Consulados/buenosaires/es/ServiciosConsulares/Paginas/index.aspx?scca=Visados&scco=Argentina&scd=40&scs=Visado+de+residencia+para+teletrabajo+%28n%C3%B3mada+digital%29)；[长期居留第32条](https://boe.es/buscar/act.php?id=BOE-A-2000-544#a32)；[民法典第22条](https://www.boe.es/buscar/act.php?id=BOE-A-1889-4763#art22)；[AEAT税务居民](https://sede.agenciatributaria.gob.es/Sede/ayuda/manuales-videos-folletos/manuales-practicos/irpf-2024/c02-irpf-cuestiones-generales/sujecion-irpf-aspectos-personales/residencia-habitual-territorio-espanol.html)；[AEAT入境者特别税制](https://sede.agenciatributaria.gob.es/Sede/ayuda/manuales-videos-folletos/manuales-practicos/irpf-2025/c02-irpf-cuestiones-generales/sujecion-irpf-aspectos-personales/regimen-fiscal-especial-aplicable-trabajadores-desplazados.html)
