# 巴拿马

## Short Stay Visa as Remote Worker

- **当前状态：** 开放
- **申请者身份限制：** 第198号行政令第1条面向与境外跨国企业有合同的外国远程雇员或自主工作者，工作效果及收入须来自境外；属于No Residente下的专项签证，不等于已获巴拿马居民身份。不得把Friendly Nations等另一项目的国籍名单套用到本签证。见[第198号行政令](https://www.migracion.gob.pa/wp-content/uploads/DECRETO_EJECUTIVO_198.pdf)。
- **最低门槛或收入：** 境外年收入B/.36,000
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 9个月，可续1次9个月
- **居住与续签：** 不通PR
- **当地工作：** 不得向巴拿马客户或企业提供服务
- **家属：** 法规无统一家庭包
- **永居或入籍路径：** 不通PR
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 短停留专项签证；家庭需单独核验
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.migracion.gob.pa/wp-content/uploads/18.REQUISITOS-PARA-SOLICITAR-VISA-DE-CORTA-ESTANCIA-COMO-TRABAJADOR-REMOTO.pdf)；[第198号行政令](https://www.migracion.gob.pa/wp-content/uploads/DECRETO_EJECUTIVO_198.pdf)
