# 保加利亚

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

> **待补证事项：** 当前受理程序、家属操作及长期身份年限计算尚未建立完整官方依据。

## Digital Nomad residence permit

- **当前状态：** 开放
- **申请者身份限制：** 须符合新增法条对境外受雇、经营或独立远程服务活动的具体定义；并非所有自称数字游民者均可申请。现有法条不足以确认完整特别国籍限制及当前身份转换细则，须由递交领馆和移民局补证。
- **最低门槛或收入：** 年毛收入须不低于保加利亚上一日历年度法定最低月工资的50倍；不得写成固定BGN50,000
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 1年，可续1次
- **居住与续签：** 最多2年，需换类别才继续累计
- **当地工作：** 雇主/公司须在EU/EEA/瑞士以外或境外客户关系≥1年；不得服务保加利亚客户
- **家属：** 家属按团聚
- **永居或入籍路径：** 不是直接永居路径
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 2025年法律新增专项，门槛按上一日历年度最低月工资公式计算；具体递件、外币换算及家属程序应向领馆和移民局确认
- **证据等级：** B
- **主要来源：** [2025年外国人法修正公报（第24с条）](https://dv.parliament.bg/DVWeb/showMaterialDV.jsp?idMat=235575)
