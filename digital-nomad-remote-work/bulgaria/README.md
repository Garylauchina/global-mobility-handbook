# 保加利亚

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Digital Nomad residence permit

- **当前状态：** 开放
- **最低门槛或收入：** 过去12月毛收入≥BGN50,000
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 1年，可续1次
- **居住与续签：** 最多2年，需换类别才继续累计
- **当地工作：** 雇主/公司须在EU/EEA/瑞士以外或境外客户关系≥1年；不得服务保加利亚客户
- **家属：** 家属按团聚
- **永居或入籍路径：** 不是直接永居路径
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 2025末实施，操作实践仍较新
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://www.parliament.bg/bg/laws/ID/166119)
- **本条核验日期：** 2026-09-02
