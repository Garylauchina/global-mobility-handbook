## DE Rantau Nomad Pass

- **当前状态：** 开放
- **最低门槛或收入：** 数字/科技从业者年收入>US$24,000；非科技类别适用更高标准
- **资金或收入性质：** 远程受雇者须有非马来西亚公司合同；自由职业者可按数字服务合同、订单或平台收入证明
- **首次身份与期限：** 3–12个月，可续至总计24个月
- **居住与续签：** 不通PR
- **当地工作：** 不能一概写成禁止本地客户：MDEC FAQ允许马来西亚公司给数字游民服务项目并担保；远程受雇者仍须为非马来西亚公司工作
- **家属：** 配偶/事实伴侣、未满18岁子女、无年龄限制的残障子女及主申请人父母；随行配偶不得工作
- **永居或入籍路径：** 不通PR
- **税务提示：** MDEC FAQ分别处理远程受雇与自由职业税务，境外付款并非免税；业务性质、实际工作及停留时间、税收协定须分别判断
- **关键限制与变化：** 原FAQ为2024年4月版；非科技扩展后当前完整收入与担保清单仍须补证。不要将半岛许可自动外推为沙巴/砂拉越工作居留
- **证据等级：** B
- **主要来源：** [MDEC原始FAQ](https://mdec.my/static/pdf/derantau/DE%20Rantau%20Pass%20FAQ-Foreign.pdf)；[MDEC扩展项目公告](https://www.mdec.my/press-releases/mdec-expands-de-rantau-programme-new-opportunities-for-global-digital-nomads-and-exciting-partnerships)
