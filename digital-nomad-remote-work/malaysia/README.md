## DE Rantau Nomad Pass

- **当前状态：** 开放
- **最低门槛或收入：** 数字/科技从业者年收入>US$24,000；非科技类别适用更高标准
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 3–12个月，可续至总计24个月
- **居住与续签：** 不通PR
- **当地工作：** 只服务境外客户/雇主
- **家属：** 配偶、伴侣、子女
- **永居或入籍路径：** 不通PR
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 科技与非科技门槛不同；须使用MDEC最新FAQ
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://mdec.my/static/pdf/derantau/DE%20Rantau%20Pass%20FAQ-Foreign.pdf)
- **本条核验日期：** 2026-09-02
