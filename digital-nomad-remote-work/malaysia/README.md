# 马来西亚

[返回“数字游民与远程工作”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

> **待补证事项：** 非科技扩展后完整现行资格/金额及担保办理细节；中国/孟加拉国银行担保的替代方式已有后续公告，见下文；砂拉越独立项目不在本页已核范围

## DE Rantau Nomad Pass

- **当前状态：** 开放
- **申请者身份限制：** MDEC外国申请人FAQ称向所有国籍开放，但以色列申请人入境须另获内政部批准。中国、孟加拉国申请人的银行担保旧要求，已被MDEC于2024-08-26宣布改为security bond或personal bond；不能继续把银行担保当作现行唯一方式。见[后续官方公告](https://www.mdec.my/media-release/news-press-release/349/de-rantau-unveils-terengganu-as-the-coastal-paradise-for-digital-nomads-seeking-tranquility-and-cultural-richness)。
- **最低门槛或收入：** 数字/科技从业者年收入>US$24,000；非科技类别适用更高标准
- **资金或收入性质：** 远程受雇者须有非马来西亚公司合同；自由职业者可按数字服务合同、订单或平台收入证明
- **首次身份与期限：** 3–12个月，可续至总计24个月
- **居住与续签：** 不通PR
- **当地工作：** 不能一概写成禁止本地客户：MDEC FAQ允许马来西亚公司给数字游民服务项目并担保；远程受雇者仍须为非马来西亚公司工作
- **家属：** 配偶/事实伴侣、未满18岁子女、无年龄限制的残障子女及主申请人父母；随行配偶不得工作
- **永居或入籍路径：** 不通PR
- **税务提示：** MDEC FAQ分别处理远程受雇与自由职业税务，境外付款并非免税；业务性质、实际工作及停留时间、税收协定须分别判断
- **关键限制与变化：** 原FAQ为2024年4月版；2024-08-26后续公告已修订中国/孟加拉国银行担保方式，非科技扩展后完整收入及担保办理清单仍须补证。不要将半岛许可自动外推为沙巴/砂拉越工作居留
- **证据等级：** B
- **主要来源：** [MDEC原始FAQ](https://mdec.my/static/pdf/derantau/DE%20Rantau%20Pass%20FAQ-Foreign.pdf)；[MDEC扩展项目公告](https://www.mdec.my/press-releases/mdec-expands-de-rantau-programme-new-opportunities-for-global-digital-nomads-and-exciting-partnerships)；[后续官方公告](https://www.mdec.my/media-release/news-press-release/349/de-rantau-unveils-terengganu-as-the-coastal-paradise-for-digital-nomads-seeking-tranquility-and-cultural-richness)

## 政策时间线

### 2024-08-26 — 中国与孟加拉国申请人的担保方式调整

- **公布与生效：** MDEC于2024-08-26公布改用security bond或personal bond，公告未单列另一生效日期
- **变化摘要：** 原银行担保要求被安全保证金或个人担保方式替代；具体提交及退还安排仍须按当前办理清单确认
- **官方依据：** [MDEC后续公告](https://www.mdec.my/media-release/news-press-release/349/de-rantau-unveils-terengganu-as-the-coastal-paradise-for-digital-nomads-seeking-tranquility-and-cultural-richness)
- **事件证据：** A
