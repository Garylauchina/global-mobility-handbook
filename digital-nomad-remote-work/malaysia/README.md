## DE Rantau Nomad Pass

- **当前状态：** 待复核（原记录：开放）
- **状态说明：** 开放
- **申请者身份限制：** MDEC 2026-08-28第10版FAQ明确面向所有国籍，但排除以色列公民，不能继续沿用旧版“另获内政部批准”的表述。主申请人须超过18岁；中国与孟加拉国适用personal/security bond，不再以银行担保为唯一方式。旅游/社交访问身份不能直接境内转换，获批后须依批准信离境再入境；EP1/EP2有效时有条件境内衔接，EP3须离境，学生身份也不能直接转换。
- **最低门槛或收入：** 科技人员年收入US$24,000、非科技人员US$60,000；总则写最低金额，材料问答仍用“>”，等于门槛者须确认
- **资金或收入性质：** 远程受雇者须有非马来西亚公司合同；自由职业者可按数字服务合同、订单或平台收入证明
- **首次身份与期限：** 3–12个月，可续至总计24个月
- **居住与续签：** 最初3–12个月，最多另续12个月；可在到期前3个月申请。批准信有效6个月，首次入境及续签获批后均须在1个月内完成e-Pass endorsement
- **当地工作：** 新版FAQ明确自由职业者可有境外及马来西亚客户；远程受雇者的雇主不得在马来西亚注册。合同须在递件前至少开始3个月，并提供对应薪单、收款和银行流水
- **家属：** 配偶/事实伴侣、未满18岁子女、无年龄限制的残障子女及主申请人父母；随行配偶不得工作
- **永居或入籍路径：** 不通PR
- **税务提示：** MDEC FAQ分别处理远程受雇与自由职业税务，境外付款并非免税；业务性质、实际工作及停留时间、税收协定须分别判断
- **关键限制与变化：** 第10版FAQ覆盖马来半岛及纳闽，沙巴/砂拉越仅能按相应旅游身份访问。Endorsement须提供有效保险、LHDN税务登记及担保材料，并留在马来西亚直至e-Pass签发；首次入境须走人工柜台取得入境章。2026-08-01起拒件不再接受appeal，仍可符合条件后重新申请。
- **证据等级：** B
- **主要来源：** [MDEC现行项目入口](https://www.mdec.my/md-programmes/digital-nomad-pass)；[第10版FAQ（2026-08-28）](https://www.mdec.my/api/media/file/DE-Rantau_Pass_FAQ_v10.pdf)；[MDEC原始FAQ](https://mdec.my/static/pdf/derantau/DE%20Rantau%20Pass%20FAQ-Foreign.pdf)；[MDEC扩展项目公告](https://www.mdec.my/press-releases/mdec-expands-de-rantau-programme-new-opportunities-for-global-digital-nomads-and-exciting-partnerships)；[后续官方公告](https://www.mdec.my/media-release/news-press-release/349/de-rantau-unveils-terengganu-as-the-coastal-paradise-for-digital-nomads-seeking-tranquility-and-cultural-richness)

## 政策时间线

### 2024-08-26 — 中国与孟加拉国申请人的担保方式调整

- **公布与生效：** MDEC于2024-08-26公布改用security bond或personal bond，公告未单列另一生效日期
- **变化摘要：** 原银行担保要求被安全保证金或个人担保方式替代；具体提交及退还安排仍须按当前办理清单确认
- **官方依据：** [MDEC后续公告](https://www.mdec.my/media-release/news-press-release/349/de-rantau-unveils-terengganu-as-the-coastal-paradise-for-digital-nomads-seeking-tranquility-and-cultural-richness)
- **事件证据：** A

### 2026-08-01 — 拒件申诉渠道停止

- **公布与生效：** MDEC第10版FAQ标注2026-08-28，明确拒件不再接受appeal自2026-08-01起适用；其他条款的最初生效日未单独公开
- **变化摘要：** 拒件后不再使用appeal渠道，满足条件者可重新申请。新版FAQ同时明确以色列公民不合资格，以及非科技类别、现有EP身份转换和endorsement要求；本站据现行全文纠正旧版摘要，不把全部条款都推定为同日新设
- **过渡安排：** FAQ未单列既有申诉的过渡处理
- **官方依据：** [MDEC第10版FAQ](https://www.mdec.my/api/media/file/DE-Rantau_Pass_FAQ_v10.pdf)
- **事件证据：** A
