## E33G — Remote Worker

- **当前状态：** 开放；移民局地方办事处公布具体资格并指向官方eVisa申请
- **最低门槛或收入：** 年薪或收入至少US$60,000，须有境外设立公司雇佣合同；另提供近3个月银行流水证明至少US$2,000生活资金
- **资金或收入性质：** 为境外公司履行远程工作职责取得的收入；并非只凭存款即可申请
- **首次身份与期限：** 1年有限居留；签证签发后通常须在90日内使用，入境时签发有限居留及再入境许可
- **居住与续签：** 官方说明允许在线续签和依法转换身份；不得超过获准停留期限，再入境须保持再入境许可有效
- **当地工作：** 用于境外公司远程工作；不得从事不符居留许可的工作或擅自销售商品、服务，不是印尼本地就业许可
- **家属：** 不自动随主申请取得身份；具体家属签证类别、担保和材料须另向移民局确认
- **永居或入籍路径：** 有限居留本身不是永久居留或国籍，不承诺自动转换
- **税务提示：** 身份本身不等于税务居民；实际天数、住所、收入来源和税收协定须独立判断
- **关键限制与变化：** 不需担保人；官方公布1年合计费用IDR7,000,000。主站个别详情页不可读，不应据此忽略地方移民局已公布的正式细则
- **证据等级：** B
- **主要来源：** [Bontang移民局：E33G完整资格和费用](https://bontang.imigrasi.go.id/public/layanan-publik/kategori/wna/sub/informasi-visa-republik-indonesia)；[印度尼西亚官方eVisa](https://evisa.imigrasi.go.id/)
