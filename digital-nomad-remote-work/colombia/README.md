# 哥伦比亚

[返回“数字游民与远程工作”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Visitor Visa — Digital Nomad

- **当前状态：** 开放
- **申请者身份限制：** Resolución 5477/2022第46条要求持由获短期免签待遇国家／地区签发的有效护照；还须属于为境外企业远程工作或合资格数字创业者。不能把第三国居留、第三国签证带来的入境便利，直接替代此处护照条件；本限制不应移植到M类投资者或养老金签证。
- **最低门槛或收入：** 最近3个月月收入≥3 SMLMV
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 最长2年
- **居住与续签：** V签证时间不计居民签证年限
- **当地工作：** 不得为哥伦比亚雇主工作
- **家属：** 可申请受益家属
- **永居或入籍路径：** 不通PR
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 仅向短期免签国家/地区所发护照持有人开放；须符合收入动态基准、境外工作证明和全程健康保险，不能把持有第三国签证的入境便利等同国籍资格。
- **证据等级：** A
- **主要来源：** [外交部现行第5477/2022号决议汇编（第46条等）](https://www.cancilleria.gov.co/normograma/compilacion/docs/resolucion_minrelaciones_5477_2022.htm)
