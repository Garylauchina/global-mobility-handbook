# 哥伦比亚

[返回“数字游民与远程工作”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

> **待补证事项：** 第5488/2022号决议列有附条件及按第三国永久居留取得的短期免签情形；这些情形如何适用于第5477/2022号决议第46条数字游民护照资格，仍须签证主管机关确认，不能笼统判断相关申请人全部可办或全部不可办。

## Visitor Visa — Digital Nomad

- **当前状态：** 开放/免签护照资格须分情形核对
- **申请者身份限制：** 第5477/2022号决议第46条要求短期免签国家／地区签发的护照，并符合境外远程工作或数字创业条件。但所引用的第5488/2022号决议还包含中国等国的附条件免签，以及按特定第三国永久居留取得的短停免签；不能把所有情况压缩成单一国籍白名单。这些附条件情形是否满足第46条的数字游民护照要求，尚需主管机关确认，不作一律可办或不可办的结论。见[现行免签决议第3–5条](https://www.cancilleria.gov.co/normograma/compilacion/docs/resolucion_minrelaciones_5488_2022.htm)。
- **最低门槛或收入：** 最近3个月月收入≥3 SMLMV
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 最长2年
- **居住与续签：** V签证时间不计居民签证年限
- **当地工作：** 不得为哥伦比亚雇主工作
- **家属：** 可申请受益家属
- **永居或入籍路径：** 不通PR
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 须结合数字游民第46条和现行免签决议判断身份；附条件入境免签能否满足本项目要求尚待确认，不能只看护照国家名称。收入动态基准、境外工作证明和全程健康保险仍须满足
- **证据等级：** B
- **主要来源：** [外交部现行第5477/2022号决议汇编（第46条等）](https://www.cancilleria.gov.co/normograma/compilacion/docs/resolucion_minrelaciones_5477_2022.htm)；[现行第5488/2022号免签决议及后续修订](https://www.cancilleria.gov.co/normograma/compilacion/docs/resolucion_minrelaciones_5488_2022.htm)

## 国籍与附条件免签

第5488号决议第3(C)条将柬埔寨、印度、尼加拉瓜、缅甸、中国、泰国、台湾及越南列为附条件短停免签对象：持有效的美国或申根成员国居留许可，或在入境时仍有至少180天有效期的美国／申根签证，可按该条获准免签短停；此处居留许可并未一概限定为永久居留。第4、5条还分别涉及太平洋联盟、安第斯共同体成员国的第三国永久居民。上述是已核实的短停入境规则，其对数字游民签证资格的适用仍须另确认。[现行免签决议](https://www.cancilleria.gov.co/normograma/compilacion/docs/resolucion_minrelaciones_5488_2022.htm)
