# 毛里求斯

> **待补证事项：** 专项文件未证实子女24岁上限，已移除固定年龄；20年PR衔接仍需正式依据

## Premium Visa

- **当前状态：** 开放
- **最低门槛或收入：** 每名成人US$1,500/月；每名受养子女US$500/月
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** >6个月至1年，可续
- **居住与续签：** 长住签证，不直接计入20年PR
- **当地工作：** 不得进入毛里求斯劳动力市场
- **家属：** 配偶及受养子女可随行；现有专项清单未给统一子女年龄上限，须按签发机关审核
- **永居或入籍路径：** 不直接通PR；可转换其他许可
- **税务提示：** MRA专项FAQ按汇入处理：外国信用卡/借记卡支出不视为汇入；汇入本地银行的收入通常应税，但可就原属国或居住国已纳税收入提交PV1声明。既有积蓄也须保留来源并按要求声明；实际应税者须登记申报
- **关键限制与变化：** 每名成人US$1,500/月、每名受养子女US$500/月，另交最近3个月银行流水；不可把外国付款等同全面免税
- **证据等级：** B
- **主要来源：** [护照与移民署](https://passport.govmu.org/passport/?page_id=595)；[EDB Premium Visa FAQ](https://edbmauritius.org/wp-content/uploads/2023/12/FAQs-Premium-Visa.pdf)；[税务局专项FAQ](https://www.mra.mu/download/FAQsPremiumVISA.pdf)
