# 毛里求斯

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Premium Visa

- **当前状态：** 开放
- **最低门槛或收入：** 每名成人US$1,500/月；每名受养子女US$500/月
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** >6个月至1年，可续
- **居住与续签：** 长住签证，不直接计入20年PR
- **当地工作：** 不得进入毛里求斯劳动力市场
- **家属：** 配偶及未满24岁子女
- **永居或入籍路径：** 不直接通PR；可转换其他许可
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 境外收入按汇入制有特别说明；外国卡消费处理需留存证据
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://passport.govmu.org/passport/?page_id=595)
- **本条核验日期：** 2026-09-02
