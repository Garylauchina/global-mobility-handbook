## Digital Nomad temporary residence

- **当前状态：** 开放
- **申请者身份限制：** 须为远程服务境外法人的外国雇员、合同服务者或境外企业股东／管理者，不能把所有个人客户自由职业都自动包含。曾在原籍国以外国家居住至少2年者，还须提交该居住国犯罪记录及居留权证明；这是既有居住经历引起的材料要求，不是人人须先有外国永居。见[投资署现行资格问答](https://invest.gov.md/en/qa-2/digital-nomads/)。
- **最低门槛或收入：** 过去6个月总收入至少为18倍预测全国平均月薪；2026基数MDL17,400，合计MDL313,200，相当于平均MDL52,200/月
- **资金或收入性质：** 为境外法人远程受雇或提供服务，或作为境外公司股东/管理人通过信息技术经营
- **首次身份与期限：** 最长2年，可续
- **居住与续签：** 理论可累计长期居留，受实际居住/缺席规则
- **当地工作：** 以境外公司为对象，不进入摩尔多瓦本地市场；不能把所有境外自然人客户都视为自动合格
- **家属：** 家属按团聚
- **永居或入籍路径：** 可续，理论上5年永居；实践需确认
- **税务提示：** Invest Moldova现行政府项目资料称取得该专项居留即成为税务居民，所得税按每年2倍全国平均月薪定额并按期间比例计算；具体申报和协定适用仍须税务机关确认
- **关键限制与变化：** 2026定额公式计算为MDL34,800/年并按期间比例；不要套用一般183天规则或另一个独立创业者15%制度
- **证据等级：** B
- **主要来源：** [Invest Moldova专项问答](https://invest.gov.md/en/qa-2/digital-nomads/)；[CNAS 2026预测平均工资](https://cnas.gov.md/ro/node/568)；[Invest Moldova政府行业资料第14–15页](https://invest.gov.md/wp-content/uploads/2026/01/Profile_BPO_2025.pdf)
