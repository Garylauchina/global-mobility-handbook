## Digital Nomad temporary residence

- **当前状态：** 开放
- **最低门槛或收入：** 过去6月总收入≥18倍预测全国平均月薪；2026约MDL52,200/月
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 最长2年，可续
- **居住与续签：** 理论可累计长期居留，受实际居住/缺席规则
- **当地工作：** 境外雇主/客户/公司
- **家属：** 家属按团聚
- **永居或入籍路径：** 可续，理论上5年永居；实践需确认
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 适用特别固定税；2026约MDL34,800/年并按期间比例
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://invest.gov.md/en/qa-2/digital-nomads/)
- **本条核验日期：** 2026-09-02
