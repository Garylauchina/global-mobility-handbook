## Digital Nomad temporary residence

- **当前状态：** 待复核（原记录：开放）
- **状态说明：** 开放
- **申请者身份限制：** 【部分待核实】须属于受雇于境外公司或经营境外公司的外国远程工作者；在黑山合法入境、停留与递交期限另须满足。所引专项说明未列完整国籍白名单，不据此保证任意国籍均可入境申请。
- **最低门槛或收入：** 当前项目页要求生活来源证明；具体金额或计算公式仍须现行实施规则补证
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 最长2年，可再延2年
- **居住与续签：** 最长2年后可延最多2年；续期须提前至少30日本人递交。前次许可到期满6个月才可申请新许可；合法90日停留结束前提交完整首次申请者可留待决定
- **当地工作：** 仅境外雇主/自有境外公司
- **家属：** 配偶、未成年子女可团聚
- **永居或入籍路径：** 4年后有间隔，非干净5年永居路径
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 收入门槛与税收豁免条件不可混为一谈
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://digitalnomads.gov.me/article/legal-status-for-nomads)
