## Digital Nomad temporary residence

- **当前状态：** 开放
- **申请者身份限制：** 须属于受雇于境外公司或经营境外公司的外国远程工作者；在黑山合法入境、停留与递交期限另须满足。所引专项说明未列完整国籍白名单，不据此保证任意国籍均可入境申请。
- **最低门槛或收入：** 无统一固定金额；证明生活来源；税收优惠另有收入公式
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 最长2年，可再延2年
- **居住与续签：** 之后须离境6个月
- **当地工作：** 仅境外雇主/自有境外公司
- **家属：** 配偶、未成年子女可团聚
- **永居或入籍路径：** 4年后有间隔，非干净5年永居路径
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 收入门槛与税收豁免条件不可混为一谈
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://digitalnomads.gov.me/article/legal-status-for-nomads)
