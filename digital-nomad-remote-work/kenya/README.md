## Permit Class N — Digital Nomad

- **当前状态：** 开放
- **申请者身份限制：** 【部分待核实】Class N面向为境外雇主工作、经营境外企业或服务境外客户的外国远程工作者，并要求不属于被禁止入境者。公开资格页未列项目专属国籍白名单；这只说明所引页的证据范围，不构成对所有国籍的受理保证。
- **最低门槛或收入：** 境外来源年收入≥US$55,000
- **资金或收入性质：** 境外雇佣/公司/客户收入
- **首次身份与期限：** 1年或2年，可续
- **居住与续签：** Class N是否计入PR未被官方明确点名
- **当地工作：** 禁止为肯尼亚注册实体有偿或无偿工作/创收
- **家属：** 家属可办Dependent Pass
- **永居或入籍路径：** PR衔接需移民机关书面确认
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 税务居民常见183日或三年平均122日规则
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://fns.immigration.go.ke/infopack/permits/classN/)
