## Digital Nomad Visa + short-term residence

- **当前状态：** 开放/国籍白名单
- **最低门槛或收入：** US$3,000/月或US$36,000/年；21–55岁、大学学历
- **资金或收入性质：** 境外雇主收入
- **首次身份与期限：** 短期居留通常每次最长2年
- **居住与续签：** 长期居留理论看8年连续合法停留
- **当地工作：** 仅非土耳其雇主
- **家属：** 家属无自动DN资格
- **永居或入籍路径：** 并非直接永居；中国护照当前不在合资格名单
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 国籍白名单是关键筛选条件
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://goturkiye.com/tr/digitalnomads/dijital-gocebe-vize-ve-kisa-donem-ikamet-icin-basvuru-sartlari)
- **本条核验日期：** 2026-09-02
