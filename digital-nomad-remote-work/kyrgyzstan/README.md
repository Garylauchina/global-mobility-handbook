# 吉尔吉斯斯坦

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Digital Nomad status

- **当前状态：** 开放（限指定国籍及专业）
- **申请者身份限制：** 限阿塞拜疆、亚美尼亚、白俄罗斯、哈萨克斯坦、摩尔多瓦、俄罗斯、美国、英国、德国、日本、韩国的ICT、软件及相关领域专业人员；中国大陆不在现行规则第3条名单。外国永居不能直接替代所列国家资格；另受第6条犯罪及安全事由限制。
- **最低门槛或收入：** 过去一年合同服务收入至少US$5,000，另须银行余额至少US$3,000；须证明指定ICT、软件、数字创意等专业资格
- **资金或收入性质：** 境外远程专业收入
- **首次身份与期限：** 第一阶段60天；第二阶段延长1年，可按年继续延长，法规上限10年
- **居住与续签：** 须在首次60天内补本地医疗/HIV检查、有效身份及所需DN签证、专业收入和个体经营登记；延长后须按规则办理停留登记
- **当地工作：** 在法规所列专业范围内免工作许可，并可按本地登记及税法从事个体经营或担任企业创办人；不能概称只准境外收入
- **家属：** 配偶、未成年子女及其他受养/受监护近亲依移民规则入境停留；需要签证的合资格家属通过电子平台申请FF类签证
- **永居或入籍路径：** 不是直接PR或入籍
- **税务提示：** 法规明确须遵守税务、企业登记及国家社会保险义务；专项身份不等于免税。
- **关键限制与变化：** 限阿塞拜疆、亚美尼亚、白俄罗斯、哈萨克斯坦、摩尔多瓦、俄罗斯、美国、英国、德国、日本、韩国公民及指定专业；不得沿用旧6个月制度或概称所有国籍开放。
- **证据等级：** A
- **主要来源：** [2025年政府数字游民条例](https://www.gov.kg/storage/media/npa/4648/6823297d9a4df.pdf)；[劳动与移民部电子平台上线说明](https://mlsp.gov.kg/ru/2025/12/16/v-kyrgyzskoj-respublike-zapushhena-elektronnaya-platforma-dlya-podachi-hodatajstv-inostrannymi-grazhdanami-na-prisvoenie-statusa-czifrovoj-kochevnik-digital-nomad/)
