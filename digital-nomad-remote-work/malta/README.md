# 马耳他

[返回“数字游民与远程工作”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Nomad Residence Permit

- **当前状态：** 开放
- **申请者身份限制：** 须年满18岁，属非EU／EEA／瑞士的第三国国民。2026-04-17版FAQ排除阿富汗、朝鲜、伊朗、刚果民主共和国、索马里、南苏丹、苏丹、也门、委内瑞拉国民或与这些国家有紧密联系者，另不接收俄罗斯、白俄罗斯申请；“紧密联系”不能只靠换一本护照排除。不能同时保留两种马耳他居留身份，现有许可如何撤销须按FAQ办理。
- **最低门槛或收入：** 毛收入€42,000/年
- **资金或收入性质：** 境外雇主、境外公司或境外客户收入
- **首次身份与期限：** 每次1年，最多续3次，总计4年
- **居住与续签：** 续签前12个月累计住满5个月，并提供在马耳他消费的银行流水；到期前2–3个月申请，递件回执不延长合法停留
- **当地工作：** 仅境外业务
- **家属：** 配偶/合资格伴侣、未成年子女及合资格受养成年子女；须在初次缴费前一同纳入，之后一般到续签时才能新增，新生儿除外
- **永居或入籍路径：** 官方明确不通长期居留/入籍
- **税务提示：** 满足S.L.123.210条件的主申请人授权远程收入适用10%税率，首12个月有条件豁免；须税务登记。家属及非授权工作收入适用一般税法，不能把居留许可当作自动享税惠。
- **关键限制与变化：** 第三国国籍且受官方不适用国籍/紧密联系名单限制；每人健康保险至少€100,000并覆盖EU（含马耳他）及英国；须按最新保险项目表和住所要求提供材料。
- **证据等级：** A
- **主要来源：** [Residency Malta现行FAQ](https://nomad.residencymalta.gov.mt/new-faqs/)；[数字游民所得税规则S.L.123.210](https://legislation.mt/getpdf/65815fd48a3ed618b0827fe2)
