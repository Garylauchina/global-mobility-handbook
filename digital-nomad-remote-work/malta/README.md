## Nomad Residence Permit

- **当前状态：** 开放
- **最低门槛或收入：** 毛收入€42,000/年
- **资金或收入性质：** 境外雇主、境外公司或境外客户收入
- **首次身份与期限：** 每次1年，最多续3次，总计4年
- **居住与续签：** 续签前12月累计住满5个月
- **当地工作：** 仅境外业务
- **家属：** 配偶/伴侣/子女可随
- **永居或入籍路径：** 官方明确不通长期居留/入籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 授权远程收入可能适用10%专项规则并有首12月条件性豁免
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://nomad.residencymalta.gov.mt/wp-content/uploads/2024/04/Nomad-FAQs-v.12.pdf)
- **本条核验日期：** 2026-09-02
