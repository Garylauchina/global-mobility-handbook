# 葡萄牙

[返回“数字游民与远程工作”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## D8 Remote Work Residence

- **当前状态：** 开放
- **申请者身份限制：** 【部分待核实】须证明与葡萄牙境外实体的雇佣或服务关系；税务居所证明与国籍、永久居留是不同材料。所引D8专门条款未列国籍白名单，但这不等于所有国籍都免于一般入境及受理辖区限制。
- **最低门槛或收入：** 最近3个月平均远程工作/自雇收入至少4倍法定最低月薪；2026最低月薪€920，对应€3,680/月，另须税务居民证明
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 先办用于入境申请居留的签证，通常两次入境、4个月；D8居留卡2年，续期每次3年
- **居住与续签：** 临时居留期内无合理理由离境连续6个月或累计8个月，可能被取消；超过上限须事先申请说明，特殊情形可事后，法律另有工作/商业等可证明理由例外
- **当地工作：** 申请基础须为境外雇主/客户远程工作；取得居留后一般工作权受第83条及专项条件共同约束，仍须维持D8基础，不应概括为全面禁止当地活动
- **家属：** 家属可依第58条与主申请人同时申请随行居留签证；居留后普通团聚另按第98条，通常主申请人已持有效居留2年，符合既往同居条件的配偶可15个月，未成年/无能力受养人等有例外
- **永居或入籍路径：** 临时居留至少5年并满足生计、住宿、基础葡语等条件可申请永居。2026-05-19生效国籍法对EU/CPLP为7年，其他通常10年；生效前已提出的国籍程序沿用旧法
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 最低工资每年更新；D8的2+3年居留不等同入籍计时保证，国籍新法另加语言文化、公民义务及生计等条件，并须关注实施规定
- **证据等级：** A
- **主要来源：** [AIMA D8居留](https://aima.gov.pt/pt/trabalhar/autorizacao-de-residencia-para-o-exercicio-de-atividade-profissional-prestada-de-forma-remota-com-visto-de-residencia-para-o-exe)；[实施条例第31-A条](https://www.pgdlisboa.pt/leis/lei_mostra_articulado.php?artigo_id=940A0031A&ficha=1&nid=940&nversao=&pagina=1&so_miolo=&tabela=leis)；[2026公报最低工资依据](https://files.diariodarepublica.pt/2s/2026/01/003000001/0000200010.pdf)；[外国人法第58条](https://www.pgdlisboa.pt/leis/lei_mostra_articulado.php?nid=920&tabela=leis)；[外国人法第80、83、85、98条](https://www.pgdlisboa.pt/leis/lei_mostra_articulado.php?artigo_id=&ficha=101&nid=920&nversao=&pagina=2&so_miolo=&tabela=leis)；[司法部国籍新法公告](https://justica.gov.pt/en-gb/Noticias/Lei-da-Nacionalidade-novas-regras-entram-em-vigor-a-19-de-maio)
