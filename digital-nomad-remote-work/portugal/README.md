## D8 Remote Work Residence

- **当前状态：** 开放
- **最低门槛或收入：** 最近3月平均收入≥最低工资4倍；2026为€3,680/月
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 居留卡2年，续3年
- **居住与续签：** 长期路径需实际居住
- **当地工作：** 为境外雇主/客户远程工作
- **家属：** 可家庭团聚
- **永居或入籍路径：** 永居5年；2026国籍法下多数非EU/CPLP通常10年
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 最低工资每年变化；不要沿用旧金额
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://aima.gov.pt/pt/trabalhar/autorizacao-de-residencia-para-o-exercicio-de-atividade-profissional-prestada-de-forma-remota-com-visto-de-residencia-para-o-exe)
- **本条核验日期：** 2026-09-02
