# 中国台湾

[返回“数字游民与远程工作”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

> **适用范围：** 主申请人须实际适用台湾免签待遇。中国大陆普通护照不符合；取得外国永居或曾获他国数字游民签证，均不能替代此前提。

> **待补证事项：** 大陆地区人民改持外国护照后的身份适用、随行家属的个案递交及延期操作仍须主管机关确认；两年停留上限与家属类别已有2026正式公报支持。

## Digital Nomad Visitor Visa

- **当前状态：** 开放/限实际免签资格
- **申请者身份限制：** 主申请人须为实际适用台湾免签待遇的外国人，并持合资格外国护照；不能只看签发国家是否出现在名单，还须核对护照类别、出生地及公民身份脚注。中国大陆普通护照不符合，外国永居或其他国家数字游民签证不能替代免签资格。另持外国护照者仍须分别核对免签排除条件及大陆地区人民／外国人身份适用。依据[2026资格公告](https://gazette.nat.gov.tw/EG_FileManager/eguploadpub/eg032005/ch01/type1/gov84/num1/Eg.htm)及[完整免签名单与限制](https://www.boca.gov.tw/cp-149-4486-7785a-2.html)，具体边界见下文。
- **最低门槛或收入：** 先满足实际免签资格，再符合以下任一：曾获他国数字游民签证，或30岁及以上过去2年任1年年收入至少US$40,000，或20–29岁至少US$20,000；上述三选一之外，另须近6个月平均每月存款余额至少US$10,000
- **资金或收入性质：** 境外远程收入/存款
- **首次身份与期限：** 按2026作业要点核发6个月有效、多次入境、停留期6个月的停留签证；符合条件可申请延期，每次不超过6个月、每次总停留最长2年。附表提示来台停留期间少于6个月者，签证到期后不能按第14条申请延期
- **居住与续签：** 访客性质，不计永久居留
- **当地工作：** 仅境外业务
- **家属：** 2026作业要点列配偶、未成年子女及因身心障碍无法自理生活的成年子女；家属须另按对应材料和个案资格办理，不能把主申请人收入三选一直接套为每名家属的要求
- **永居或入籍路径：** 不直接通永久居留
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 免签资格是三选一专业条件之外的前置门槛；换一本免签国家护照也可能受出生地等脚注排除。须提供远程工作证明、存款及全程医疗保险；境内有其他访客身份不当然豁免上述资格。2026附表另提示来台停留期间少于6个月者，签证到期后不能按第14条延期
- **证据等级：** B
- **主要来源：** [2026资格公告](https://gazette.nat.gov.tw/EG_FileManager/eguploadpub/eg032005/ch01/type1/gov84/num1/Eg.htm)；[2026作业要点及附表](https://gazette.nat.gov.tw/EG_FileManager/eguploadpub/eg032067/ch01/type2/gov84/num2/Eg.pdf)；[完整免签名单与限制](https://www.boca.gov.tw/cp-149-4486-7785a-2.html)；[领务局数字游民签证说明](https://www.boca.gov.tw/fp-158-7718-c0382-2.html)

## 申请资格边界

先核对本人是否适用免签待遇，再检查远程工作、收入或既有数字游民签证等条件。三选一只发生在后一步，不是“曾有他国数字游民签证便不受国籍限制”。[2026资格公告](https://gazette.nat.gov.tw/EG_FileManager/eguploadpub/eg032005/ch01/type1/gov84/num1/Eg.htm)

- **出生地排除：** 伯利兹、斯威士兰、圣基茨和尼维斯、圣卢西亚、图瓦卢护照，如资料页出生地记载为阿富汗、伊朗、伊拉克、利比亚、尼日利亚、巴基斯坦、中国、叙利亚或也门，不适用台湾免签；洪都拉斯护照如记载出生地为中国，也不适用。不能只因持有这些国家护照就认定满足数字游民的免签前提。
- **公民身份类别：** 英国护照只限British Citizen身份；马绍尔群岛另有限定出生取得国籍等条件，不能将其他英国国籍类别或马绍尔群岛的后天归化身份自动视为合资格。
- **护照种类：** 免签名单的部分国家排除外交、公务护照；数字游民签证材料本身还排除临时和紧急护照，并要求护照至少6个月有效。一般免签的证件例外不自动适用于数字游民签证。

上述为[领务局免签名单及脚注](https://www.boca.gov.tw/cp-149-4486-7785a-2.html)与[数字游民护照要求](https://www.boca.gov.tw/fp-158-7718-c0382-2.html)的组合核对。对原大陆地区人民而言，还须独立确认改持外国护照后的身份适用；仅有外国永久居民资格不会把中国大陆护照变成免签护照。

## 政策时间线

### 2026-01-01 — 资格及停留规则的适用日期

- **公布与生效：** 资格公告于2026-01-08公布，作业要点于2026-04-16修正公布，两份公报均明定自2026-01-01生效
- **变化摘要：** 免签待遇仍是独立前提；修正要点明确6个月停留、每次延期不超过6个月、每次总停留最长2年，并列明配偶及合资格子女。附表对不足6个月停留的延期另有限制
- **官方依据：** [资格公告](https://gazette.nat.gov.tw/EG_FileManager/eguploadpub/eg032005/ch01/type1/gov84/num1/Eg.htm)；[修正要点及附表](https://gazette.nat.gov.tw/EG_FileManager/eguploadpub/eg032067/ch01/type2/gov84/num2/Eg.pdf)
- **事件证据：** A
