## Digital Nomad Visitor Visa

- **当前状态：** 开放
- **申请者身份限制：** 限享有赴台免签待遇国家的国民，并须符合远程工作资格；不能把第三地永久居留或单次入境便利当作该国国籍。中国大陆普通护照持有人不能据此直接按外国数字游民申请；另持外国护照者的大陆地区人民／外国人身份适用仍须另向主管机关确认。见[领务局资格及免签名单入口](https://www.boca.gov.tw/fp-158-7718-c0382-2.html)。
- **最低门槛或收入：** 仅免签入境适用国家的国民：曾获他国数字游民签证，或30岁及以上过去2年任1年年薪至少US$40,000，或20–29岁至少US$20,000；上述三选一之外，另须过去6个月每月平均存款至少US$10,000
- **资金或收入性质：** 境外远程收入/存款
- **首次身份与期限：** 每次最多6个月，可续至总计2年
- **居住与续签：** 访客性质，不计永久居留
- **当地工作：** 仅境外业务
- **家属：** 2026新规允许配偶及未成年子女随行
- **永居或入籍路径：** 不直接通永久居留
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 免签国籍、三选一资格与独立存款条件须同时区分；仅有存款不满足年龄/收入/既有数字游民签证资格，须提供远程合同及全程健康住院保险
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://www.boca.gov.tw/fp-158-7718-c0382-2.html)
