# 伯利兹

## Long Stay Visitor Permit（推广名：Work Where You Vacation）

- **当前状态：** 开放；移民局有现行规则及在线申请入口，政府费用币种存在官方页面冲突
- **最低门槛或收入：** 单人年收入至少US$75,000；携带家属至少US$100,000。申请人须为EU、英国、美国或加拿大的公民或永久居民
- **资金或收入性质：** 伯利兹境外受雇或自雇收入；自雇者须提供企业登记和年度报税等材料，并提交银行证明、6个月内无犯罪记录及至少US$50,000旅行医疗保险
- **首次身份与期限：** 自签发起最长6个月，且每个日历年停留不超过6个月
- **居住与续签：** 官方明确不得延期；能否在下一日历周期重新提出全新申请及是否有等待期，当前公开页面没有积极说明
- **当地工作：** 主申请人和家属均不得在伯利兹本地就业；只可继续从事合资格境外远程工作，所谓免工作许可不等于开放本地工作权
- **家属：** 配偶、未满18岁的未婚亲生/继子女或依法收养子女，以及法院确认的其他受养人；合资格未成年子女入学可免学生许可
- **永居或入籍路径：** 本许可没有直接PR通道，且不可延期的6个月结构本身不能满足普通PR所需的一年合法居留和累计离境不超过14天；改用其他合法身份后的路径须另行判断
- **税务提示：** 最长180天不自动保证无税务义务；在伯利兹有住所、一个评税年度停留超过183天或取得伯利兹来源收入，均可能触发相应税务规则
- **关键限制与变化：** 移民局写US$500/成人、US$200/儿童，旅游局写BZD500/BZD200；按固定汇率折算，两者金额相差一倍，申请前须向移民局或实际申请门户书面确认，本站不自行选择较低金额
- **证据等级：** B
- **主要来源：** [伯利兹移民局Long Stay Permit](https://immigration.gov.bz/permits/long-stay-permit/)；[2021年移民法修正案](https://www.agm.gov.bz/uploads/laws/639771269b486_Act_No-20_of_2021_____Immigration__Amendment__Act_2021.pdf)；[旅游局Work Where You Vacation](https://www.travelbelize.org/work-where-you-vacation/)
- **本条核验日期：** 2026-09-02
