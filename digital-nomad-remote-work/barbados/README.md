## Welcome Stamp

- **当前状态：** 开放
- **最低门槛或收入：** 预计未来12个月收入US$50,000或有足够生活资金
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 12个月，可申请续签
- **居住与续签：** 不直接通PR
- **当地工作：** 不得向当地个人或实体提供服务
- **家属：** 家庭包
- **永居或入籍路径：** 不直接通PR
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 访问/远程许可不等于税务免除
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://barbadoswelcomestamp.bb/applynow/)
