# 巴巴多斯

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Welcome Stamp

- **当前状态：** 开放
- **申请者身份限制：** 【部分待核实】须属于境外收入支持的远程工作者。申请表收集现有及曾有国籍、出生地等资料，但下拉选项不能作为所有国籍均合资格的证据；本次未从公开条款确认完整国籍或特殊身份排除范围。
- **最低门槛或收入：** 预计未来12个月收入US$50,000或有足够生活资金
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 12个月，可申请续签
- **居住与续签：** 不直接通PR
- **当地工作：** 不得向当地个人或实体提供服务
- **家属：** 家庭包
- **永居或入籍路径：** 不直接通PR
- **税务提示：** 官方计划说明对合资格境外远程工作给予巴巴多斯所得税豁免；这不免除原税籍国的申报纳税，也不等于所有税种豁免
- **关键限制与变化：** 仅为境外主体远程工作，申请人及家属均须承诺不接受当地就业或提供本地服务；专项所得税待遇须与原税籍国义务分开
- **证据等级：** A
- **主要来源：** [移民局申请及续签表](https://barbadoswelcomestamp.bb/applynow/)；[官方旅游局计划说明](https://www.visitbarbados.org/barbados-welcome-stamp)
