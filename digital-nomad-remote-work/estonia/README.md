## Teleworking / Digital Nomad D visa

- **当前状态：** 开放
- **最低门槛或收入：** €132/日，约€3,960/月
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** D签最多365日/12个月
- **居住与续签：** 签证而非居留卡
- **当地工作：** 仅境外雇佣或业务
- **家属：** 无自动附属家属，通常各自办签
- **永居或入籍路径：** 不计长期居留
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 停留≥183日可能成为税务居民
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://vm.ee/en/consular-visa-and-travel-information/visa-information/application-long-stay-d-visa)
- **本条核验日期：** 2026-09-02
