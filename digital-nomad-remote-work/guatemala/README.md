## Temporary residence — foreign-employer migrant worker

- **当前状态：** 待复核（原记录：开放）
- **申请者身份限制：** IGM-016-2025第6条面向符合移民法类别的外国人，第11(2)条明确境外雇主移民工作者路线；须有效护照、最后入境证明及相应无犯罪材料。项目资格与入境国籍分类分开，完整免签／咨询签证例外仍待核实。
- **最低门槛或收入：** 过去一年每月境外报酬至少US$2,000；携受养人至少US$3,000。国际NGO或国际组织雇员可按劳动关系及医疗保险证明豁免该收入证明
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 最长5年
- **居住与续签：** 续签须提前30日递交并保持有效及已更新身份，境外雇主路线继续证明上一年每月2000/携家属3000美元；拟离境一年或以上须事先申请授权
- **当地工作：** 本页记录境外雇主路线；当地雇主和自营工作是条例另设分项，须各自许可，不应混为此路线附带工作权
- **家属：** 移民法第27条所涉亲属、配偶/同居伴侣可按同期限随行，同时或之后递件；完整关系范围及材料仍须按移民法补核
- **永居或入籍路径：** 条例要求居留超过5年者按移民法第78条申请永居，具体条件仍须另核，并非满期自动获得
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 2025-10-08生效的居留条例已列境外雇主路线；该法源应优先于第三方“数字游民”项目概括
- **证据等级：** B
- **主要来源：** [2025居留条例](https://extranjeria.igm.gob.gt/files/normativa/24.1.4-Reglamento-de-Residencias-Guatemaltecas-Acdo-IGM-016-2025-AMN-05-2025.pdf)；[IGM现行居留入口](https://extranjeria.igm.gob.gt/index.php/component/content/article/residencias-temporales?catid=8)；[官方或主要依据](https://www.ey.com/content/dam/ey-unified-site/ey-com/en-gl/insights/workforce/documents/ey-gl-global-immigration-index-remote-work-and-digital-nomads-03-2026.pdf)
