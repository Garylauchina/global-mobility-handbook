## Long-term visa for remote work

- **当前状态：** 待复核（原记录：开放）
- **状态说明：** 开放
- **申请者身份限制：** 属于第三国国民远程工作路线。OECD条件针对雇主注册国或自雇登记国，不是要求申请人具有OECD国籍；受雇者还须证明此前至少6个月的雇佣关系。俄罗斯公民的签证受理限特定拉脱维亚或EU/EEA/瑞士公民亲属、人道理由及已获拉脱维亚居留权需入境签证者；普通远程工作不独立构成例外。白俄罗斯公民的长期签证申请可受理，不能直接套用俄罗斯规则。仍须符合一般入境、旅行证件及个别审查条件。
- **最低门槛或收入：** €4,538/月（上年全国平均毛薪2.5倍）
- **资金或收入性质：** 境外OECD雇主/自雇收入
- **首次身份与期限：** 1年
- **居住与续签：** D签非居留许可
- **当地工作：** 不得在拉脱维亚就业；关系需已持续≥6个月
- **家属：** 无捆绑家属
- **永居或入籍路径：** 不计永居
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 183日可能触发税籍
- **证据等级：** B
- **主要来源：** [外交部俄籍受理限制](https://www.mfa.gov.lv/en/acceptance-visa-applications-citizens-russian-federation)；[白俄籍受理规则](https://www.mfa.gov.lv/en/acceptance-visa-applications-citizens-belarus)；[官方或主要依据](https://www.pmlp.gov.lv/en/receiving-long-term-visa-remote-work)
