# 拉脱维亚

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Long-term visa for remote work

- **当前状态：** 开放
- **最低门槛或收入：** €4,538/月（上年全国平均毛薪2.5倍）
- **资金或收入性质：** 境外OECD雇主/自雇收入
- **首次身份与期限：** 1年
- **居住与续签：** D签非居留许可
- **当地工作：** 不得在拉脱维亚就业；关系需已持续≥6个月
- **家属：** 无捆绑家属
- **永居或入籍路径：** 不计永居
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 183日可能触发税籍
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.pmlp.gov.lv/en/receiving-long-term-visa-remote-work)
- **本条核验日期：** 2026-09-02
