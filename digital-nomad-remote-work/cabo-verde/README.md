## Remote professional activity residence

- **当前状态：** 待复核（原记录：开放）
- **状态说明：** 开放
- **申请者身份限制：** 【部分待核实】2025实施条例第35条要求境外劳动合同或服务／经营关系，并提交税务居所证明；税务居所不等于国籍或永久居民身份。新法条不能沿用2020旅游推广项目的地域营销范围作为国籍白名单；完整特别国籍入境限制仍须另核。
- **最低门槛或收入：** 官方现行页面仅要求充足生活来源，无统一数额
- **资金或收入性质：** 境外劳动、服务或公司活动；须提供过去3个月平均专业收入证明及税务居民证明
- **首次身份与期限：** 入境签后临时居留通常2年，可每2年续
- **居住与续签：** 一般临居每两年续；无合理理由连续离境6个月可能撤销临居。续期原则须到期前45日申请
- **当地工作：** 只能面向境外自然人/法人远程工作
- **家属：** 可家庭团聚
- **永居或入籍路径：** 一般临居满5年可申请永居，还须生计、住房、语言、品格等条件；佛得角出生外国人等另有例外。归化一般要求至少5年惯常居住及成年、品格和自给能力
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 2025年重刊实施条例第35条规定远程签证文件，不要混用2020旧6+6个月及€1,500/€2,700存款口径；一般居留和归化仍须分别满足各自全部条件。
- **证据等级：** B
- **主要来源：** [2025年官方公报元数据](https://boe.incv.cv/Bulletins/View/85465)；[Decreto-Lei13/2025及重刊全文](https://boe.incv.cv/Bulletins/DownloadAct?id=85465)；[移民高等署居留与续期说明](https://aai.gov.cv/cat-geral/38-imigrantes/perman%C3%AAncia-%E2%80%93-autoriza%C3%A7%C3%A3o-de-resid%C3%AAncia)；[移民高等署国籍说明](https://aai.gov.cv/cat-geral/20-imigrantes)
