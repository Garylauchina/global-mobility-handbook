## Remote professional activity residence

- **当前状态：** 开放
- **最低门槛或收入：** 官方现行页面仅要求充足生活来源，无统一数额
- **资金或收入性质：** 境外劳动/服务/公司合同
- **首次身份与期限：** 入境签后临时居留通常2年，可每2年续
- **居住与续签：** 实际连续居住可累计长期身份
- **当地工作：** 只能面向境外自然人/法人远程工作
- **家属：** 可家庭团聚
- **永居或入籍路径：** 临时居留满5年可申请永久居留；归化通常也看5年惯常居住
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 不要混用2020旧6+6个月及€1,500/€2,700存款口径
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://boe.incv.cv/Bulletins/View/85465)
- **本条核验日期：** 2026-09-02
