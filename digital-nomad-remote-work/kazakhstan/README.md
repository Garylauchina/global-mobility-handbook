## Neo Nomad Visa

- **当前状态：** 待复核（原记录：开放）
- **状态说明：** 开放
- **申请者身份限制：** 政府Neo Nomad B12-1指引明确面向所有国家、具有稳定境外收入的远程工作公民。48国附件仅免邀请函，不是项目国籍白名单；中国不在该附件，须按邀请函程序办理。不得与ICT人才Digital Nomad Residency混用。见[官方指引及完整附件](https://www.gov.kz/uploads/2025/2/19/d79373170d20305395432e0d15db1acc_original.116081.pdf)。
- **最低门槛或收入：** 最近6个月稳定境外收入约US$3,000/月；伦敦使馆写至少US$3,000，伯尔尼清单写超过US$3,000，压线者须向递件馆确认
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 1年，可续1年
- **居住与续签：** 不通PR
- **当地工作：** 不得在哈萨克斯坦受雇
- **家属：** 家属可获同期限
- **永居或入籍路径：** 不通PR
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 须提供资金、税务居民申报、无犯罪及保险等相应材料，并核对国籍/邀请函清单；收入等于US$3,000的边界存在使馆用语差异。不要与ICT人才Digital Nomad Residency项目混淆
- **证据等级：** B
- **主要来源：** [官方Neo Nomad指引及48国附件](https://www.gov.kz/uploads/2025/2/19/d79373170d20305395432e0d15db1acc_original.116081.pdf)；[伦敦使馆Neo Nomad B12-1](https://www.gov.kz/memleket/entities/mfa-london/press/article/details/188964?lang=en)；[伯尔尼使馆签证材料清单](https://www.gov.kz/memleket/entities/mfa-bern/press/article/details/6521?lang=en)
