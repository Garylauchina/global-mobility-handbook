# 乌拉圭

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Permiso especial para nómadas digitales

- **当前状态：** 开放
- **最低门槛或收入：** 自我声明有足够生活来源，无固定数字
- **资金或收入性质：** 境外远程收入
- **首次身份与期限：** 6个月+1次6个月
- **居住与续签：** 可另申请普通临时/永久居留
- **当地工作：** 只为境外主体远程
- **家属：** 家属须另行办理
- **永居或入籍路径：** 可转换其他类别但非自动
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 宽松门槛不代表无需证明资金和保险
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.gub.uy/agencia-gobierno-electronico-sociedad-informacion-conocimiento/comunicacion/noticias/permiso-especial-residencia-legal)
- **本条核验日期：** 2026-09-02
