# 克罗地亚

## Temporary stay of digital nomads

- **当前状态：** 开放
- **最低门槛或收入：** €3,622.50/月；或12月存款€43,470、18月€65,205；家属按平均净薪10%加成
- **资金或收入性质：** 境外远程收入/存款证明
- **首次身份与期限：** 最长18个月
- **居住与续签：** 届满后须等6个月再申请
- **当地工作：** 仅境外雇主/自有境外公司；不得服务克罗地亚雇主或客户
- **家属：** 可家庭团聚
- **永居或入籍路径：** 强制间隔通常不形成连续5年路径
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 境外劳动收入有专项税务规则；其他收入和税籍另判
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://mup.gov.hr/aliens-281621/stay-and-work/temporary-stay-of-digital-nomads/286833?impaired=1)
- **本条核验日期：** 2026-09-02
