## Destination Thailand Visa (DTV)

- **当前状态：** 开放
- **最低门槛或收入：** 银行余额至少THB500,000
- **资金或收入性质：** 存款+远程工作/软实力活动资格
- **首次身份与期限：** 5年多次；每次180天，可境内延1次180天
- **居住与续签：** 每次停留独立，不计PR
- **当地工作：** 不得以DTV直接受雇于泰国雇主
- **家属：** 配偶、未满20岁子女
- **永居或入籍路径：** 不计PR
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 需证明远程工作/自由职业或合格活动；存款不是投资居留
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://washingtondc.thaiembassy.org/en/page/page/dtv-visa)
- **本条核验日期：** 2026-09-02
