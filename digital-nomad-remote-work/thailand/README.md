## Destination Thailand Visa (DTV)

- **当前状态：** 开放
- **申请者身份限制：** 适用远程工作者／自由职业者、规定泰国活动参加者及合资格家属等不同类别，须分别提供证明。驻华盛顿馆对非美国公民要求美国永久居留卡或至少6个月有效美国签证，属于该馆递交材料，不能推导为所有DTV申请人须先有美国身份。
- **最低门槛或收入：** 资金至少THB500,000；华盛顿使馆当前要求近3个月每月期末余额均达标，其他递件馆按各自清单
- **资金或收入性质：** 存款+远程工作/软实力活动资格
- **首次身份与期限：** 5年多次；每次180天，可境内延1次180天
- **居住与续签：** 每次停留独立，不计PR
- **当地工作：** 不得以DTV直接受雇于泰国雇主
- **家属：** 配偶、未满20岁子女
- **永居或入籍路径：** 不计PR
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 远程工作/自由职业或合格活动须有证明。使领馆材料可不同：华盛顿另列近3个月FBI无犯罪证明及美国合法居留证明；每次180+180天届满须出境再入境
- **证据等级：** A
- **主要来源：** [泰国驻华盛顿使馆DTV](https://washingtondc.thaiembassy.org/en/page/page/dtv-visa)；[外交部DTV期限与材料说明](https://image.mfa.go.th/mfa/0/4a5AsMHake/%E0%B9%80%E0%B8%81%E0%B8%B5%E0%B9%88%E0%B8%A2%E0%B8%A7%E0%B8%81%E0%B8%B1%E0%B8%9A%E0%B9%80%E0%B8%A3%E0%B8%B2/New_Visa_to_Thailand_-_Infographic.pdf)
