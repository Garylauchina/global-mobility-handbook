## Residence for digital nomad

- **当前状态：** 开放/有配额
- **最低门槛或收入：** 官方未公布统一数额；须有足够经济能力并获经济部资质认定
- **资金或收入性质：** 地点独立的境外远程收入
- **首次身份与期限：** 2年→2年→3年→其后10年
- **居住与续签：** 每年主居住≥90日
- **当地工作：** 不得本地就业
- **家属：** 可带受养家属
- **永居或入籍路径：** 可持续续签；入籍一般20年实际居住
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 年度配额和资质认定；90日不等于税籍安全
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://www.govern.ad/ca/tematiques/immigracio/residencia/residencia-per-a-nomada-digital)
- **本条核验日期：** 2026-09-02
