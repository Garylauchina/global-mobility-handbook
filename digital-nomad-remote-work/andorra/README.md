## Residence for digital nomad

- **当前状态：** 待复核（原记录：开放）
- **状态说明：** 开放/有配额
- **申请者身份限制：** 【部分待核实】须获主管部门对数字游民活动的认可；普通境外远程雇佣关系不自动满足该认可。官方材料允许EU／EEA国民以有效身份证替代护照，并要求来源国、国籍国及居住国犯罪记录；这反映材料差异，不是完整国籍白名单。
- **最低门槛或收入：** 官方未公布统一数额；须有足够经济能力并获经济部资质认定
- **资金或收入性质：** 地点独立的境外远程收入
- **首次身份与期限：** 一般为2年→2年→3年→其后10年；已与安道尔批准有关协定的国家国民适用例外，不能将该序列无条件套用于所有国籍
- **居住与续签：** 每年主居住≥90日
- **当地工作：** 不得本地就业
- **家属：** 可带受养家属
- **永居或入籍路径：** 可持续续签；一般归化须证明20年居住，最后5年连续，并须放弃原国籍；还须满足法定语言等要求，不能以每年90日直接推定满足归化条件
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 年度配额和资质认定；90日不等于税籍安全
- **证据等级：** B
- **主要来源：** [移民局数字游民居留说明](https://www.govern.ad/ca/tematiques/immigracio/residencia/residencia-per-a-nomada-digital)；[政府国籍申请及第11.1条条件](https://www.e-tramits.ad/tramits/ca/demanda-de-nacionalitat/p/GV100016)
