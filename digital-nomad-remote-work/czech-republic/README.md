## Digital Nomad Programme

- **当前状态：** 待复核（原记录：开放）
- **状态说明：** 开放/限职业国籍
- **申请者身份限制：** 限澳大利亚、巴西、印度、以色列、日本、加拿大、韩国、墨西哥、新西兰、新加坡、英国、美国和台湾的合资格IT或市场营销专业人员；中国大陆普通护照不在名单。申请时及此前一年不得持有过捷克超过90日的长期签证或长期居留许可；外国永居不能替代国籍白名单。见[项目规则第4.1节](https://mpo.gov.cz/assets/en/foreign-trade/economic-migration/programs-and-projects/2025/7/Digital-Nomad-EN.pdf)。
- **最低门槛或收入：** 须达到劳动与社会事务部公布的平均毛年薪1.5倍，并满足IT或市场营销专业的学历/经验条件；按当年官方基准计算
- **资金或收入性质：** 境外雇佣收入，或在捷克登记IT/市场营销自由职业所产生的合同收入
- **首次身份与期限：** 境外雇员首次项目资格最长1年，获准延续后另申请相同目的长期居留；自由职业者项目入选期限不限不等于居留许可永久有效
- **居住与续签：** 依所获长期签证/居留类型
- **当地工作：** 雇员为境外雇主远程工作；自由职业者按捷克获准IT或市场营销业务经营
- **家属：** 配偶、登记伴侣、未成年子女及成年受养子女可与主申请人同时进入项目；家属不必具备主申请人的13个国籍，但须满足递件使领馆的地域管辖或法定豁免。成年受养子女不能据此取得家庭团聚居留，须另按学习或其他教育目的申请相应身份
- **永居或入籍路径：** 是否计入长期居留取决于最终签证类别和实际居住
- **税务提示：** 【待核实】专项居留不自动决定税务身份；该国对在境内履行远程工作的税务居民判定、收入来源及申报义务尚缺当前税务机关依据，不能据本页认定免税或无需登记。
- **关键限制与变化：** 适用澳大利亚、巴西、印度、以色列、日本、加拿大、韩国、墨西哥、新西兰、新加坡、英国、美国及台湾国籍/护照范围；雇员的境外雇主须全球至少50人。不是面向全部国籍和职业的通用签证。
- **证据等级：** B
- **主要来源：** [工业与贸易部项目说明](https://mpo.gov.cz/en/foreign-trade/economic-migration/digital-nomad-program--275799/)；[2025年项目规则PDF](https://mpo.gov.cz/assets/en/foreign-trade/economic-migration/programs-and-projects/2025/7/Digital-Nomad-EN.pdf)
