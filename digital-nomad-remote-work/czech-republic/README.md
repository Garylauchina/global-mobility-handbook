## Digital Nomad Programme

- **当前状态：** 开放/限职业国籍
- **最低门槛或收入：** 无单一公开固定金额；面向指定国籍的高技能IT雇员/自由职业者并满足薪资与资历
- **资金或收入性质：** 境外IT雇佣或捷克自由职业架构
- **首次身份与期限：** 通常1年，可按项目续
- **居住与续签：** 依所获长期签证/居留类型
- **当地工作：** 仅按批准IT活动
- **家属：** 配偶、子女可随项目办理
- **永居或入籍路径：** 是否计入长期居留取决于最终签证类别和实际居住
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 不是面向所有国籍和职业的通用DNV
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://ipc.gov.cz/en/for-employers/programmes-approved-by-the-government-with-the-view-of-economic-benefit-of-the-czech-republic/)
- **本条核验日期：** 2026-09-02
