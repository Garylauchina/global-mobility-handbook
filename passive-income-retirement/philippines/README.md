## Special Resident Retiree’s Visa (SRRV)

- **当前状态：** 开放
- **最低门槛或收入：** 40岁以上；50+有养老金存款US$15k、无养老金US$30k；40–49岁分别US$25k/US$50k；养老金常为US$800/月或家庭US$1,000/月
- **资金或收入性质：** 定期存款+养老金/退休资格
- **首次身份与期限：** 无限期、多次入境，条件持续即有效
- **居住与续签：** 维持存款和年费
- **当地工作：** 可按SRRV权限，受雇另核
- **家属：** 配偶、未满21岁子女；人数多常需加存款
- **永居或入籍路径：** 不直接通公民身份
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 年龄、养老金和家属组合影响存款金额
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.pra.gov.ph/srrvisa)
- **本条核验日期：** 2026-09-02
