## Special Resident Retiree’s Visa (SRRV)

- **当前状态：** 开放
- **申请者身份限制：** PRA现行SRRV面向年满40岁的外国国民及前菲律宾公民，并要求有效旅游身份等材料；Courtesy等分支另针对未重新取得菲律宾国籍的前菲律宾人、合资格退休外交／国际组织／特定军职背景，不能推广成所有申请人都适用优惠。完整限制国家及特别批准范围本次仍未确认。
- **最低门槛或收入：** 年满40；50+有养老金存款US$15k、无养老金US$30k；40–49岁分别US$25k/US$50k；采用有养老金档须证明终身养老金至少US$800/月，带家属为US$1,000/月
- **资金或收入性质：** 定期存款+养老金/退休资格
- **首次身份与期限：** 无限期、多次入境，条件持续即有效
- **居住与续签：** 维持存款和年费
- **当地工作：** 可按SRRV权限，受雇另核
- **家属：** 合法配偶及申请时未满21岁的未婚子女；除前菲律宾公民例外外，超过2名受养人后每增1人加存款US$15,000
- **永居或入籍路径：** 不直接通公民身份
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 年龄、养老金和家属组合影响存款金额
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.pra.gov.ph/srrvisa)
