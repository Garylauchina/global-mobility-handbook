> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Qualified Retirement Program

- **当前状态：** 开放
- **最低门槛或收入：** 年满40；境外退休/投资等收入US$2,000/月或US$24,000/年
- **资金或收入性质：** 境外退休/投资收入
- **首次身份与期限：** QRP卡每年续
- **居住与续签：** 每年连续住满30天
- **当地工作：** 通常不得当地受雇；获批QRP Investor除外
- **家属：** 配偶、未满18岁子女
- **永居或入籍路径：** 专门退休居民身份，不等同普通PR
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 须持续满足收入和年度居住
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.belizetourismboard.org/programs-events/retirement-program/)
- **本条核验日期：** 2026-09-02
