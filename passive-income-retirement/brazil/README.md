## Retiree Residence

- **当前状态：** 开放
- **最低门槛或收入：** 可转入巴西的退休金/养老金US$2,000/月
- **资金或收入性质：** 境外养老金并汇入
- **首次身份与期限：** 通常先2年，再续/转长期
- **居住与续签：** 须按许可维持居住
- **当地工作：** 可按居留规则生活/工作，具体另核
- **家属：** 家属可团聚
- **永居或入籍路径：** 可进入一般长期居留与归化轨道，但非自动
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 汇款和养老金认证是核心
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.gov.br/mre/pt-br/embaixada-camberra/English/consular-section/visas/long-term-visas-for-stays-longer-than-90-days/vitem-xiv-immigration-policy)
- **本条核验日期：** 2026-09-02
