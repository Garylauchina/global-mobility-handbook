## Residence Permit as Retired Non-Citizen

- **当前状态：** 开放
- **最低门槛或收入：** 年满50；首汇US$2,000；之后每年US$24,000或每月US$2,000
- **资金或收入性质：** 境外养老金/收入汇入
- **首次身份与期限：** 10年，可续
- **居住与续签：** PR路径要求实际持证和汇款
- **当地工作：** 不得受雇或参与企业日常管理/领薪；可投资
- **家属：** 配偶、父母、24岁以下子女
- **永居或入籍路径：** 持退休居留≥5年且5年累计汇入≥US$200,000，可申请20年PR
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 采用2025 Finance Act新标准，不用旧US$1,500门槛
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://president.govmu.org/president/wp-content/uploads/2025/08/18_The-Finance-Act-2025.pdf)
- **本条核验日期：** 2026-09-02
