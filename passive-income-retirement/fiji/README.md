## Residence on Assured Income

- **当前状态：** 待复核（原记录：开放）
- **状态说明：** 开放/裁量
- **申请者身份限制：** 官方要求非公民申请人年满45岁，并有足够境外资产或稳定收入供养本人及家属；不是只凭“退休”称谓即可申请。公开要求未列完整项目国籍白名单，普通入境及背景条件仍独立适用。
- **最低门槛或收入：** 年满45并具足够境外资产/可靠收入；官网另要求汇入$100,000或购入同值以上房产后签发剩余许可期限（该段未注明币种，须书面确认，不能自行当作美元）
- **资金或收入性质：** 境外资产/保证收入
- **首次身份与期限：** 合计3年：先批6个月，收到$100,000汇款和/或同值以上购房证明后再批余下2.5年
- **居住与续签：** 须自给自足
- **当地工作：** 本类别不得受雇、经营企业或从事工作
- **家属：** 仅合法配偶及未满18岁子女可附属；事实伴侣及18岁以上子女须另申co-extensive类别
- **永居或入籍路径：** 不自动PR或入籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 须通过品行/健康审查；逾期、假材料、违反既往许可及禁止入境者受限制。主申请人许可终止亦影响家属；须书面确认汇款币种和续签条件
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://www.immigration.gov.fj/residence-on-assured-income-permit-application/)
