# 泰国

## LTR — Wealthy Pensioner

- **当前状态：** 开放
- **申请者身份限制：** 面向年满50岁的外国退休人士，以养老金或规定的被动收入满足要求；工资或提取非退休储蓄不能替代退休收入，并须不存在移民法规定的禁止入境情形。已有泰国签证者应依BOI通知在LTR获批后办理原签证转换，不应提前自行取消。
- **最低门槛或收入：** 年满50；收入≥US$80k/年，或US$40k–80k并在泰国投资≥US$250k
- **资金或收入性质：** 养老金/被动收入+可选泰国投资
- **首次身份与期限：** 10年，通常分两个5年期
- **居住与续签：** 先授予5年，复核持续符合资格后再授5年；境内停留报告通常由90天改为每年一次，仍须遵守入境与住址申报要求
- **当地工作：** 可按LTR规则，工作许可另办
- **家属：** 合法配偶、父母、未满20岁子女或法定受养人；每人须满足相应保险或存款条件，未婚伴侣不能当然按配偶申请
- **永居或入籍路径：** 不是PR或入籍捷径
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 须有至少US$50,000医疗保险（通常剩余有效期至少10个月）、泰国社会保障或已保持12个月的US$100,000存款替代；每名家属的存款替代额为US$25,000。投资必须属于BOI认可类别并归申请人持有。
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://ltr.boi.go.th/)

- **补充来源：** [BOI第Por.3/2568号公告](https://ltr.boi.go.th/documents/Announcement_of_the_Office_of_the_Board_of_Investment_No_Por_3_2568_%28EN%29.pdf)；[BOI现行FAQ](https://ltr.boi.go.th/page/faq.html)

## 政策时间线

- **2025-02-04（公告并生效）：** BOI第Por.3/2568号公告将合法父母和法定受养人纳入随行范围，并明确退休分支的收入、投资和保险条件；本页据此补全原先仅列配偶和子女的说明。来源：[BOI公告](https://ltr.boi.go.th/documents/Announcement_of_the_Office_of_the_Board_of_Investment_No_Por_3_2568_%28EN%29.pdf)。
