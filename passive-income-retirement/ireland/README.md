# 爱尔兰

[返回“被动收入与退休居留”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Stamp 0 — retire / independent means

- **当前状态：** 开放
- **最低门槛或收入：** 个人稳定收入€50,000/年，另需足够应急一次性资金并经爱尔兰会计师认证
- **资金或收入性质：** 境外稳定收入+资产
- **首次身份与期限：** 按批准信，通常年度续
- **居住与续签：** 须自给自足
- **当地工作：** 未经许可不得就业、经营或从业
- **家属：** 家属通常各自满足
- **永居或入籍路径：** 通常不属可计入入籍的reckonable residence
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 不得依赖公共福利/公立医院；不是永居路径
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.irishimmigration.ie/coming-to-live-in-ireland/i-want-to-retire-to-ireland/)
- **本条核验日期：** 2026-09-02
