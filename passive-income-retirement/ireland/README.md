## Stamp 0 — retire / independent means

- **当前状态：** 开放
- **最低门槛或收入：** 个人稳定收入€50,000/年，另需足够应急一次性资金并经爱尔兰会计师认证
- **资金或收入性质：** 境外稳定收入+资产
- **首次身份与期限：** 按批准信，通常年度续
- **居住与续签：** 须自给自足
- **当地工作：** 未经许可不得就业、经营或从业
- **家属：** 家属通常各自满足
- **永居或入籍路径：** 不保证转永居或入籍计时。ISD现行入籍指南在可计入时间栏目中列有Stamp 0，与历史上常用的排除口径存在疑义；须按本人许可条件向ISD确认可计入期间
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 须在入境前获Stamp 0批准，并持覆盖私立医院的完整私人医疗保险；不得依赖公共福利；并非自动永居路径
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://www.irishimmigration.ie/coming-to-live-in-ireland/i-want-to-retire-to-ireland/)

- **补充来源：** [ISD居留印章条件](https://www.irishimmigration.ie/registering-your-immigration-permission/information-on-registering/immigration-permission-stamps/)、[现行入籍指南](https://www.irishimmigration.ie/how-to-become-an-irish-citizen-guide/)
