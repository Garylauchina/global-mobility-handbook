## Non-lucrative Residence Visa

- **当前状态：** 开放
- **最低门槛或收入：** 2026主申约€2,400/月（400% IPREM）；每家属约€600/月
- **资金或收入性质：** 被动收入/储蓄
- **首次身份与期限：** 首年1年，续2+2年
- **居住与续签：** 长期路径需实际居住
- **当地工作：** 明确不得工作，包括远程工作
- **家属：** 配偶/伴侣、受养子女/尊亲
- **永居或入籍路径：** 5年永居；一般10年入籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 住满183日通常全球所得纳税；远程工作者不应误用此签
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.exteriores.gob.es/Embajadas/nuevadelhi/en/ServiciosConsulares/Paginas/Consular/Visado-de-residencia-no-lucrativa.aspx)
- **本条核验日期：** 2026-09-02
