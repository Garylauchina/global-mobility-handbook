# 西班牙

[返回“被动收入与退休居留”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Non-lucrative Residence Visa

- **当前状态：** 开放
- **最低门槛或收入：** 2026主申约€2,400/月（400% IPREM）；每家属约€600/月
- **资金或收入性质：** 被动收入/储蓄
- **首次身份与期限：** 首年1年，续2+2年
- **居住与续签：** 续签要求在一个自然年内于西班牙真实有效居住超过183天，并维持医疗保险和足额资源
- **当地工作：** 明确不得工作，包括远程工作
- **家属：** 配偶/伴侣、受养子女/尊亲
- **永居或入籍路径：** 通常连续合法居住5年可申请长期居留；一般归化居住期10年，另有语言、融入和法定例外等条件，均非自动
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 居留续签的超过183天要求与税务居民判定分别适用；远程工作者不应误用此签
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.exteriores.gob.es/Embajadas/nuevadelhi/en/ServiciosConsulares/Paginas/Consular/Visado-de-residencia-no-lucrativa.aspx)

- **补充来源：** [长期居留法第32条](https://boe.es/buscar/act.php?id=BOE-A-2000-544#a32)；[民法典第22条](https://www.boe.es/buscar/act.php?id=BOE-A-1889-4763#art22)；[现行移民条例第64条](https://www.boe.es/buscar/act.php?id=BOE-A-2024-24099#a6-6)

## 政策时间线

- **2025-05-20（生效）：** 第1155/2024号皇家法令第64条明确非营利居留续签须每自然年实际居住超过183天，续签一般为2年。来源：[BOE现行条例](https://www.boe.es/buscar/act.php?id=BOE-A-2024-24099#a6-6)。
