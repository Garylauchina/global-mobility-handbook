## Settlement Permit — Gainful Employment Excepted

- **当前状态：** 开放/年度配额
- **最低门槛或收入：** 2026单身€2,616.78/月；夫妻/伴侣€4,128.24；每子女+€403.76，另需住房和保险
- **资金或收入性质：** 稳定自有收入/资产
- **首次身份与期限：** 通常1年续签；首次需A1德语
- **居住与续签：** 须真实定居
- **当地工作：** 不得进入劳动力市场
- **家属：** 配偶、子女分别申请
- **永居或入籍路径：** 合法定居5年可Daueraufenthalt-EU；入籍通常10年且严格
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 年度配额、住房成本和语言均为硬门槛
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.migration.gv.at/en/types-of-immigration/permanent-immigration/other-forms-of-settlement/)
- **本条核验日期：** 2026-09-02
