## M Visa — Pensionado

- **当前状态：** 开放
- **最低门槛或收入：** 终身养老金≥3 SMLMV/月
- **资金或收入性质：** 境外养老金
- **首次身份与期限：** M签证最长3年，可续
- **居住与续签：** 长期身份需实际合法停留
- **当地工作：** 依M签证权限
- **家属：** 可带受益家属
- **永居或入籍路径：** M类累计5年可申请R
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** SMLMV每年更新；养老金证明须认证
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.cancilleria.gov.co/node/26976)
- **本条核验日期：** 2026-09-02
