## Residence visa for the retired

- **当前状态：** 开放/酋长国差异
- **最低门槛或收入：** 年满55且工作满15年；联邦页列房产+储蓄各≥AED1m或年收入≥AED180k；迪拜收入门槛常为AED240k
- **资金或收入性质：** 房产、储蓄或退休收入
- **首次身份与期限：** 5年，可续
- **居住与续签：** 无传统PR/入籍计时
- **当地工作：** 本地受雇/经营须另守许可制度
- **家属：** 可按担保规则为家属办居留
- **永居或入籍路径：** 不自动PR或入籍
- **税务提示：** UAE无个人所得税，但原税籍、企业税和资产申报另核。
- **关键限制与变化：** 联邦与迪拜口径不同，应按递交酋长国确认
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://u.ae/en/information-and-services/visa-and-emirates-id/residence-visas/residence-visa-for-the-retired)
- **本条核验日期：** 2026-09-02
