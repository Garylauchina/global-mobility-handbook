# 巴拿马

[返回“被动收入与退休居留”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Pensionado

- **当前状态：** 开放
- **申请者身份限制：** 须有政府、国际组织或合资格私人机构支付的终身养老金；一般租金／投资收益不能自动替代养老金身份。现有官方法令本次未完整复取，特别国籍及其他现有居留转换限制仍待核实。
- **最低门槛或收入：** 终身养老金B/.1,000/月；每家属+B/.250；持> B/.100k房产时主门槛可降至B/.750
- **资金或收入性质：** 终身养老金
- **首次身份与期限：** 主申请人获无限期居留，无须延期；受养子女适用另列限制
- **居住与续签：** 维持养老金；归化需实际定居
- **当地工作：** 可依法生活；工作/执业按普通许可
- **家属：** 配偶及受养子女；夫妻可合并养老金满足主门槛。全日制在读受养子女只获临时居留至25岁，通常不享永久居留/退休身份；经证明的严重残疾子女有例外
- **永居或入籍路径：** 主申请人无限期居留不等于全家自动PR；普通归化另按国籍法评估
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 必须是真实终身养老金，不是一般投资收益
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.migracion.gob.pa/wp-content/uploads/02-JUBILADO-PENSIONADO-1.pdf)
