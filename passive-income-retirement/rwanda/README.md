## Permit Class K — Assured Income

- **当前状态：** 开放
- **最低门槛或收入：** 有稳定保证收入；官方未列统一固定最低额
- **资金或收入性质：** 养老金/保证收入
- **首次身份与期限：** 最长2年，可续
- **居住与续签：** 无自动PR承诺
- **当地工作：** 不得本地就业
- **家属：** 家属依附需个案申请
- **永居或入籍路径：** PR/入籍需按普通规则，不能承诺
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 公开透明度较低；先取得移民机关书面材料清单
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://www.migration.gov.rw/index.php?L=2&id=66)
- **本条核验日期：** 2026-09-02
