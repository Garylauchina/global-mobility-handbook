## Residence permit for pensioners

- **当前状态：** 开放
- **最低门槛或收入：** 养老金≥ALL1,200,000/年，并通过阿尔巴尼亚银行账户定期收款
- **资金或收入性质：** 境外养老金
- **首次身份与期限：** 1年，年度续
- **居住与续签：** 连续合法居住可累计长期身份
- **当地工作：** 完全禁止经济/职业活动
- **家属：** 配偶/伴侣可团聚
- **永居或入籍路径：** 连续合法居留5年可申请永久居留
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 须持续从境外收取养老金并保持保险/住址
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://mb.gov.al/wp-content/uploads/2024/10/Ligj-per-te-Huajt-%E2%80%93-nr.-79.2021_English.pdf)
- **本条核验日期：** 2026-09-02
