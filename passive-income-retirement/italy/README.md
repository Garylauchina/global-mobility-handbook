## Elective Residence Visa

- **当前状态：** 开放
- **申请者身份限制：** 适用于以稳定、持续非劳动收入生活的外国申请人，并非只向领取退休金者开放。驻外领馆清单须结合合法居住地和受理辖区使用，不能将某馆要求的当地居留解释为全体申请人的外国永久居民门槛；完整特殊国籍限制仍须另核。
- **最低门槛或收入：** 塔什干使馆2026年3月清单要求每名申请人（包括配偶）稳定被动收入至少€31,000/年；这是该馆清单，其他递交领馆须另核
- **资金或收入性质：** 稳定被动收入；该馆清单不接受受雇或自雇收入计入门槛
- **首次身份与期限：** D签后居留通常1年，年度续
- **居住与续签：** 长期身份需真实居住
- **当地工作：** 不得工作
- **家属：** 配偶及符合条件子女须分别办理；不能假设夫妻合计€31,000即满足该馆要求
- **永居或入籍路径：** 5年可EU长期居留；非EU入籍通常10年
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 领馆金额不是全国统一单一数字；递件地口径优先
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://ambtashkent.esteri.it/wp-content/uploads/2026/03/Residenza-elettiva_IT.pdf)
