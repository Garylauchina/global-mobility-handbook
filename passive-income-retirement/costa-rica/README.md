## Pensionado / Rentista Residence

- **当前状态：** 开放
- **最低门槛或收入：** Pensionado终身养老金US$1,000/月；Rentista稳定收入US$2,500/月通常覆盖2年
- **资金或收入性质：** 养老金或保证收入/存款
- **首次身份与期限：** 临时居留，通常2年续
- **居住与续签：** 保持资格并在当地建立居留
- **当地工作：** 可投资；受雇需转换/许可
- **家属：** 可带家属
- **永居或入籍路径：** 通常持临居3年可申请永久居留；入籍需实际居住
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** Rentista资金结构和家属覆盖需按DGME最新清单
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://www.visitcostarica.com/retirement)
- **本条核验日期：** 2026-09-02
