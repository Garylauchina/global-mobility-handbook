# 葡萄牙

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## D7 — retirement / own income

- **当前状态：** 开放
- **最低门槛或收入：** 2026主申€920/月；第二成人€460/月；每子女/受养成年子女€276/月，实践还看持续收入和资金覆盖
- **资金或收入性质：** 养老金、租金、股息等稳定收入
- **首次身份与期限：** 居留卡2年，续3年
- **居住与续签：** 长期路径需实际居住
- **当地工作：** 取得居留后原则可依法就业，但首签基础必须是稳定自有收入
- **家属：** 可家庭团聚
- **永居或入籍路径：** 永居5年；2026国籍法下多数非EU/CPLP通常10年
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 旧NHR税制不可假定适用；最低工资每年更新
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.gov.pt/servicos/pedir-um-visto-de-residencia-para-fixacao-de-residencia-de-reformados-religiosos-e-pessoas-que-vivem-de-rendimentos-proprios)
- **本条核验日期：** 2026-09-02
