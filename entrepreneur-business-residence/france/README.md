# 法国

## Talent-porteur de projet — investissement économique

- **当前状态：** 开放
- **最低门槛或收入：** 本人直接投资，或通过本人管理/持股至少30%的公司，在法国投入至少€300k有形或无形固定资产，并创造、保留或承诺在投资后4年内创造或保留就业岗位
- **资金或收入性质：** 已投入或有约束力承诺的直接经济投资；须提交商业计划、年度就业安排和资金证明
- **首次身份与期限：** 预计少于12个月通常为需入境后验证的VLS-TS；预计至少1年则先获长期签证后申领多年期卡，卡最长4年
- **居住与续签：** 没有本路径单独公布的年度最低天数，但须真实执行投资和就业计划；发卡后1年内项目完全未启动或资金来源非法，居留卡可被撤销
- **当地工作：** 主申请人获准从事与核准经济投资项目相关的商业活动，不应理解为与项目无关的无限制就业许可
- **家属：** 配偶及未成年子女可走简化的Talent-famille而非普通家庭团聚；配偶卡原则上允许受雇或自雇，期限通常随主卡
- **永居或入籍路径：** 欧盟长期居民一般要求5年合法连续居住、稳定资源、医保、语言和融入，离境受限；普通归化一般以5年惯常居住为基准并接受其他条件和裁量审查
- **税务提示：** 家庭住所/主要停留地、主要职业活动或经济利益中心任一因素均可能形成法国税务住所；税务居民原则上申报全球所得，双重居民按税收协定处理
- **关键限制与变化：** 不是零居住黄金签证；续签和长期身份均取决于项目落地、就业证明、实际居住和整体合规，不保证因投入€300k自动续签或归化
- **证据等级：** A
- **主要来源：** [Service-Public项目页](https://www.service-public.gouv.fr/particuliers/vosdroits/F16922)；[CESEDA L421-16](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000049052499/)；[CESEDA R421-35至R421-36](https://www.legifrance.gouv.fr/codes/section_lc/LEGITEXT000006070158/LEGISCTA000042801016/)
- **本条核验日期：** 2026-09-02
