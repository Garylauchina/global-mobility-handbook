## Citizenship by Investment

- **当前状态：** 已公告金额／待正式收件确认
- **申请者身份限制：** 当前缺少可据以判断新申请资格的有效专项入口或完整执行规则；国籍、外国永居、居住地及职业身份范围仍待核实，不因一般入境或其他居留资格成立就认定此项目可办。
- **关键变化：** 2026-10-02政府宣布拟于2026年第四季度开始接收申请：主申向国库不退还贡献US$350,000，或认购专设US$800,000国债；配偶及18–25岁未婚无子女子女各贡献US$100,000，未满18岁子女各US$25,000。公告未给出准确开放日、国债持有条件和完整办理入口
- **为什么不能按有效项目处理：** 公告金额已明确，不能再说门槛完全未公布；但第四季度计划不等于已有可验证的实际收件入口，仍需完整实施规范及国籍/安全审查细则
- **证据等级：** B
