## Citizenship by Investment

- **当前状态：** 已关闭
- **申请者身份限制：** 当前不作为可新递交方案判断身份资格；旧国籍、永居或居住条件即使满足，也不能恢复新申请入口。存量案件如有过渡安排，须核对本人原申请／许可。
- **关键变化：** 2022-12-31到期，未续期
- **为什么不能按有效项目处理：** 旧项目地产名录不得用于招揽新申请
- **证据等级：** B
- **主要来源：** [政府原项目启动公告](https://www.gov.me/en/article/195254--development-programme-for-acquisition-of-montenegrin-citizenship-by-admission-for-investment-purposes-launched)；[2022-09-29内阁确认计划于2022-12-31终止](https://www.gov.me/en/article/the-21st-cabinet-session-29-september-2022)
