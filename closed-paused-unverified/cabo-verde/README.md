## 旧 Remote Working Cabo Verde

- **当前状态：** 旧版历史方案；现有法定远程活动居留框架
- **关键变化：** 2020年的6+6个月旅游推广计划应与2025-05-16生效的远程专业活动居留框架分别理解
- **为什么不能按有效项目处理：** 主表采用新法；旧€1,500/€2,700财力示例不能作为新居留框架门槛；新法第35条要求海外工作/服务关系、近3个月收入证明及税务居所文件，未在该条列统一金额
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.governo.cv/cabo-verde-lanca-programa-remote-working-e-nomadas-digitais-para-diversificar-e-desconcentrar-a-oferta-turistica/)

- **补充来源：** [第13/2025号法令及重刊第2/2015号法令第35条](https://boe.incv.cv/Bulletins/DownloadAct?id=85465)

## 政策时间线

- **2025-05-16（生效）：** 第13/2025号法令将面向境外的远程专业活动居留签证程序纳入现行规则；应按法定居留要求处理，不沿用2020旅游计划的财力与期限。来源：[2025-05-15官方公报，第7条及附件第35条](https://boe.incv.cv/Bulletins/DownloadAct?id=85465)。
