# 奥地利

[返回警示目录](../README.md) · [返回仓库首页](../../README.md)

> 本目录用于阻止停办、暂停、被替代或只有营销材料的项目被误列为当前可办方案。有限公开检索不能证明法律上的绝对不存在。

## 所谓固定价“投资入籍”

- **当前状态：** 不存在标准项目
- **申请者身份限制：** 当前缺少可据以判断新申请资格的有效专项入口或完整执行规则；国籍、外国永居、居住地及职业身份范围仍待核实，不因一般入境或其他居留资格成立就认定此项目可办。
- **关键变化：** 国籍法仅允许因共和国特殊利益和杰出成就个案例外
- **为什么不能按有效项目处理：** 无官方价目、时限或保证；营销固定金额不可信
- **证据等级：** A
