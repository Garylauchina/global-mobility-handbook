## Remote Employment Permit

- **当前状态：** 有法律/未确认开放
- **申请者身份限制：** 当前缺少可据以判断新申请资格的有效专项入口或完整执行规则；国籍、外国永居、居住地及职业身份范围仍待核实，不因一般入境或其他居留资格成立就认定此项目可办。
- **关键变化：** 2021法案已列资格及附表申请书/费用，但当前受理渠道与实施状态尚未确认
- **为什么不能按有效项目处理：** 不能仅凭法律文本当作已可递交
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://grenadaparliament.gd/wp-content/uploads/2021/07/Act-No.-3-of-2021-Remote-Employment.pdf)
