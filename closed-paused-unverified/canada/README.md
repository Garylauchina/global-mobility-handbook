# 加拿大

[返回警示目录](../README.md) · [返回仓库首页](../../README.md)

> 本目录用于阻止停办、暂停、被替代或只有营销材料的项目被误列为当前可办方案。有限公开检索不能证明法律上的绝对不存在。

## Federal Immigrant Investor / Entrepreneur Programs

- **当前状态：** 已终止
- **关键变化：** 2014年联邦立法终止大部分积压及项目
- **为什么不能按有效项目处理：** 当前不存在联邦被动投资换PR
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.canada.ca/en/immigration-refugees-citizenship/news/notices/notice-update-returns-applications-affected-termination-immigrant-investor-program-federal-entrepreneur-program.html)

## Start-up Visa

- **当前状态：** 暂停新申请
- **关键变化：** 2026-06-30停止接收新申请；此前已经接受的申请继续处理
- **为什么不能按有效项目处理：** 旧承诺或存量审理不构成现在新递交SUV的资格；其他创业路径须另查现行收件规则
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.canada.ca/en/immigration-refugees-citizenship/services/immigrate-canada/start-visa/about.html)
