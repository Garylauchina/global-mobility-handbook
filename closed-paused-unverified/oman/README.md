## Retirement / Passive-income Visa

- **当前状态：** 未确认
- **申请者身份限制：** 当前缺少可据以判断新申请资格的有效专项入口或完整执行规则；国籍、外国永居、居住地及职业身份范围仍待核实，不因一般入境或其他居留资格成立就认定此项目可办。
- **关键变化：** 外交部2021-09-29历史公告明确投资者及退休人士可申请长期居留；现行Golden Residency门户主要列投资、房产、证券、存款及雇员等分支，未提供可重建的退休分支完整条件。不能将历史存在与当前可按纯养老金递交混为一谈
- **为什么不能按有效项目处理：** 不要使用第三方未确认的退休收入数字
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://omanresidence.gov.om/en-us/)

- **补充来源：** [外交部2021年投资者及退休人士居留公告](https://archive.fm.gov.om/en/1780/)

## 政策时间线

- **2021-09-29（公告）：** 官方历史说明将退休人士纳入长期投资者居留介绍，但该公告未列出退休分支完整现行资格，不能单独据以申请。来源：[外交部历史公告](https://archive.fm.gov.om/en/1780/)。
