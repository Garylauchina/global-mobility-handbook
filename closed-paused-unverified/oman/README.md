## Retirement / Passive-income Visa

- **当前状态：** 未确认
- **申请者身份限制：** 当前缺少可据以判断新申请资格的有效专项入口或完整执行规则；国籍、外国永居、居住地及职业身份范围仍待核实，不因一般入境或其他居留资格成立就认定此项目可办。
- **关键变化：** 现行官方门户以投资Golden Residency为核心，未见仅凭养老金的全国项目
- **为什么不能按有效项目处理：** 不要使用第三方未确认的退休收入数字
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://omanresidence.gov.om/en-us/)
