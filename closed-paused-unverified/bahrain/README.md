## Golden Residency 旧房产门槛（历史纠错）

- **当前状态：** 现行项目开放；旧门槛已过时
- **关键变化：** NPRA 当前总入口与专项官网均采用 BHD130,000 的购置时房产总值；BHD200,000 仅作为本站此前引用的旧门槛保留历史记录，不再称为现行官方冲突
- **为什么不能按有效项目处理：** 本页仅归档旧金额，现行方案见[投资永居目录的巴林页](../../investment-permanent-residence/bahrain/README.md)。不能据旧金额宣称项目暂停，也不能把旧页冲突沿用为当前状态
- **证据等级：** B
- **主要来源：** [NPRA 当前黄金居留条件](https://www.npra.gov.bh/en/services/visas-residence-permit/residence-permits-services/golden-residency/)；[专项官网资格](https://goldenresidency.gov.bh/eligibility-criteria/)；[官方或主要依据](https://goldenresidency.gov.bh/news/bahrain-lowers-minimum-real-estate-investment-for-golden-residency-to-usd-345000/)
