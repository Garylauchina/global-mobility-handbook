## Malaysia My Second Home (MM2H)

- **当前状态：** 开放
- **最低门槛或收入：** Silver：FD US$150k+房产RM600k；Gold：US$500k+RM1m；Platinum：US$1m+RM2m
- **资金或收入性质：** 定期存款+强制购房
- **首次身份与期限：** 分别5年、15年、20年，可续
- **居住与续签：** 25–49岁家庭每年合计通常90天
- **当地工作：** Silver/Gold本地工作受限；Platinum权限更宽，须按批文
- **家属：** 配偶、符合条件子女及父母/岳父母
- **永居或入籍路径：** 长期社交访问准证，不自动通PR或入籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 不同等级、特别经济区规则及取款条件复杂；必须用官方最新清单
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.mm2h.gov.my/category/overview)
- **本条核验日期：** 2026-09-02
