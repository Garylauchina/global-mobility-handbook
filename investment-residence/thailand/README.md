## LTR — Wealthy Global Citizen

- **当前状态：** 开放
- **最低门槛或收入：** 全球资产≥US$1m；泰国政府债/FDI/房产≥US$500k，并满足收入等资格
- **资金或收入性质：** 泰国资产+全球财富/收入
- **首次身份与期限：** 10年，通常分两个5年期
- **居住与续签：** 维持资格；有定期报告要求
- **当地工作：** 可按LTR规则工作，工作许可另办
- **家属：** 配偶、未满20岁子女
- **永居或入籍路径：** 不是PR或入籍捷径
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 还须保险或合资格存款；资格为多重条件，不是单一US$500k
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://ltr.boi.go.th/)
- **本条核验日期：** 2026-09-02
