## Guest Investor Residence Permit

- **当前状态：** 开放
- **最低门槛或收入：** €250k合资格房地产基金份额并锁定至少5年；或向指定高等教育公益信托捐赠€1m
- **资金或收入性质：** 基金或捐赠；直接购房€500k路线已删除
- **首次身份与期限：** 最长10年，可再延10年
- **居住与续签：** 维持许可无最低停留要求
- **当地工作：** 可工作/经商
- **家属：** 可家庭团聚
- **永居或入籍路径：** 不自动转永居/国籍；长期身份需真实居住、连续性和融入
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 只能选现行基金/捐赠路线；旧直接购房宣传无效
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://oif.gov.hu/factsheets/residence-permit-for-guest-investor)
- **本条核验日期：** 2026-09-02
