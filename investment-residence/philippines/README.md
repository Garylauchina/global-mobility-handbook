## Special Investor’s Resident Visa (SIRV)

- **当前状态：** 开放
- **最低门槛或收入：** US$75,000投入合资格企业
- **资金或收入性质：** 企业股权投资
- **首次身份与期限：** 投资存续期间可无限期居留、多次入境
- **居住与续签：** 持续维持合资格投资
- **当地工作：** 可经营/管理投资；受雇权限另核
- **家属：** 配偶、未婚未满21岁子女
- **永居或入籍路径：** 特殊非移民签证，不等同普通PR或直接入籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 必须为合资格经济活动；投资价值和持续性受审查
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://boi.gov.ph/resources/faqs/)
- **本条核验日期：** 2026-09-02
