## Special Investor’s Resident Visa (SIRV)

- **当前状态：** 开放
- **申请者身份限制：** 【部分待核实】SIRV实施规则允许年满21岁的外国人申请，但明确排除外交部认定不得获发签证国家的国民，并有犯罪、健康等准入条件。本次未取得外交部完整现行排除名单，不能简写成“任何国籍均可申请”。
- **最低门槛或收入：** US$75,000投入合资格企业
- **资金或收入性质：** 企业股权投资
- **首次身份与期限：** 一般先获6个月试用SIRV；将US$75,000按期转成获准投资并提交证明后，才可转为投资及资格持续期间无限期、多次入境的SIRV
- **居住与续签：** 必须持续维持获准股权投资并提交年度报告和投资／企业合规证明；未完成投资或不符合条件可撤销
- **当地工作：** 投资资格本身不能代替工作许可；司法机关收录的劳动规则明确SIRV从事执行、顾问、监督或技术职位须AEP，具体职务的现行许可或豁免须向DOLE核实
- **家属：** 配偶、未婚未满21岁子女
- **永居或入籍路径：** 投资条件下的特殊居留；无限期逗留依赖持续投资与资格，不承诺普通永久居民或直接入籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 一般须先汇入Land Bank或DBP指定定存，随后按期转换合资格公司股权；普通购房不能代替该投资。应区分6个月试用、无限期SIRV和独立的旅游项目SIRV规则
- **证据等级：** B
- **主要来源：** [BOI官方问答](https://boi.gov.ph/resources/faqs/)；[最高法院收录SIRV修订规则](https://elibrary.judiciary.gov.ph/thebookshelf/showdocs/10/41709)；[驻纽约总领馆SIRV表格和承诺书](https://newyorkpcg.dfa.gov.ph/images/2023uploads/FORMS/VISA/SIRV-Checklist-Application-Forms.pdf)；[司法机关收录的工作许可说明](https://elibrary.judiciary.gov.ph/thebookshelf/showdocs/10/78484)
