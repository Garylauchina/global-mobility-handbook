## Premium Residency — Real Estate Owner

- **当前状态：** 开放
- **最低门槛或收入：** 合资格住宅/指定期房价值≥SAR4m
- **资金或收入性质：** 房地产；通常不得抵押，期房有付款要求
- **首次身份与期限：** 期限与房产所有权或用益权挂钩
- **居住与续签：** 持续持有合资格房产
- **当地工作：** 可按Premium Residency规则经营/工作
- **家属：** 配偶、父母和符合年龄规则子女
- **永居或入籍路径：** 不自动取得国籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 出售或资格消失会影响身份；须核验估值和项目资格
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://pr.gov.sa/product-details-real-estate-residency)
- **本条核验日期：** 2026-09-02
