# 沙特阿拉伯

[返回“投资居留”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

> **待补证事项：** 现行FAQ有第一年10天、之后5天的最低停留，而详细条件无此条；必须由中心厘清适用版本

## Premium Residency — Real Estate Owner

- **当前状态：** 开放
- **申请者身份限制：** 【部分待核实】房地产所有权／用益权与合资格期房为不同分支，须核对申请人本人持有权益。现行门户本次未完整返回一般身份规则，特别国籍、年龄及现有沙特居留合法性要求仍待主管机关确认。
- **最低门槛或收入：** 已有住宅所有权／用益权总值至少SAR4m；另一类别为单一合资格期房住宅至少SAR4m，已付款至少SAR1m或总价10%两者较高者。项目一次性费用SAR4,000
- **资金或收入性质：** 已有物业须为住宅、非土地且不得现有或日后抵押；期房须为房地产主管机关批准开发商的合资格项目，不能以抵押融资或日后抵押
- **首次身份与期限：** 现有住宅类别与所有权／用益权挂钩；期房类别与购房合同持续有效挂钩，须在签约后5年内完成产权转移并继续持有
- **居住与续签：** 须持续符合物业或期房条件；官方FAQ列第一年至少10天、其后每年至少5天，但当前详细条件页未列该项，二者适用口径须向中心核实
- **当地工作：** 可按Premium Residency规则经营/工作
- **家属：** 配偶、未满25岁子女及不在沙特工作的父母，均须符合中心详细条件及一般申请要求
- **永居或入籍路径：** 房产类别并非永久Premium Residency；与合资格房产持续挂钩，也不自动取得国籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 出售／转让后通常须在90天内以合资格房产替换或续展用益权，否则可能撤销；期房5年内未完成产权也有取消风险。官方FAQ与详细条件的最低停留口径未一致
- **证据等级：** B
- **主要来源：** [现行房产业主产品页](https://pr.gov.sa/pr?id=pr_product_details_real_estate_owner)；[官方FAQ](https://pr.gov.sa/pr?id=faqs)；[详细条件与规则（房产业主类别）](https://pr.gov.sa/pr?id=conditions_controls)
