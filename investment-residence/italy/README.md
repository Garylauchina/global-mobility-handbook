## Investor Visa for Italy

- **当前状态：** 开放
- **最低门槛或收入：** 创新初创€250k；意大利公司€500k；公益捐赠€1m；国债€2m
- **资金或收入性质：** 股权、捐赠或国债；入境后3个月内完成
- **首次身份与期限：** 2年居留，维持投资可续3年
- **居住与续签：** 无专属低停留捷径；长期身份需实际居住
- **当地工作：** 可依法工作/经商
- **家属：** 可按家庭团聚规则
- **永居或入籍路径：** 实际居住5年可争取EU长期居民；非EU入籍通常10年
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 俄/白俄护照申请受暂停限制；必须持续投资
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://investorvisa.mise.gov.it/index.php/en/)
- **本条核验日期：** 2026-09-02
