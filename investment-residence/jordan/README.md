# 约旦

[返回“投资居留”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

> **待补证事项：** 房产居留工作权、家属年龄和依赖范围及完整实施细则未取得直接现行官方证据；不能计完整核验

## Investor Property Residence

- **当前状态：** 开放
- **申请者身份限制：** 【部分待核实】2026政府公告适用于外国购房投资者，但未完整说明受限国籍、已有约旦居留及家属身份条件；房产所在地区和卖方类别合格，不等于主申请人的身份资格已经确定。
- **最低门槛或收入：** 从开发商或住房公司购买房产至少JD200k；其他卖家至少JD300k；首都省以外至少JD150k且不限制卖家类型。由土地测量部门估值，须持有至少5年且不得出售或抵押
- **资金或收入性质：** 房地产
- **首次身份与期限：** 5年可续居留
- **居住与续签：** 持续符合房产条件；2026-07-15内阁公告明确，授予或续签5年居留不取决于此前在约旦停留时长
- **当地工作：** 依一般许可
- **家属：** 房产居留配偶及子女的具体随行范围，当前公开内阁公告未完整列明，须向内政部核实；不能套用同一公告的投资入籍家属范围
- **永居或入籍路径：** 不自动取得国籍；与投资入籍路线不同
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 2026-07-15内阁公布房产区域、卖方及金额规则；违反条件可撤销居留。工作权、家属范围及具体递件细则仍需主管机关确认
- **证据等级：** B
- **主要来源：** [约旦首相府2026-07-15内阁公告](https://www.pm.gov.jo/AR/NewsDetails/am0847)；[Petra官方通讯社](https://petra.gov.jo/candid/htdocs/index.php/en/news/government-revamps-investor-citizenship-rules-to-funnel-capital-into-provinces)

## 政策时间线

### 2026-07-15 — 内阁公布分地区及卖方的房产居留标准

- **来源日期：** 首相府2026-07-15内阁公告
- **变化摘要：** 开发商/住房公司JD200k、其他卖家JD300k、首都省外JD150k；房产须持有5年且不得出售或抵押，5年居留的授予及续签不取决于此前停留时长
- **适用边界：** 房产居留与同一公告中的投资入籍规则分开；工作及家庭受养细则仍须主管机关确认
- **官方依据：** [首相府内阁公告](https://www.pm.gov.jo/AR/NewsDetails/am0847)
- **事件证据：** A
