# 约旦

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Investor Property Residence

- **当前状态：** 开放
- **最低门槛或收入：** 开发商房产JD200k；私人卖家JD300k；安曼以外JD150k；通常无抵押并持有5年
- **资金或收入性质：** 房地产
- **首次身份与期限：** 5年可续居留
- **居住与续签：** 持续持有房产
- **当地工作：** 依一般许可
- **家属：** 家庭可按批文随行
- **永居或入籍路径：** 不自动取得国籍；与投资入籍路线不同
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 2026新规刚调整，房产区域与来源须确认
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://petra.gov.jo/candid/htdocs/index.php/en/news/government-revamps-investor-citizenship-rules-to-funnel-capital-into-provinces)
- **本条核验日期：** 2026-09-02
