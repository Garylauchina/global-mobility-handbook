# 卡塔尔

[返回“投资居留”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

> **待补证事项：** 当前房产路线工作许可和家属年龄/受养证明实施细节未完整公开或取得

## Real Estate Residency

- **当前状态：** 开放
- **申请者身份限制：** 属于非卡塔尔人的指定区域购房及相应居留权益制度；外国人可购范围不是全境房产。所引官方说明未确认完整国籍排除名单，购房资格、居留权益和永久居民身份须分别判断。
- **最低门槛或收入：** 合资格房产价值至少QAR730,000可申请免担保人居留；至少QAR3.65m可另取得永久居民卡持有人的医疗、教育、投资福利
- **资金或收入性质：** 房地产
- **首次身份与期限：** 国家人权委员会指南列房产所有人／用益权人可获5年居留并续同等期限；QAR3.65m档描述的是永久居民卡福利，不应直接写成永久居民身份
- **居住与续签：** 司法部对两档均明确每年在卡塔尔至少90天，可连续或分段，须持续符合物业及居留资格
- **当地工作：** 依居留及许可
- **家属：** 国家人权委员会指南列配偶、子女和父母可获居留；房产路线具体年龄、受养证明及申请程序仍须向内政部核实
- **永居或入籍路径：** QAR3.65m房产提供指定永久居民卡福利，不等于直接授予永久居民卡或自动入籍
- **税务提示：** 卡塔尔个人税制与原税籍、业务来源另判。
- **关键限制与变化：** 购买范围、估值和产权资格须获认可；指定区域之外部分住宅小区独立单位及商场办公室／商铺也有规则，不能把所有房产都视为合资格。当地受雇许可和家属细则公开材料仍不完整
- **证据等级：** B
- **主要来源：** [司法部房产居留及两档福利](https://www.moj.gov.qa/en/departments/non-qatari-ownership-and-use-real-estate)；[国家人权委员会指南第70页](https://www.nhrc-qa.org/storage/publications/file_6666d6f57f82d_1718015733.pdf)
