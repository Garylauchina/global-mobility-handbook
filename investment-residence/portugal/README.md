# 葡萄牙

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## ARI 投资居留

- **当前状态：** 开放
- **最低门槛或收入：** 10个岗位；文化€250k；科研€500k；非房地产基金€500k；公司资本/就业€500k
- **资金或收入性质：** 捐赠、基金、科研或企业投资；房地产及单纯资本转移已取消
- **首次身份与期限：** 通常2年临时居留并可续
- **居住与续签：** 首年7天；以后每个2年期14天
- **当地工作：** 可依法工作/经商
- **家属：** 可家庭团聚
- **永居或入籍路径：** 永居通常5年并另满足语言等；2026国籍法下多数非EU/CPLP通常10年，旧案有过渡
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 房地产和资本转移旧路线已取消；基金须非房地产并满足期限/配置；国籍规则刚变
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://aima.gov.pt/en/viver/autorizacao-de-residencia-para-investimento-art-90-o-a)
- **本条核验日期：** 2026-09-02
