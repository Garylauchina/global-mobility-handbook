## ARI 投资居留

- **当前状态：** 待复核（原记录：开放）
- **状态说明：** 开放
- **申请者身份限制：** AIMA明确本制度不适用于葡萄牙、EU／EEA、安道尔及瑞士国民；符合条件的其他外国申请人仍须满足合法入境和一般居留要求。其他国家永久居留与这些国家国籍不同；多本护照须按官方材料要求披露。
- **最低门槛或收入：** 10个岗位；文化€250k；科研€500k；非房地产基金€500k；公司资本/就业€500k。合资格低密度地区就业可降至8个岗位、科研可降至€400k；文化路线低密度优惠的当前AIMA文字存在百分比与金额矛盾，不能据此承诺具体优惠额
- **资金或收入性质：** 捐赠、基金、科研或企业投资；房地产及单纯资本转移已取消
- **首次身份与期限：** 通常2年临时居留并可续
- **居住与续签：** 首年7天；以后每个2年期14天；续签还须维持合资格投资、税费/社保合规、健康保障、生活来源及住宿证明
- **当地工作：** 可依法工作/经商
- **家属：** 可家庭团聚
- **永居或入籍路径：** 永居通常5年并另满足语言等；2026-05-19生效国籍法下EU/CPLP国民通常7年、其他国民通常10年；生效前已在审申请适用旧法，均非自动获籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 【部分待核实】AIMA文化低密度条款同时写“减20%”与“€220k”，与€250k基准不相符；须按现行法条及主管机关确认，本站保留标准金额。房地产和资本转移旧路线已取消；基金须非房地产、到期不少于5年，且至少60%投资于葡萄牙公司；取得独立永久居留后依该身份本身及批文条件审查，不能直接沿用ARI续签口径
- **证据等级：** B
- **主要来源：** [AIMA投资居留](https://aima.gov.pt/en/viver/autorizacao-de-residencia-para-investimento-art-90-o-a)；[AIMA续签及停留FAQ](https://aima.gov.pt/pt/a-aima/perguntas-frequentes-faqs/autorizacao-de-residencia-para-investimento-ari)；[司法部2026国籍法说明](https://justica.gov.pt/en-gb/Noticias/Lei-da-Nacionalidade-novas-regras-entram-em-vigor-a-19-de-maio)

## 政策时间线

### 2026-05-19 — 国籍法居住年限调整

- **公布与生效：** 司法部说明新国籍法自2026-05-19生效
- **变化摘要：** 通常归化的合法居住门槛为EU/CPLP国民7年、其他国民10年；ARI及永久居留不等于自动取得国籍
- **过渡安排：** 新法生效前已在审申请适用旧法
- **官方依据：** [司法部新国籍法说明](https://justica.gov.pt/en-gb/Noticias/Lei-da-Nacionalidade-novas-regras-entram-em-vigor-a-19-de-maio)
