# 印度尼西亚

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Golden Visa — Investors

- **当前状态：** 开放
- **最低门槛或收入：** 不设公司个人：US$350k/5年或US$700k/10年；创办企业：US$2.5m/5年或US$5m/10年
- **资金或收入性质：** 政府债券/公司股票/存款或企业资本
- **首次身份与期限：** 5年或10年有限居留
- **居住与续签：** 持续维持投资
- **当地工作：** 按投资活动；受雇另核
- **家属：** 家属另办家庭类居留
- **永居或入籍路径：** 不自动取得永久居留或国籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 签证子类别和合资格资产须在移民目录逐项确认
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.imigrasi.go.id/wna/daftar-visa-indonesia)
- **本条核验日期：** 2026-09-02
