# 阿曼

> **待补证事项：** 续签、离境期限、受雇许可、具体家属证明边界未获完整规则

## Golden Residency

- **当前状态：** 开放/需预审
- **最低门槛或收入：** 商务、工业和投资促进部2025-09-13说明最低投资为OMR200,000；路径包括企业、旅游综合体房产、债券／股票、定存、雇用至少50名阿曼人或获投资企业提名，具体路径条件另核
- **资金或收入性质：** 多类投资
- **首次身份与期限：** 10年，可续
- **居住与续签：** 10年期可续；须继续符合获批路径及居留规则，公开项目介绍未完整列明离境上限和续签材料，不应推定零停留要求
- **当地工作：** 商务部明确可全资拥有并管理企业；受雇于其他企业的工作许可范围未在项目介绍中完整列明
- **家属：** 商务部公开说明家属不设年龄或人数限制；亲属关系及受养资格材料仍须向办理机关确认
- **永居或入籍路径：** 非国籍项目
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 现行黄金居留自2025-08-31推出；2025-09-13官方说明房产投资路径为综合旅游区内已建成住宅，不能把取得身份后的区外购房权益当作所有区外房产均可申办；旧250k／500k双档资料不能代替新计划预审
- **证据等级：** B
- **主要来源：** [黄金居留门户](https://omanresidence.gov.om/en-us/)；[商务部2025-09-13说明](https://tejarah.gov.om/en/media/news/m4peoqcsjjn94obkfvjym0mg)
