> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Golden Residency

- **当前状态：** 开放/需预审
- **最低门槛或收入：** 2025/26新版总体最低约OMR200k；企业、旅游综合体房产、债券/股票、定存、就业或企业提名等
- **资金或收入性质：** 多类投资
- **首次身份与期限：** 10年，可续
- **居住与续签：** 维持合资格投资；未见统一年度最低停留
- **当地工作：** 依项目可经营/工作
- **家属：** 官方称家属人数/年龄限制较宽
- **永居或入籍路径：** 非国籍项目
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 旧OMR250k/500k资料已过时；各路径需在官方门户预审确认
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://omanresidence.gov.om/en-us/)
- **本条核验日期：** 2026-09-02
