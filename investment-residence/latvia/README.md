# 拉脱维亚

[返回“投资居留”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Investor Temporary Residence

- **当前状态：** 公司投资开放；房产及银行次级负债的新申请渠道将于2026-09-15停止，旧申请与持证人有过渡安排；国债渠道已于2026-05-20删除
- **最低门槛或收入：** 公司资本€50k/€100k+国家款€10k；在2026-09-15新法生效前仍适用的房产路线为€250k+5%、银行次级负债€280k/至少5年+€25k；国债不再列作新申请选项
- **资金或收入性质：** 公司股本须符合企业规模及纳税条件；房产须符合地点、产权、地籍价值及非农林地限制，并以非现金方式支付；银行路线为法定次级负债，不是普通存款
- **首次身份与期限：** 现行投资临时居留最长5年并按规定登记；2026-09-15起公司投资新许可最长2年，旧案适用过渡安排
- **居住与续签：** 持续维持投资；€50k公司通常每年实缴税至少€40k，€100k公司路线至少€100k。房产/银行旧持证人须在有效期内申请，维持旧法投资资格并依过渡条款缴款；转长期身份另须实际连续居住
- **当地工作：** 现行法Article9(5)对公司、房产、银行投资许可及其家属授予不受雇主限制的工作权；新法Article44(23)也保留公司投资者不受限制的工作权，房产/银行旧案过渡续签明确保留同类权利
- **家属：** 现行规则包括配偶、本人或配偶的未成年子女及法定受监护人，家属许可不超过主申请人期限
- **永居或入籍路径：** 欧盟长期居民须至少5年实际连续合法居住、稳定足够生活来源及A2语言，通常连续离境不超过6个月、合计不超过10个月，非持卡满5年自动取得
- **税务提示：** 税籍与居留许可分开判断；申报住所位于拉脱维亚，或在始于/终于该税年的任意12个月内停留至少183天，均可构成税务居民；双重税籍按税收协定处理。
- **关键限制与变化：** 俄/白俄国民只能按现行法列明的例外申请，不能直接套用普通投资渠道。部分PMLP英文页及英文译法仍保留已删除国债条款；新法09-15生效前递交的临时居留申请按旧法审理，生效不等于既有卡统一立即失效
- **证据等级：** A
- **主要来源：** [现行法Article9/23/23.1](https://likumi.lv/ta/id/68522-imigracijas-likums)；[2026-05-20生效修法](https://likumi.lv/ta/id/368122-grozijumi-imigracijas-likuma)；[2026-09-15生效的新法与过渡第4–10条](https://likumi.lv/ta/id/370622-imigracijas-likums)；[PMLP路线说明（含未更新国债项）](https://www.pmlp.gov.lv/en/how-long-may-residence-permit-be-issued-0)；[欧盟长期居民条件](https://www.pmlp.gov.lv/en/long-term-resident-status-european-community-latvia)；[VID税务居民](https://www.vid.gov.lv/lv/latvijas-rezidenti-arvalstis)

## 政策时间线

### 2026-09-15 — 新移民法将关闭房产及银行次级负债的新申请渠道

- **公布与生效：** 新法于2026-08-20通过、2026-09-01公布，将于2026-09-15生效；这是已公布尚未生效的变化
- **变化摘要：** 第27(1)(10)保留公司投资，初次许可最长2年；房产及次级负债不再列为新申请理由
- **过渡安排：** 生效前已递交的临时居留申请按旧法处理；既有房产/银行许可及家属依过渡第10条可申请最长5年续期，须在原许可有效期内递交、继续满足原投资条件并缴纳法定款项。不能据此保证尚未递交者获批
- **官方依据：** [新移民法第27条及过渡条款](https://likumi.lv/ta/id/370622-imigracijas-likums)
- **事件证据：** A

### 2026-05-20 — 国债投资居留条款删除

- **变化摘要：** 2026-04-23通过的修法删除原第23(1)(31)条，€250k国债加€38k国家款不再作为新申请渠道
- **官方依据：** [修法第7项与生效记录](https://likumi.lv/ta/id/368122-grozijumi-imigracijas-likuma)
- **事件证据：** A
