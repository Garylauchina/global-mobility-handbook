# 拉脱维亚

## Investor Temporary Residence

- **当前状态：** 开放
- **最低门槛或收入：** 公司资本€50k/€100k+国家款€10k；房产€250k+5%；银行次级负债€280k/5年+€25k；国债€250k+€38k
- **资金或收入性质：** 公司股本、房产、银行工具或国债
- **首次身份与期限：** 临时居留最长5年，按规定登记/换卡
- **居住与续签：** 维持投资；转长期身份须实际连续居住
- **当地工作：** 依许可可经商；受雇另核
- **家属：** 配偶及受养子女
- **永居或入籍路径：** 5年后长期居民非自动，须语言和实际居住
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 俄/白俄国民及关联资金受更强限制；各路线附加政府款
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.pmlp.gov.lv/en/how-long-may-residence-permit-be-issued-0)
- **本条核验日期：** 2026-09-02
