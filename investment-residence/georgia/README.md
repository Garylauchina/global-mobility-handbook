# 格鲁吉亚

[返回“投资居留”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Short-Term Residence Permit (property)

- **当前状态：** 开放
- **申请者身份限制：** 须由外国申请人持有合资格不动产并满足居留申请条件；合法停留及是否可从当前入境身份递交须另核，不能把第三国签证、永居带来的入境便利等同于居留申请资格。现有来源未确认完整特别国籍限制。
- **最低门槛或收入：** 非农业房地产市值>US$150,000
- **资金或收入性质：** 房地产持续持有
- **首次身份与期限：** 通常1年，可续
- **居住与续签：** 官方项目页未列统一年度最低天数
- **当地工作：** 短期房产居留不等同于投资居留的劳动许可豁免；就业/自雇须另按现行劳动移民法取得工作权或满足适用豁免
- **家属：** 配偶及子女可随行
- **永居或入籍路径：** 不自动转国籍；普通归化一般须申请前10年连续合法居住，通过语言、历史和法律考试，并有工作、房产、经营或企业股份等联系
- **税务提示：** 居留许可不单独决定税籍；在以该税年结束的任意连续12个月内实际停留183天或以上，通常构成该整个税年的格鲁吉亚税务居民；特殊规则及收入来源另行判断。
- **关键限制与变化：** 须独立估值和产权核验；短期房产居留不是永居
- **证据等级：** A
- **主要来源：** [国家服务机构居留规则](https://sda.gov.ge/en/products/migration-residence-permits/)；[外国人法Article15/16](https://www.matsne.gov.ge/en/document/view/2278806)；[劳动移民法现行格鲁吉亚文](https://matsne.gov.ge/ka/document/view/2806732)；[普通归化](https://sda.gov.ge/en/products/citizenship/)；[税法Article34](https://matsne.gov.ge/en/document/view/1043717)

## Investment Residence Permit

- **当前状态：** 开放
- **申请者身份限制：** 须以外国投资者身份满足投资及登记条件；不能仅因拥有其他国家居留或已免签入境便认定可在境内获批投资居留。特别国籍限制及当前入境身份的转换规则仍待补齐。
- **最低门槛或收入：** 企业投资≥US$300,000；非农业房地产市值>US$300,000。企业路线须达到营业额：第1年≥US$50,000、第2年≥US$100,000、第3至5年每年≥US$120,000（均折合GEL）
- **资金或收入性质：** 房地产或企业投资
- **首次身份与期限：** 5年投资居留；持续合规后可申请无限期居留
- **居住与续签：** 企业路线每年期满前提交税务机关营业额证明；房产路线持续持有，置换须在原产权终止前申报同等或更高价值替代房产
- **当地工作：** 持有效投资居留者属于劳动移民法Article1(4)的豁免类别；仍须遵守行业、企业及一般劳动规则
- **家属：** 配偶、未成年子女及特定受养人
- **永居或入籍路径：** 资产/经营持续5年后可申请无限期居留；归化仍需实际居住
- **税务提示：** 居留许可不单独决定税籍；在以该税年结束的任意连续12个月内实际停留183天或以上，通常构成该整个税年的格鲁吉亚税务居民；特殊规则及收入来源另行判断。
- **关键限制与变化：** 企业路线有逐年营业额要求；非低成本被动入籍
- **证据等级：** A
- **主要来源：** [国家服务机构居留规则](https://sda.gov.ge/en/products/migration-residence-permits/)；[外国人法Article15/16](https://www.matsne.gov.ge/en/document/view/2278806)；[劳动移民法现行格鲁吉亚文](https://matsne.gov.ge/ka/document/view/2806732)；[普通归化](https://sda.gov.ge/en/products/citizenship/)；[税法Article34](https://matsne.gov.ge/en/document/view/1043717)
