# 格鲁吉亚

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Short-Term Residence Permit (property)

- **当前状态：** 开放
- **最低门槛或收入：** 非农业房地产市值>US$150,000
- **资金或收入性质：** 房地产持续持有
- **首次身份与期限：** 通常1年，可续
- **居住与续签：** 官方项目页未列统一年度最低天数
- **当地工作：** 依一般规则
- **家属：** 配偶及子女可随行
- **永居或入籍路径：** 不自动转国籍；普通归化需长期真实居住及考试
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 须独立估值和产权核验；短期房产居留不是永居
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://sda.gov.ge/en/products/migration-residence-permits/)
- **本条核验日期：** 2026-09-02

## Investment Residence Permit

- **当前状态：** 开放
- **最低门槛或收入：** 投资或房地产>US$300,000；经营投资还须逐年达到营业额门槛
- **资金或收入性质：** 房地产或企业投资
- **首次身份与期限：** 5年投资居留；持续合规后可申请无限期居留
- **居住与续签：** 保持资产/经营；营业额门槛适用
- **当地工作：** 可经营批准企业
- **家属：** 配偶、未成年子女及特定受养人
- **永居或入籍路径：** 资产/经营持续5年后可申请无限期居留；归化仍需实际居住
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 企业路线有逐年营业额要求；非低成本被动入籍
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://sda.gov.ge/en/products/migration-residence-permits/)
- **本条核验日期：** 2026-09-02
