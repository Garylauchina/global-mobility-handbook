# 中国香港

[返回“投资居留”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## New Capital Investment Entrant Scheme

- **当前状态：** 开放
- **申请者身份限制：** 须年满18岁，并属于外国国民、中国籍且已取得外国永久居民资格者、澳门居民或台湾华籍居民。外国国民范围排除阿富汗、古巴、朝鲜；无国籍人须有外国永居及可返回该国的证明。中国内地申请人仅有外国临时签证／居留不满足“外国永久居民”条件；不能将所有中国籍申请人均套入同一分支。
- **最低门槛或收入：** 申请净资产审查前6个月持续拥有净资产HK$30m；投资HK$30m，其中HK$27m合资格资产及HK$3m CIES投资组合
- **资金或收入性质：** 金融资产、非住宅/有限额房地产及指定组合
- **首次身份与期限：** 首次2年，再3+3年
- **居住与续签：** 持续符合投资组合维持规则及一般入境要求；通常居住7年与单纯持有投资7年须区分
- **当地工作：** 可工作/经商
- **家属：** 配偶或符合官方定义的婚姻／民事结合伴侣，以及未婚受养未满18岁子女
- **永居或入籍路径：** 连续通常居港不少于7年可申请永久居民；仅维持合资格投资7年但不符合通常居住要求者，可另申请无条件限制逗留，二者不是同一身份
- **税务提示：** 香港税制以来源地为主，但个人事实、业务和原税籍仍须另判。
- **关键限制与变化：** 申请者身份须按上述分支分别判断。2025-09-17起完成购入的住宅须为单一成交价至少HK$30m的物业，住宅最多计入HK$10m，全部房地产合计最多HK$15m；2026-03-01另修订合资格私人公司持有条件
- **证据等级：** A
- **主要来源：** [资格条件](https://www.newcies.gov.hk/en/eligibility-criteria/)；[2026-03-01修订计划规则](https://www.newcies.gov.hk/media/jvkfl4uq/scheme-rule-en.pdf)；[入境事务处](https://www.immd.gov.hk/eng/services/visas/newcies.html)；[官方问答](https://www.newcies.gov.hk/en/resources/faqs/)；[税务局来源地原则](https://www.ird.gov.hk/eng/tax/bus_pft.htm)

## 政策时间线

### 2025-09-17 — 住宅投资计入标准调整

- **公布与生效：** 现行计划规则对2025-09-17起完成的住宅购入适用新标准
- **变化摘要：** 单一住宅成交价须至少HK$30m，住宅最多计入HK$10m，房地产合计最多计入HK$15m；此前购入须按相应历史规则判断
- **官方依据：** [现行计划规则](https://www.newcies.gov.hk/media/jvkfl4uq/scheme-rule-en.pdf)
- **事件证据：** A
