# 中国香港

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## New Capital Investment Entrant Scheme

- **当前状态：** 开放
- **最低门槛或收入：** 净资产HK$30m；投资HK$30m，其中通常HK$27m合资格资产+HK$3m CIES组合
- **资金或收入性质：** 金融资产、非住宅/有限额房地产及指定组合
- **首次身份与期限：** 首次2年，再3+3年
- **居住与续签：** 续签无机械年度天数；永居须证明通常居住
- **当地工作：** 可工作/经商
- **家属：** 配偶、未婚未满18岁子女
- **永居或入籍路径：** 通常居港7年可申请永久居民
- **税务提示：** 香港税制以来源地为主，但个人事实、业务和原税籍仍须另判。
- **关键限制与变化：** 房地产有物业价值/计入上限；资产种类和托管规则严格
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.newcies.gov.hk/en/eligibility-criteria/)
- **本条核验日期：** 2026-09-02
