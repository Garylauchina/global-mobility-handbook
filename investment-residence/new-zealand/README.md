## Active Investor Plus Visa

- **当前状态：** 开放
- **最低门槛或收入：** Growth NZ$5m/3年；Balanced NZ$10m/5年
- **资金或收入性质：** Growth或Balanced合资格投资
- **首次身份与期限：** Resident Visa
- **居住与续签：** Growth住21天；Balanced住105天，可因追加Growth投资降至91/77/63天
- **当地工作：** 可工作/经商
- **家属：** 伴侣、受养子女
- **永居或入籍路径：** 完成投资期和检查点后可申请Permanent Resident Visa
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 投资类别、持有期和检查点规则2026仍有更新，须按当前操作手册
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.immigration.govt.nz/visas/active-investor-plus-visa/)
- **本条核验日期：** 2026-09-02
