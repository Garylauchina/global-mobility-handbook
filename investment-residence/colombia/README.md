# 哥伦比亚

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

> **待补证事项：** M投资者签证的具体受雇/经商许可范围在已打开官方项目及现行Article79中未明列，仍需签证附注或主管机关正式解释

## Migrant Visa — Investor

- **当前状态：** 开放
- **申请者身份限制：** 须为符合M类投资者要求的外国申请人并证明本人投资登记；该类别不能直接套用V类数字游民的免签护照白名单。所引M类页面未列完整国籍排除清单，普通签证拒签事由仍独立适用。
- **最低门槛或收入：** 本人名下房地产≥350 SMLMV；本人名下已登记外国直接投资须>650 SMLMV（均按申请时法定最低月工资计算）
- **资金或收入性质：** 房地产或经登记的外国直接投资
- **首次身份与期限：** M签证最长3年，可续
- **居住与续签：** 须持续持有投资，续申请证明整个上一签证期间均维持；自签发日起每365天期间连续离境超过180天，M签证自动失效
- **当地工作：** 官方M投资者条款未明确授予开放工作权；须核实所签发签证的工作附注及主管机关许可，不能套用M公司股东或R签证的权限
- **家属：** 可为经济依赖的配偶/永久伴侣、未满25岁子女及符合规定的残疾成年子女申请受益人签证；家属签证不准工作，期限不超过主签证
- **永居或入籍路径：** M投资者有效身份累计至少5年可申请R；前后签证须在到期前衔接，临时通行证明不构成连续累计，满年限不保证获批；入籍另行审查
- **税务提示：** 签证与税籍分别判断；任意连续365天在境内累计超过183天（含出入境日）可成为税务居民；跨两个税年时从第二年起认定，哥伦比亚国民另有家庭及资产等标准。
- **关键限制与变化：** 须提交央行外汇系统投资记录、前3个月银行流水及全期间医疗保险；房地产须本人单独持有；任何影响投资的变化须立即向签证部门申报
- **证据等级：** B
- **主要来源：** [M投资者官方页](https://www.cancilleria.gov.co/node/26979)；[M签证离境规则](https://www.cancilleria.gov.co/node/26933)；[Resolution5477现行汇编](https://www.cancilleria.gov.co/normograma/compilacion/docs/resolucion_minrelaciones_5477_2022.htm)；[DIAN税务居民说明](https://micrositios.dian.gov.co/renta-personas-naturales-ag-2025/todo-lo-que-usted-debe-saber-sobre-renta/)
