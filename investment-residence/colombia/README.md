> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Migrant Visa — Investor

- **当前状态：** 开放
- **最低门槛或收入：** 房地产≥350 SMLMV；外国直接投资≥650 SMLMV（均为动态公式）
- **资金或收入性质：** 房地产或经登记的外国直接投资
- **首次身份与期限：** M签证最长3年，可续
- **居住与续签：** 投资必须持续存在；长期身份看实际连续停留
- **当地工作：** 依M签证权限
- **家属：** 可带受益家属
- **永居或入籍路径：** M类累计5年通常可申请R居民签证
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** SMLMV每年更新；投资登记和持续性是核心
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.cancilleria.gov.co/node/26979)
- **本条核验日期：** 2026-09-02
