## Permanent Investor Residence Permit / Golden Visa

- **当前状态：** 开放
- **最低门槛或收入：** 重点地区房产€800k；其他地区€400k；商改住或保护建筑€250k；普通路线通常单套且≥120㎡
- **资金或收入性质：** 房地产；须持续持有；短租受限
- **首次身份与期限：** 5年投资者居留，可续
- **居住与续签：** 维持卡通常无年度最低停留
- **当地工作：** 通常不赋予受雇工作权；可持股/投资
- **家属：** 配偶、子女及双方父母
- **永居或入籍路径：** 入籍通常需7年真实通常居住及融入；零居住持卡不足
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** €250k特殊路线必须有真实商改住/历史建筑证据；营销价格不能替代法律资格
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://migration.gov.gr/en/golden-visa/)
- **本条核验日期：** 2026-09-02
