# 斯里兰卡

[返回“投资居留”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

> **待补证事项：** 自由受雇与无关业务工作权、受养人完整定义仍缺；8June税务通知正文当前无法取得

## Investor Visa Category

- **当前状态：** 开放
- **申请者身份限制：** 【部分待核实】官方Investor Visa类别面向外国投资者及合资格配偶、受养人；须符合允许的投资活动。公开类别说明未列完整国籍排除名单；行业投资限制不能与本人国籍资格混为一谈。
- **最低门槛或收入：** US$100,000对应5年档；US$200,000对应总计10年档。主申请人、配偶和每名受养人的政府费均为每人每年US$200
- **资金或收入性质：** 资金须经持牌银行的Inward Investment Account进入Visa Programme Foreign Currency Account，再投向合资格股权、在斯经营的境外公司、至少5年期政府／央行债务、定期存款或依法允许的不动产；部分股权路线要求至少10%表决权
- **首次身份与期限：** 两档初次签注均为5年；US$200,000档另获正式函件，用于再延长5年，不是一次签发10年有效签注
- **居住与续签：** 须持续合规维持投资，每2年接受投资复核，重大变化须在2个月内书面报告；当前指南未公布统一最低实际居住天数，不应据此推定绝对零居住要求
- **当地工作：** 可管理获批投资；公开官方指南没有正向确认可自由受雇或经营与获批投资无关的业务，其他活动须另行核实授权
- **家属：** 配偶及受养人可随行并按人缴费；当前指南没有完整公开受养人的年龄和经济依赖边界
- **永居或入籍路径：** 本项目没有承诺自动转永久居民或国籍；通用长期身份路径须另按届时法律专题核实
- **税务提示：** 2026年税法规定，持Investor Category Residence Visa者在相应课税年度不视为斯里兰卡税务居民，规则追溯自2025-04-01适用；斯里兰卡来源所得及相关交易仍可能产生纳税义务
- **关键限制与变化：** 投资行业受外资禁止、比例上限或特别审批规则约束；旧Golden Paradise页面仍在线但不能替代当前Investor Visa Category指南，工作权和受养人定义仍有公开信息缺口
- **证据等级：** B
- **主要来源：** [移民局项目页](https://www.immigration.gov.lk/pages_t.php?id=67)；[官方Investor Visa指南](https://www.immigration.gov.lk/content/files/visa/Guideline%20Investor%20Visa%20Category%20doc%202.pdf)；[2026年第11号所得税修正法](https://www.ird.gov.lk/en/publications/Acts_Income%20Tax_2017/IR_Act_No_11-2026_E.pdf)

## 政策时间线

### 2026-06-03 — 投资者签证专门税务非居民规则立法

- **公布与生效：** 修正法于2026-06-03认证；税务机关2026-06-08通知确认该规则追溯自2025-04-01适用
- **变化摘要：** Investor Category Residence Visa持有人在相应课税年度不按通常规则视为斯里兰卡税务居民；非居民仍须就斯里兰卡来源所得承担相应义务
- **过渡安排：** 法律采用追溯适用日，个案申报、已纳税款和交易结构须向税务机关或专业人士核实
- **官方依据：** [修正法](https://www.ird.gov.lk/en/publications/Acts_Income%20Tax_2017/IR_Act_No_11-2026_E.pdf)；[税务机关通知SEC/PN/IT/2026/02](https://www.ird.gov.lk/en/Lists/Latest%20News%20%20Notices/Attachments/793/SEC_PN_IT_2026-02_E.pdf)
- **事件证据：** A
