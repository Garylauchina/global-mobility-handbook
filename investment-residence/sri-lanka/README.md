# 斯里兰卡

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Investor Visa Category

- **当前状态：** 开放
- **最低门槛或收入：** US$100,000/5年或US$200,000/10年
- **资金或收入性质：** 股权、债券、定存、房产等经指定账户投资
- **首次身份与期限：** 5年或10年
- **居住与续签：** 持续维持投资
- **当地工作：** 依签证许可
- **家属：** 配偶及受养人
- **永居或入籍路径：** 不自动转PR或入籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 资产必须经指定账户和主管机关认可
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.immigration.gov.lk/pages_t.php?id=67)
- **本条核验日期：** 2026-09-02
