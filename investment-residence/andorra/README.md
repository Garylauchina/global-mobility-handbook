# 安道尔

[返回“投资居留”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Residència sense treball

- **当前状态：** 开放/有配额；2026-03-11公布的新一批无营利居留配额为163个，实际剩余名额须向移民部门确认
- **申请者身份限制：** 【部分待核实】2026修法可确认非工作居留的投资变化，但不能单独证明完整国籍与现有身份适用范围；外国居留、国籍及此前已递交安道尔申请的过渡资格须分开判断。递交时间决定的旧制资格不是某一国籍的永久优惠。
- **最低门槛或收入：** 一般须持续投资安道尔合资格资产至少€1m；依法直接或间接投资住房基金（Fons d’Habitatge）的特别门槛为€400k。另须支付主申请人€50,000、每名受养人€12,000的不可退还款（初次许可被拒除外）；年收入须高于当年最低年工资300%，每名受养人另加100%
- **资金或收入性质：** 合资格房产、公司资本、政府债务、保险等资产；投资当地实体债务/金融工具或安道尔法集合投资基金最多计入36个月，之后须转入其他合资格资产；每套购入房产须投入超过€800k
- **首次身份与期限：** 一般2年→2年→3年→其后10年；适用双边协定的国籍可能采用不同续签期限
- **居住与续签：** 每年至少90天主要及实际居住，持续维持投资、收入、住所和保险；投资一般须在申请承诺后6个月内落实，因不可抗力或第三人原因可依法延长最多6个月
- **当地工作：** 不得在安道尔从事劳动或职业活动；被动持有资产不等于取得经营或就业许可
- **家属：** 配偶及符合条件受养人
- **永居或入籍路径：** 普通归化须累计20年主要及永久居住，并包括申请前至少5年主要及实际居住、融入等条件；须按国籍法程序证明已失去原有国籍，非投资自动取得
- **税务提示：** 居留许可与税务居民须分开判断；每自然年在安道尔超过183天，或主要经济活动/利益中心在安道尔，均可能构成税务居民，仍须结合适用税收协定。
- **关键限制与变化：** Llei 2/2026自2026-02-13生效，将一般投资由€600k提高至€1m并改为不可退还的入款；在2026-01-22法律通过前已提交的相关居留申请适用旧规则。部分旧办事页仍显示€600k及旧押金，不能据此递交新申请
- **证据等级：** A
- **主要来源：** [现行投资条款与过渡规则](https://www.portaljuridicandorra.ad/L2026002)；[公布及生效记录](https://portaljuridicandorra.ad/L2026002_F)；[2026年配额公告](https://www.govern.ad/ca/w/el-govern-acorda-reduir-les-quotes-d-immigracio-per-afavorir-el-creixement-sostenible-i-controlat-de-la-poblacio)；[初始许可办事页（部分金额未更新）](https://www.e-tramits.ad/tramits/ca/d1-residencia-sense-treball-autoritzacio-inicial/p/GV001309)；[国籍法汇编](https://www.portaljuridicandorra.ad/L19951005A)；[IRPF税务居民](https://www.e-tramits.ad/tramits/impostos/irpf)

## 政策时间线

### 2026-02-13 — 一般投资门槛提高并改为不可退还入款

- **公布与生效：** Llei 2/2026于2026-01-22通过、2026-02-12公布、2026-02-13生效
- **变化摘要：** 一般投资提高至€1m；主申请人€50,000及每名受养人€12,000改为不可退还款（初次许可被拒除外），住房基金特别门槛及合资格资产限制另见现行条款
- **过渡安排：** 2026-01-22通过前已提交的相关居留申请适用原规则，不论是否关联外国投资或配额预留
- **官方依据：** [Llei 2/2026](https://www.portaljuridicandorra.ad/L2026002)；[生效记录](https://portaljuridicandorra.ad/L2026002_F)
- **事件证据：** A
