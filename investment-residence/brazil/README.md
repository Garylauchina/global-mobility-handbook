## RN 36 Real Estate Investment Residence

- **当前状态：** 开放
- **申请者身份限制：** 【部分待核实】RN36针对以自有境外资金投资房地产的外国自然人；须证明本人投资和国际资金汇入。所引专项法条未列项目国籍白名单；企业持有房产、外国永居或一般免签入境均不自动等于本人获批投资居留。
- **最低门槛或收入：** 通常房产R$1m；北部/东北部可降至R$700,000
- **资金或收入性质：** 自有境外资金购入已建成或在建城市房地产，可合并多套达到门槛；共有时每名投资人均须满足最低投资额
- **首次身份与期限：** 初始4年
- **居住与续签：** 自向联邦警察登记起，每2年至少在巴西14天（可连续或累计），并持续维持投资；失去投资基础可导致居留权被撤销
- **当地工作：** 可按居留规则工作/经商
- **家属：** 家属可家庭团聚
- **永居或入籍路径：** 满足投资和居住可转无固定期限居留；归化另按一般规则
- **税务提示：** 临时居留、永久身份、受雇及实际停留对税籍的影响分别判断；临时入境者在任意不超过12个月内累计184天，或此前取得永久签证/受雇关系，可能较早成为税务居民。
- **关键限制与变化：** 已建成物业须提供无负担产权登记及认可金融机构的跨境汇款证明；在建物业另需已登记购房承诺、建造许可和开发登记；只有超过法定最低投资额部分可融资
- **证据等级：** A
- **主要来源：** [RN36/2018及2021修订](https://www.gov.br/mj/pt-br/assuntos/seus-direitos/migracoes/portal-de-imigracao-laboral/navegacao-guiada-1/possui-autorizacao-de-residencia/o-que-deseja/qual-a-finalidade-desejada-1/investidor-pessoa-fisica/rn-36-2018)；[司法部家庭团聚](https://www.gov.br/mj/pt-br/assuntos/seus-direitos/migracoes/autorizacao-de-residencia)；[劳动部移民工作说明](https://www.gov.br/trabalho-e-emprego/pt-br/acesso-a-informacao/acoes-e-programas/programas-projetos-acoes-obras-e-atividades/proteja/duvidas-frequentes)；[税务局居民规则](https://www.gov.br/receitafederal/pt-br/assuntos/meu-imposto-de-renda/preenchimento/dsdp/nao-residente)
