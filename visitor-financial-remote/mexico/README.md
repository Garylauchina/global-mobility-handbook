## Temporary Resident Visa — economic solvency

- **当前状态：** 开放/领馆差异
- **最低门槛或收入：** 按UMA公式；2026部分领馆示例约月收入US$3,064或12月平均存款约US$75,950
- **资金或收入性质：** 境外收入或存款
- **首次身份与期限：** 临时居民最多4年
- **居住与续签：** 满4年通常可转永久居民
- **当地工作：** 境外支付远程工作通常可行；本地雇佣需许可
- **家属：** 可家庭团聚
- **永居或入籍路径：** 4年后通常可转永久居民；入籍需实际居住
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 各领馆金额和计算期不同，必须按递交领馆确认
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://www.miconsulado.sre.gob.mx/visasmexicanas/visa/visa-de-residencia-temporal/)
- **本条核验日期：** 2026-09-02
