## Temporary Resident Visa — economic solvency

- **当前状态：** 开放/领馆差异
- **申请者身份限制：** 【部分待核实】这是外国申请人的经济能力临时居民签证，须使用受理领馆的现行财力及辖区规则；领馆要求在第三国合法居住时，该要求不等于项目统一要求先获第三国永久居留。现有来源未确认完整国籍及境内身份转换例外。
- **最低门槛或收入：** 按实际受理领馆及当年清单判断；例如圣迭戈总领馆2026年要求最近12个月每月平均投资/储蓄余额US$75,950，或最近6个月每月就业/养老金收入US$4,510。不是全国统一美元标准
- **资金或收入性质：** 境外收入或存款
- **首次身份与期限：** 临时居民最多4年
- **居住与续签：** 须按临时居留程序办理及续期；持临时居民许可满4年可向INM申请变更为永久居民，须持有效卡及提交申请，不是届满自动转永居
- **当地工作：** 圣迭戈财力路线接受境外雇佣远程工作，其雇主信须明确同意申请人在墨西哥居住并远程工作；本地雇佣仍须相应许可，不能据此外推所有经营活动均获准
- **家属：** 可家庭团聚
- **永居或入籍路径：** 满4年可申请转永久居民；普通归化通常须申请前5年持合资格临时或永久居留且实际居住，并核查离境、语言、历史及品行；学生临时居民年限不计入该归化居住要求
- **税务提示：** 《联邦税法典》第9条以墨西哥住房判断个人税务居民；两国均有住房时看重大利益中心，包括超过50%年度总收入来源于墨西哥或主要职业活动中心在墨西哥。不能仅凭远程雇主在境外或居留卡类别断言免税
- **关键限制与变化：** 各领馆金额和计算期不同，必须按递交领馆确认
- **证据等级：** B
- **主要来源：** [SRE临时居民签证](https://www.miconsulado.sre.gob.mx/visasmexicanas/visa/visa-de-residencia-temporal/)；[圣迭戈2026财力清单](https://consulmex.sre.gob.mx/sandiego/images/visasespanol2026/5a_Temporal_-_Solvencia_economica.pdf)；[INM满4年转永久居民](https://www.inm.gob.mx/static/Tramites/cambio_residente_temporal-residente_permanente.pdf)；[SRE普通归化](https://sre.gob.mx/carta-de-naturalizacion-por-residencia)；[现行联邦税法典第9条](https://www.diputados.gob.mx/LeyesBiblio/pdf/CFF.pdf)
