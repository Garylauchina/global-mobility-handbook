# 新加坡：中小学留学

[返回“新加坡留学”](../README.md) · [返回“留学与学生居留”](../../README.md) · [返回仓库首页](../../../README.md)

> 本页覆盖外国学生在新加坡政府、政府资助、独立中小学，以及 ICA 所称 Foreign System Schools／Privately-Funded Schools 就读全日制课程时的 Student’s Pass 与衔接规则，不覆盖幼儿园、托儿中心、学校排名、学校目录、录取概率、补习、寄宿或监护服务推荐。MOE 学位、学校录取、ICA Student’s Pass、陪读家长 LTVP、学生工作和永久居民分别审批。

## 中小学 Student’s Pass 路线

- **当前状态：** 开放；获政府、政府资助或独立学校，或符合 ICA 当前条件的 Foreign System School／Privately-Funded School 全日制录取后，可按实际学校类别申请 Student’s Pass。持有效 Dependant’s Pass、LTVP 或 Immigration Exemption Order 的学生，通常可在现有身份有效期内就读全日制非宗教课程而免办 Student’s Pass；获准宗教学校适用 ICA 明列的不同例外，不能从普通学校规则推定。
- **适用对象与核心资格：** 已取得相应学校全日制录取、能提交 Registration Acknowledgement Letter 和真实完整资料，并持续满足学校及 ICA 条件的外国中小学生。政府体系录取与外国体系／私立学校录取入口不同；“国际学校”或“私立学校”的宣传名称不能代替 ICA 对 Government、FSS、Privately-Funded School 或 PEI 的实际分类。非全日制、晚间或周末课程不适用普通 Student’s Pass。
- **录取与院校要求：** 新加坡公立主流学校的小一国际学生须按 MOE 当年独立的两步流程进入 Phase 3；小二至小五、中一至中三通常通过年度 Admissions Exercise for International Students（AEIS），补充轮次 S-AEIS 的开放年级和时间以当年页面为准。申请人须按年龄选择对应测试；小学申请人在递交 AEIS／S-AEIS 前还须参加规定的 Cambridge English Qualifications（CEQ）测试、达到当届最低成绩并上传成绩单，中学申请不适用该项前置成绩。AEIS 成绩不保证学额，分配还受学校空位和申报住址影响。FSS／Privately-Funded School 由学校自行录取；ICA 当前说明，向外国学生提供入学名额的受监管 FSS 必须具备适用的 EduTrust 认证。任何学校录取都不等于 ICA 必须签发 Student’s Pass。
- **资金证明：** ICA 申请要求提供 financial support 资料，但政府学校与 FSS 页面未公布统一的全国最低生活费或存款数字。MOE 政府体系月费按学生国籍和学校类型变化，独立学校、FSS、住宿、保险、校服、交通和其他费用另按学校规则；应使用 MOE 当前费用工具和正式录取文件分别核对。2026 AEIS 的不可退费用为小学 S$340、中学 S$630，另加现行 GST；S-AEIS 也收取不可退费用，金额须按当届页面刷新。Student’s Pass 当前处理费为 S$45，获批后签发费 S$60，适用时另收 S$30 Multiple Journey Visa 费；这些考试和行政费不是完整就读成本或财力标准。
- **首次许可与期限：** 政府／政府资助／独立学校以及 FSS／Privately-Funded School 的新申请通常须在线于开课前至少 2 个月且不超过 3 个月递交。就读政府、政府资助或独立学校时另须一名年满 21 岁的新加坡公民或 PR 作为 local sponsor；公司或机构不得担任，若有新加坡公民或 PR 父母／继父母则必须由其担任。ICA 明确 local sponsor 只适用于政府类学校和 ITE，并非所有 FSS 学生的统一要求。外出生且申请时不满或等于 12 周岁的儿童还须按要求向主管机关提交疫苗资料。获批后先取得 IPA，满足入境和签发条件才取得数字 Student’s Pass；有效期以实际签发文件为准。
- **续签与学籍变化：** 应按学校和 ICA e-Service 的期限，在现有 Student’s Pass 到期及下一学段开始前办理续期或转学。持有人须持续在获准学校注册并达到 Student’s Pass 条款要求的至少 90% 总出勤率；转到另一学校类别、学校或课程不能只凭新录取信推定身份自动延续。若申请已批准但尚未领取 Student’s Pass 时转校，ICA 要求重新申请。停止或终止学习时应在 7 日内取消 Student’s Pass，地址等资料变化须按 ICA 时限更新。
- **学习期间工作：** 中小学 Student’s Pass 不提供普遍工作权。MOM 的正式假期豁免只适用于年满 14 岁、持有效 Student’s Pass、全日制就读于其当前清单所列机构的学生；该假期清单包括政府／政府资助中学、部分独立和外国体系学校，但必须逐校核对。学期内适用更窄的另一张机构清单，并须每周最多 16 小时或参加计入毕业要求的学校实习；普通政府和政府资助中学虽列于假期清单，却未列于当前学期清单。小学生、未列学校、交换生或不合条件的实习不得据此工作。
- **家属：** Student’s Pass 不自动给父母、祖父母或兄弟姐妹身份。ICA 设有一条供“持 Student’s Pass 在新加坡就读儿童”的一名父母或祖父母申请 LTVP 的独立通道；只能一人申请，须由年满 21 岁的新加坡公民或 PR local sponsor 递交，并提供学校信和亲属关系材料，批准不是自动结果。该陪读 LTVP 不自带工作权，陪读父母在新加坡首年不得工作；满 1 年后如找到工作，雇主才可为其申请专门 Work Permit，申请时 LTVP 应至少剩余 4 个月，获批后计入雇主总配额、须缴 levy，并随 LTVP 失效而失效。MOM 当前只把这项满一年 Work Permit 路径写给陪读父母，不能直接扩大到陪读祖父母；祖父母如拟工作须按 MOM 个案确认并另行取得适当工作准证。ICA-LTVP Letter of Consent 只覆盖新加坡公民／PR 的配偶或未满 21 岁未婚子女，不适用于这类陪读亲属。
- **毕业后或升学路径：** 完成小学或中学不产生一般“毕业后工作签”。继续进入中学、Junior College、Millennia Institute、理工学院、大学或其他高等教育机构，须先按相应招生制度取得录取，再按 ICA 对实际机构类别的 Student’s Pass 流程办理新申请、续期或转换。学生工作豁免随有效 Student’s Pass、年龄、学校清单和学期／假期状态变化，不能延伸到毕业后。离校或不再注册时应取消 Student’s Pass。
- **永居或入籍边界：** 在新加坡上学或通过 AEIS 不自动取得 PR。ICA 当前允许已通过至少一项新加坡国家考试（PSLE、GCE N／O／A Level）或正在 IP 的在新加坡学生递交 PR 申请，但仍按家庭联系、资格、年龄、居留年限和融入等因素个案评估。学生成为 PR 后，公民申请还有独立条件；ICA 列明的在读 PR 学生类别通常要求在新加坡居住超过 3 年、其中至少 1 年为 PR，并通过列明国家考试或在 IP。以外国学生或父母担保取得 PR／公民身份的男性通常承担 National Service，且大学阶段一般不获延期，必须在申请长期身份前单独评估。
- **税务提示：** Student’s Pass、未成年身份和陪读 LTVP 都不等于税务居民或免税。IRAS 通常按个人在新加坡停留／工作的天数与连续年度规则判断税务居民；学生、父母和祖父母须分别计算。任何获准假期工作、实习、境外或本地收入及税收协定待遇均应独立核对，不能把移民许可或未成年身份当作税务结论。
- **关键限制与变化：** 2026 年 AEIS 申请截至核验日已经关闭，考试安排为 2026-09-01 至 2026-09-03；这是年度招生窗口，不代表路线关闭，下一轮须等待 MOE 更新。MOE 学额分配、ICA Student’s Pass 和陪读 LTVP 是三项独立决定。政府学校 local sponsor、FSS 的 EduTrust 条件、两张 MOM 工作院校清单、年度 AEIS／S-AEIS 年级与期限均会变化；学校接收、担任 local sponsor 或提供住宿也不等同法定监护、工作授权、长期居留或获批保证。
