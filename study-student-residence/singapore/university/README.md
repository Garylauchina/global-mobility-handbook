# 新加坡：大学留学

[返回“新加坡留学”](../README.md) · [返回“留学与学生居留”](../../README.md) · [返回仓库首页](../../../README.md)

> 本页只覆盖新加坡移民与关卡局（ICA）按 Institutes of Higher Learning（IHL）处理的全日制高等教育 Student’s Pass 路线，不提供院校排名、学校名录、录取概率、专业推荐或奖学金建议。录取、Student’s Pass、入境准许、学习期间工作、毕业后 LTVP、工作准证、永久居民和公民身份是不同决定。

## IHL Student’s Pass 路线

- **当前状态：** 开放；外国人获 ICA 当前 IHL 类别所列机构的全日制注册学籍或录取后，可申请 Student’s Pass。持有效 Dependant’s Pass、Long-Term Visit Pass（LTVP）或 Immigration Exemption Order 者，通常可在其现有身份有效期内就读全日制非宗教课程而免办 Student’s Pass；短期访问身份只在 ICA 列明的完整独立短课程条件内例外。
- **适用对象与核心资格：** 已获 ICA IHL 页面所覆盖机构的全日制 matriculated／registered student 身份，能提交真实完整资料并满足 In-Principle Approval（IPA）列明条件的外国学生。Student’s Pass 只适用于获准的全日制课程；非全日制、晚间或周末课程不合资格。交换生即使持 Student’s Pass，也不因此获得 MOM 的学生工作豁免。
- **录取与院校要求：** 院校录取与 ICA 批准分开。院校先在 Student’s Pass 系统登记申请人并出具 Registration Acknowledgement Letter，申请人再按该编号递交。ICA 的 IHL 分类当前覆盖其页面列明的本地大学、本地理工学院和部分境外院校新加坡校区；“大学”“学院”或学位课程的名称本身不能替代当前 ICA 分类。未列入 IHL 的机构可能适用 Private Education Institution 等不同入口、EduTrust 条件和审理流程，不能照搬本页。
- **资金证明：** ICA 的 IHL 申请页要求申报 financial support，并保留要求补充材料的权力，但未公布适用于所有 IHL 学生的统一最低存款或生活费数字。申请人应按录取文件分别覆盖学费、住宿、生活、交通、保险及学校要求；不得把 Student’s Pass 行政费当作完整财力门槛。当前申请处理费为 S$45；获批后 Student’s Pass 签发费为 S$60，适用时另有 S$30 Multiple Journey Visa 费，均应在递交时刷新。
- **首次许可与期限：** IHL 新申请须在线于开课前至少 2 个月且不超过 3 个月递交。ICA 公布的普通处理目标为 1 周，需要入境签证时为 2 周，但个案可更久。获批先取得 IPA；IPA 可能包含入境签证，但不保证获准入境或停留。申请人须持有效入境身份在新加坡完成 ICA 或学校安排的手续和生物识别，满足 IPA 条件后才获数字 Student’s Pass；实际有效期以签发文件所载日期和条件为准。
- **续签与学籍变化：** 持有人须在 Student’s Pass 有效期内持续在获准机构注册并达到 ICA 条款要求的至少 90% 总出勤率，按院校和 ICA e-Service 安排及时办理续期。更换院校、课程或身份不能只靠新录取信推定获准；申请已批准但尚未领取 Student’s Pass 时转校，ICA 明确要求重新申请。姓名、性别或住址等资料变化通常须在 14 日内通知并更新；停止或终止学习时应在 7 日内取消 Student’s Pass。
- **学习期间工作：** Student’s Pass 本身不提供普遍工作权。只有在 MOM 当前清单所列机构全日制注册并持有效 Student’s Pass 的学生，才可在学期内不另办工作准证每周最多工作 16 小时，或参加由院校安排、计入毕业要求的 industrial attachment／internship；额外休学实习不适用该豁免。符合 MOM 条件、年满 14 岁者可在正式学校假期工作而免办工作准证。交换生不适用，未列机构或超出条件者须先取得适当工作准证。
- **家属：** Student’s Pass 不产生配偶或子女的 Dependant’s Pass 资格。MOM 的普通 Dependant’s Pass 是符合条件的 Employment Pass 或 S Pass 等工作准证持有人家属路线，不是学生家属路线。配偶、子女或其他家庭成员如同行，须各自以访问、学习、工作或其他合资格身份申请；学生获准入学或取得 Student’s Pass 不代表其家属会获准长期居留或工作。
- **毕业后或升学路径：** 完成学业后应在 Student’s Pass 到期或终止时按规则取消，且 Student’s Pass 到期后不能继续依学生豁免工作；取消时可能获最长 89 天的 Short-Term Visit Pass，但不是保证，也不替代长期身份。ICA 允许其单独公布名单内的新加坡 IHL 毕业生申请 1 年、不可续期的“求职 LTVP”，申请材料包括学历证书和成绩单；这不是自动签发，当前一般处理目标为 6 周，申请费 S$45、签发费 S$60，适用时另收 S$30 Multiple Journey Visa 费，名单也不应从 Student’s Pass IHL 分类或院校宣传反推。该 LTVP 只是求职期间的访问身份，不自带工作权；实际受雇仍须由雇主申请并获批 Employment Pass、S Pass 或其他适当工作准证。
- **永居或入籍边界：** Student’s Pass、新加坡学位和毕业生求职 LTVP 均不直接产生永久居民（PR）或公民身份。ICA 的“在新加坡就读学生”PR 类别要求申请人通过至少一项列明的新加坡国家考试（PSLE、GCE N／O／A Level）或正在 Integrated Programme（IP），并非仅凭大学学历；没有该背景的毕业生通常须在日后取得合资格 Employment Pass／S Pass 等身份后，按相应类别另行申请。所有 PR 与公民申请均属个案评估。以外国学生或父母担保取得 PR 的男性可能承担 National Service；ICA 明确说明大学学习通常不获 NS 延期，可能影响在读安排。
- **税务提示：** Student’s Pass 与税务居民身份分开。IRAS 通常按外国人在一个日历年停留／工作至少 183 天、连续 3 年居留，或符合跨两个日历年连续受雇等规则判断个人税务居民；具体规则、税收协定和收入性质仍须分别核对。获准兼职或实习所得可能产生新加坡申报和纳税义务，不能因学生身份、工时豁免或 LTVP 自动视为免税。
- **关键限制与变化：** ICA 的 IHL 清单、MOM 可免工作准证院校清单和 ICA 毕业生求职 LTVP 院校清单用途不同，更新节奏也可能不同；出现在其中一张清单不代表自动出现在另两张。Student’s Pass 是学习居留许可，不等于入境保证、工作准证、医疗保障、家属身份或毕业后留新保证。费用、院校分类、工作豁免清单和毕业后入口均可能调整，应在申请、实习和毕业三个时点分别刷新。
