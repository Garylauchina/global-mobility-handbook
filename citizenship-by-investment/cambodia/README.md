# 柬埔寨

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Investment / donation naturalisation（2018 Nationality Law Arts. 21–22）

- **当前状态：** 法律机制有效/裁量制；统一公开收件入口与当前处理节奏待主管机关确认
- **最低门槛或收入：** 投资路线须以本人资本实际投入至少KHR4bn；捐款路线须以本人现金向国家预算或法定人道用途捐赠至少KHR12bn
- **资金或收入性质：** 投资须属于获准、合资格项目并证明合法来源和税务合规；捐款须经正式政府渠道，属于不可返还款项
- **首次身份与期限：** 王室法令批准后取得国籍
- **居住与续签：** 投资路线至少须有12个月合法居住，捐款路线至少6个月；品行、语言、健康和其他归化条件仍适用，不是无需赴柬的远程护照产品
- **当地工作：** 取得公民身份后依柬埔寨法律享有相应权利；归化申请阶段不因投资自动获得无限制工作权
- **家属：** 本轮未从现行公开官方材料完整重建统一随行或联名规则；不得承诺一笔投资或捐款使家属自动取得国籍
- **永居或入籍路径：** 这是由国家裁量并以王室法令完成的加速归化路径，不是缴费后自动签发的标准化CBI产品
- **税务提示：** 国籍不自动等于个人税务居民；实际居住、住所、收入来源和适用税法仍须另行判断
- **关键限制与变化：** 现行核心依据为2018年《国籍法》和第225号实施次法令；公开材料以高棉文扫描件为主，申请条件和审批具有裁量性，因此维持B级
- **证据等级：** B
- **主要来源：** [内政部2018年《国籍法》](https://web-storage.interior.gov.kh/storage/doc/1597337540.pdf)；[内政部第225号次法令](https://web-storage.interior.gov.kh/document/moi-20260122041042uumTBuZBOOfq.pdf)；[内政部法规目录](https://interior.gov.kh/law_and_regulation/8ROVZv2jy23R)
- **本条核验日期：** 2026-09-02

### 2026-09-02 — 资料更正：改用现行法律与实施门槛

- **公布与生效：** 第225号次法令文件日期为2025-12-01，政府于2026年1月公开；公开英文索引未提供可独立确认的另行生效日
- **变化摘要：** 本站原页引用1996年旧法及KHR1.25bn/KHR1bn数字；现按2018年《国籍法》第21—22条及第225号次法令，改为投资至少KHR4bn、合法居住至少12个月，或捐款至少KHR12bn、合法居住至少6个月
- **过渡安排：** 这是本站资料更正，不把旧页数字的替换日期推定为柬埔寨政策生效日；存量个案须向主管机关核实
