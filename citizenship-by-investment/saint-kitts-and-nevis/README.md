# 圣基茨和尼维斯

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Citizenship by Investment

- **当前状态：** 开放
- **最低门槛或收入：** SISC或公共利益选项US$250,000；认可开发项目US$325,000；私人住宅US$600,000
- **资金或收入性质：** 捐款不可退；房地产通常锁定7年
- **首次身份与期限：** 批准后直接公民身份
- **居住与续签：** 无最低实体居住
- **当地工作：** 成为公民后按当地法律
- **家属：** 配偶、符合条件子女及55岁以上父母
- **永居或入籍路径：** 直接入籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 强制面试；官方对推广、折扣和资金来源合规要求严格
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://ciu.gov.kn/cbi-options/)
- **本条核验日期：** 2026-09-02
