## Citizenship by Investment

- **当前状态：** 开放
- **最低门槛或收入：** NTF US$235,000（单人或最多4人）；认可项目US$270,000并另付政府款US$50,000
- **资金或收入性质：** 捐款不可退；认可项目投资按项目规则持有
- **首次身份与期限：** 批准后直接公民身份
- **居住与续签：** 无最低实体居住
- **当地工作：** 成为公民后按当地法律
- **家属：** 配偶、子女、父母等
- **永居或入籍路径：** 直接入籍；可另评估美国E-2，但并非自动获签
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 不得折扣；须核验获批项目、面试和资金来源
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://imagrenada.gd/citizenship-by-investment/)
- **本条核验日期：** 2026-09-02
