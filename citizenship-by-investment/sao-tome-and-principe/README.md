# 圣多美和普林西比

[返回“投资入籍”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

> **待补证事项：** 官方资格卡片与FAQ父母祖父母年龄分别18岁和55岁，需法律文本或主管机关确认。

## Citizenship by Investment Programme

- **当前状态：** 法律有效/新项目
- **申请者身份限制：** 【部分待核实】官方资格页要求主申请人至少18岁、无犯罪记录及通过身份和背景审查；同时提示可能有司法辖区、法律或政策限制，却未列完整受限国籍名单。因此不能认定“所有国籍均可”或自行写成“仅朝鲜不收”。见[官方资格页](https://cip.gov.st/eligibility-criteria)。
- **最低门槛或收入：** 国家转型基金：单人US$90,000；2–4人家庭US$95,000；每增1人US$5,000；另有申请、尽调和证件费
- **资金或收入性质：** 政府捐款不可退
- **首次身份与期限：** 批准后终身、可传承国籍
- **居住与续签：** 无实体居住要求
- **当地工作：** 成为公民后按当地法律
- **家属：** 配偶/事实伴侣、最高30岁子女；父母或祖父母的官网FAQ要求至少55岁，但同页资格卡片误列或另列18岁，尚有官方冲突，须按现行法与主管机关书面确认为准
- **永居或入籍路径：** 直接入籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 2025年生效，执行历史短；处理能力、依亲护照和多国籍限制仍在演变，须核验授权代理和最新规则
- **证据等级：** B
- **主要来源：** [官方项目说明](https://cip.gov.st/about-the-program)；[投资结构与费用](https://cip.gov.st/investment-structure)；[家属资格及FAQ](https://cip.gov.st/eligibility-criteria)
