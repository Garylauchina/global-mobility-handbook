## Economic and Climate Resilience Citizenship Program

- **当前状态：** 开放/限时优惠
- **最低门槛或收入：** 标准主申请人贡献US$115,000；官方2026-12-31前优惠US$90,000；另有申请、尽调和家属费
- **资金或收入性质：** 政府贡献不可退
- **首次身份与期限：** 批准后直接公民身份
- **居住与续签：** 无最低实体居住
- **当地工作：** 成为公民后按当地法律
- **家属：** 配偶、子女及其他合格家属
- **永居或入籍路径：** 直接入籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 优惠有明确截止日；递件前须再次确认官方费表与代理资格
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.ecrcp.gov.nr/)
- **本条核验日期：** 2026-09-02
