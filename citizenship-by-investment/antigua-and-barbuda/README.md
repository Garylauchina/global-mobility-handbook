# 安提瓜和巴布达

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Citizenship by Investment Programme

- **当前状态：** 开放
- **最低门槛或收入：** NDF捐款US$230,000；获批房产US$300,000；企业US$1.5m（联合项目总额US$5m且每人≥US$400k）
- **资金或收入性质：** 捐款不可退；房产通常持有5年；企业投资
- **首次身份与期限：** 批准后直接公民身份
- **居住与续签：** 首5个日历年累计至少居住5天
- **当地工作：** 成为公民后按当地法律；申请阶段不是工作签
- **家属：** 配偶、符合条件子女、55岁以上父母/祖父母等
- **永居或入籍路径：** 直接入籍；无自动税籍效果
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 须通过获批代理；严格资金/财富来源尽调、面试及受限国籍审查；另有政府、尽调和护照费
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://cip.gov.ag/citizenship/)
- **本条核验日期：** 2026-09-02
