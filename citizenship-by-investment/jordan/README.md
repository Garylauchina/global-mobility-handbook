# 约旦

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Investor Citizenship（2026新规）

- **当前状态：** 开放/裁量制
- **最低门槛或收入：** 证券JD1.5m持5年；新生产项目JD700k（安曼）或JD500k（外省）并创造就业；现有项目增资约JD1m并满足资产/就业条件
- **资金或收入性质：** 证券或生产性企业投资
- **首次身份与期限：** 部分路线先发3年临时护照，持续履约后提请公民身份
- **居住与续签：** 重点为持续投资、就业和资产限制
- **当地工作：** 成为公民后按当地法律
- **家属：** 配偶、受养女儿、未婚24岁以下儿子、受养父母等
- **永居或入籍路径：** 推荐/裁量制入籍，不是机械自动批准
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 2026刚调整；实施文件、就业数量和资产条件须逐案书面确认；违约可撤销
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://www.pm.gov.jo/AR/NewsDetails/am0847)
- **本条核验日期：** 2026-09-02
