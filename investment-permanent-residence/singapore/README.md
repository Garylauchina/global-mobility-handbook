## Global Investor Programme

- **当前状态：** 开放
- **最低门槛或收入：** A企业S$10m；B GIP基金S$25m；C家办AUM≥S$200m并在新加坡部署≥S$50m
- **资金或收入性质：** 企业、基金或单一家族办公室
- **首次身份与期限：** 获批为PR；再入境许可通常5年
- **居住与续签：** 续签看企业、就业及本人/家庭居住
- **当地工作：** PR可工作/经营
- **家属：** 配偶及未婚未满21岁子女；父母通常另办
- **永居或入籍路径：** 入籍完全酌情；男性子女可能承担国民服役
- **税务提示：** 成为新加坡税务居民与PR不是同一判断；家办和企业税务需专门设计。
- **关键限制与变化：** 申请人须有合格企业/投资背景；不是仅凭资金
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.edb.gov.sg/en/incentives-and-programmes/global-investor-programme.html)
- **本条核验日期：** 2026-09-02
