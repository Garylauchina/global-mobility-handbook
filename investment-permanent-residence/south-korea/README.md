# 韩国

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Immigrant Investor Scheme for Public Business

- **当前状态：** 开放
- **最低门槛或收入：** 一般KRW1.5bn；高额KRW3bn
- **资金或收入性质：** 可选择由韩国产业银行受托运营的本金保障、无息公共基金，或法务部长指定并登记、由投资者承担盈亏的开发项目
- **首次身份与期限：** 一般路线为可自由从事经济活动的F-2，具体获批期限以签发决定为准；高额路线可直接取得附“五年维持投资”条件的F-5
- **居住与续签：** 两条路线均须维持投资5年；当前项目页没有公布统一年度最低在韩天数，不应据此推定绝对零居住要求
- **当地工作：** 官方项目页明确F-2可自由从事经济活动；F-5为永久居民身份，具体受监管职业仍须满足行业规则
- **家属：** 当前韩文主管页列配偶及未婚子女；年龄、依赖性和个案材料未在该页完整公开，递件前须向主管机关确认
- **永居或入籍路径：** 一般路线维持投资5年以上后可申请F-5，并非只凭时间自动获批；高额路线提前取回投资可导致有条件F-5被撤销。投资不自动带来国籍，普通归化仍须满足居住、品行、生计、语言文化等条件
- **税务提示：** F-2/F-5不单独决定税籍；住所、职业、共同生活家属、在韩资产及183日等客观事实均须综合判断
- **关键限制与变化：** 无息基金存在显著机会成本，风险项目可能亏损；法务部英文项目页仍显示2023年前旧门槛和已废止退休路线，本页以现行韩文主管页及告示为准，并因此保留B级冲突提示
- **证据等级：** B
- **主要来源：** [法务部现行韩文项目页](https://www.moj.go.kr/moj/189/subview.do)；[法务部制度说明](https://www.moj.go.kr/immigration/1515/subview.do)；[韩国税务机关2026年居民判定解释](https://taxlaw.nts.go.kr/qt/USEQTA002P.do?ntstDcmId=200000000000021872)
- **本条核验日期：** 2026-09-02
