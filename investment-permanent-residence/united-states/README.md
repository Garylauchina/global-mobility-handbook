## EB-5 Immigrant Investor Program

- **当前状态：** 开放
- **最低门槛或收入：** TEA/基础设施US$800,000；其他地区US$1.05m；创造10个合格全职岗位
- **资金或收入性质：** 企业风险投资；资本须处于风险中
- **首次身份与期限：** 2年有条件永久居民
- **居住与续签：** 须实际维持美国永久居民身份
- **当地工作：** PR可工作/经商
- **家属：** 配偶、未婚未满21岁子女
- **永居或入籍路径：** 解除条件后继续PR；通常持LPR满5年并满足连续居住可申请入籍
- **税务提示：** 美国税务居民和全球所得规则可能在取得绿卡时即触发，须提前规划。
- **关键限制与变化：** 排期、项目证券合规、就业计算、资金路径和资本损失风险
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.uscis.gov/eb-5)
- **本条核验日期：** 2026-09-02
