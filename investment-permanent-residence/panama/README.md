# 巴拿马

[返回“投资永居”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

> **待补证事项：** 家属类别、普通归化五年及一般离境限制仍需补充现行直接依据。

## Qualified Investor

- **当前状态：** 开放
- **最低门槛或收入：** 合资格房地产或购房承诺合同B/.300,000；合资格证券B/.500,000；定期存款B/.750,000
- **资金或收入性质：** 房地产、证券或定存，按法规持有
- **首次身份与期限：** 可直接取得永久居留
- **居住与续签：** 合资格投资至少维持5年，按年证明持续投资；提前撤资且不作合规替代投资可能取消居留；归化需真实定居
- **当地工作：** 居留不替代工作许可；受雇或从事适用劳动活动须另向MITRADEL取得相应许可（合资格投资者属4B类）
- **家属：** 配偶及受养子女
- **永居或入籍路径：** 永久居留；通常实际定居5年后才可能一般归化
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 并非所有房地产/证券都合格；须经获准银行/券商和资金来源审查
- **证据等级：** B
- **主要来源：** [2020年第722号法令](https://www.migracion.gob.pa/wp-content/uploads/DECRETO_EJECUTIVO_722.pdf)；[2024年第193号修订法令](https://www.migracion.gob.pa/wp-content/uploads/DECRETO-EJECUTIVO-193-DE-15-DE-OCTUBRE-DE-2024-QUE-MODIIFICA-Y-ADICIONA-AL-DECRETO-172-DE-15-DE-OCTUBRE-DE-2020.pdf)；[MITRADEL工作许可分类](https://www.mitradel.gob.pa/empleo/migracion-laboral/)

## 政策时间线

### 2024-10-15 — 房地产门槛与购房承诺规则修订

- **公布与生效：** 第193号行政法令于2024-10-15公布并生效
- **变化摘要：** 房地产及合资格购房承诺合同最低额为B/.300,000；证券和定存分别为B/.500,000、B/.750,000。期房付款须符合信托或开发商完工银行担保等条件
- **过渡安排：** 不以旧法令曾列的B/.500,000房地产一般门槛代替修订后规定；既有申请的转换按法令处理
- **官方依据：** [第193号修订法令](https://www.migracion.gob.pa/wp-content/uploads/DECRETO-EJECUTIVO-193-DE-15-DE-OCTUBRE-DE-2024-QUE-MODIIFICA-Y-ADICIONA-AL-DECRETO-172-DE-15-DE-OCTUBRE-DE-2020.pdf)
- **事件证据：** A
