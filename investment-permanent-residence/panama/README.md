# 巴拿马

[返回“投资永居”目录](../README.md) · [返回仓库首页](../../README.md)

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Qualified Investor

- **当前状态：** 开放
- **最低门槛或收入：** 合资格投资B/.500,000；定期存款路线通常B/.750,000
- **资金或收入性质：** 房地产、证券或定存，按法规持有
- **首次身份与期限：** 可直接取得永久居留
- **居住与续签：** 投资维持规定期限；归化需真实定居
- **当地工作：** 可依法工作/经商
- **家属：** 配偶及受养子女
- **永居或入籍路径：** 永久居留；通常实际定居5年后才可能一般归化
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 并非所有房地产/证券都合格；须经获准银行/券商和资金来源审查
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.migracion.gob.pa/wp-content/uploads/DECRETO_EJECUTIVO_722.pdf)
- **本条核验日期：** 2026-09-02
