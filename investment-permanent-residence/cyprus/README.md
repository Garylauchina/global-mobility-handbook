## Immigration Permit for Investors

- **当前状态：** 开放
- **最低门槛或收入：** €300k新房/其他房产/塞浦路斯公司股本/合资格基金；年收入€50k，配偶+€15k，每未成年子女+€10k
- **资金或收入性质：** 房地产、股本或基金+境外稳定收入
- **首次身份与期限：** 永久居留；卡通常10年换发
- **居住与续签：** 批准后1年内入境；连续离境2年会失效
- **当地工作：** 依许可类别；非自动受雇工作权
- **家属：** 配偶、未成年子女；18–25岁学生等有附加条件
- **永居或入籍路径：** 普通入籍走实际居住路线
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 须维持投资、保险并周期更新无犯罪记录；不是国籍项目
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://www.gov.cy/mip-md/en/documents/companies-investors-permanent-residence-3/immigration-permits-for-investors/)
- **本条核验日期：** 2026-09-02
