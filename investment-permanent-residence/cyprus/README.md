# 塞浦路斯

> 本页只记录公开可核验的专项方案，不构成法律、税务、投资、房产或国籍意见。所有门槛均须在递件前向主管机关再次确认。

## Immigration Permit for Investors

- **当前状态：** 开放
- **申请者身份限制：** 待核实：现行移民部门投资永居页本次返回访问阻断，尚未完整确认当前特别国籍／关联限制及现有居留适用规则。不能据€300k门槛判断任何护照均可申请，也不能套用已关闭投资入籍项目的名单。
- **最低门槛或收入：** €300k新房（另加VAT）/其他合资格房产/当地实际运营且至少雇5人的公司股本/合资格基金；年收入€50k，配偶+€15k，每未成年子女+€10k
- **资金或收入性质：** 投资款须来自境外且完整可追踪；新住宅路线收入须来自境外，其他投资路线允许全部或部分收入来自塞浦路斯
- **首次身份与期限：** 永久居留；卡通常10年换发
- **居住与续签：** 居于境外的获批者及家属须在批准后1年内建立塞浦路斯居住；取得外国永久居留或离开塞浦路斯2年会使许可失效
- **当地工作：** 申请人与配偶原则上不得受雇，例外为所投公司董事；其他公司可持股取股息或任无薪董事
- **家属：** 配偶、未成年子女；未婚18–25岁境外高等教育学生须经济依赖、独立申请且每人另增€10k年收入。成年非受养子女须增加投资并各自满足收入条件
- **永居或入籍路径：** 普通入籍走实际居住路线
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 须按年证明投资及必要医疗保险持续有效；年收入年度证明要求已取消，无犯罪证明改为每3年更新。不是国籍项目
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://www.gov.cy/mip-md/en/documents/companies-investors-permanent-residence-3/immigration-permits-for-investors/)
