## Malta Permanent Residence Programme (MPRP)

- **当前状态：** 开放
- **最低门槛或收入：** 行政费€60k+政府贡献€37k+公益捐赠€2k；租房≥€14k/年或购房≥€375k；另需证明规定资产
- **资金或收入性质：** 费用不可退+房产/租赁+资产证明
- **首次身份与期限：** 永久居留权；卡按规则换发
- **居住与续签：** 无年度最低停留；房产和资产至少保持5年，之后仍须合适住所
- **当地工作：** 依身份及许可；不是自动工作权
- **家属：** 配偶、子女、父母/祖父母等
- **永居或入籍路径：** 不提供自动归化；不是投资入籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 持续尽调和资产审查；申根仍受90/180规则
- **证据等级：** A
- **主要来源：** [官方或主要依据](https://residencymalta.gov.mt/legal-framework-mprp-2/)
- **本条核验日期：** 2026-09-02
