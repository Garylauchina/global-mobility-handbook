## Financially Independent Permanent Residence

- **当前状态：** 开放/改革风险
- **最低门槛或收入：** 净资产ZAR12m；获批后承诺缴纳ZAR120k
- **资金或收入性质：** 财富证明+政府款；不要求实际部署投资
- **首次身份与期限：** 直接永久居留
- **居住与续签：** 须维持南非永久居民身份，不宜长期放弃居所
- **当地工作：** PR可工作/经商
- **家属：** 配偶及子女可关联申请
- **永居或入籍路径：** PR后归化仍需实际居住；不是CBI
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 2025改革草案拟替换制度但尚非现行法；递件前复核
- **证据等级：** B
- **主要来源：** [官方或主要依据](https://visa.vfsglobal.com/one-pager/dha/southafrica/english/index.html)
- **本条核验日期：** 2026-09-02
