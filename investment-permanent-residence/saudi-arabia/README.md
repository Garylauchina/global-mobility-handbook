# 沙特阿拉伯

## Premium Residency — Business Investor

- **当前状态：** 开放
- **申请者身份限制：** 须符合Business Investor本人持股份额、投资登记及经营证明条件，不能只看公司总投资额。项目门户本次未完整返回可读的一般身份规则，国籍限制、年龄及现有沙特身份的合法性要求仍须主管机关确认。
- **最低门槛或收入：** 本人持股份额对应企业投资至少SAR7m，并提供对应至少10名员工的社保证明及有效投资登记、商业登记和注资证明
- **资金或收入性质：** 生产性企业投资+就业
- **首次身份与期限：** 直接授予有条件永久Premium Residency
- **居住与续签：** 前2年须同时维持至少SAR7m投资和对应10名员工；一般撤销条件仍适用
- **当地工作：** 可在私营部门工作及更换雇主，排除沙特公民专属职业；经商及资产持有遵守投资等法律
- **家属：** 配偶、未满25岁子女及不在沙特工作的父母
- **永居或入籍路径：** 长期/永久身份但不等于国籍
- **税务提示：** 身份本身不等于税务居民；通常还要按实际天数、住所/利益中心、税收协定及收入来源单独判断。
- **关键限制与变化：** 前2年投资或员工人数不达标、或触及一般撤销事由，可失去身份；永久居留不赋予国籍申请资格
- **证据等级：** A
- **主要来源：** [Premium Residency现行企业投资者详情](https://pr.gov.sa/pr?id=pr_product_details_investor_residency)；[主管中心FAQ](https://pr.gov.sa/pr?id=faqs)；[实施细则](https://pr.gov.sa/pr?id=conditions_controls)
