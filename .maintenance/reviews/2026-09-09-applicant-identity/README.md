# 申请者身份专项核查 — 2026-09-09

本轮逐项检查173个政策页面、181个方案块的申请者身份表述；基于分支起点`0884d56`，只补国籍／旅行证件、外国永久居民、现居地、原有签证／居留、年龄／职业及相关人员角色。未执行另一轮全库全部核心政策复核，也未修改首页基准、`.maintenance/review-state.json`或同日先前的全内容核查记录。

## 结果及边界

- 64个方案块：所写身份条件已有对应官方依据。这个数量不是“64个项目向全部国籍开放”，也不是全部个案资格已核实。
- 80个方案块：已有部分身份或程序依据，但仍有明确的特别国籍、当前版本、既有身份或执行细节缺口。
- 7个方案块：尚未取得足以确认当前申请者身份范围的官方正文。
- 30个方案块：历史、停办、暂停或未能确认可新递交，不依据旧身份条件判断现在可办。

80项局部缺口与7项核心缺口已在对应方案的“申请者身份限制”字段开头分别加上**【部分待核实】**、**【核心证据缺口】**，共涉及84个公开政策页面；具体未决说明继续保留，标签与JSON逐项同步。标签含义见[研究方法](../../../METHODOLOGY.md#申请者身份限制)。这次显式标注不改变核查结论、证据等级、政策状态或全库复核基准。

逐页、逐方案的结论、参考链接和具体未决事项见[audit.json](./audit.json)。`references`保留身份字段新引用及原方案来源，方便追溯；不把网页可访问、表单国籍下拉项或搜索到一个链接当成资格已核实，也不宣称本次重读了所有原有来源的全部政策内容。当前正文访问失败后，尝试主管机关其他页面、法规或官方检索正文；只能取得旧版时在结论中保留版本限制。

## 主要修正

- 国籍与外国永居：香港New CIES的中国籍／澳门／台湾／外国人分支及无国籍人条件；伯利兹远程工作许可的指定国家公民或永久居民条件，与退休计划包含中国的国家范围分别处理。
- 国籍及既有身份：日本、捷克、吉尔吉斯斯坦、土耳其数字游民名单；捷克申请前一年持有过长期签证／居留的排除；台湾、阿根廷及哥伦比亚的免签国籍或护照条件。
- 关联及名单版本：意大利投资签证俄白及非欧盟双重国籍暂停；加勒比CBI项目分别引用本项目限制，马耳他MPRP与Nomad名单不互相复制。未取得完整现行名单的不写成无限制。
- 角色和受理辖区：加拿大照管人、新加坡学校担保人、澳大利亚监护安排中的公民／PR要求不转写为学生资格；意大利／泰国驻美领馆的美国身份材料不转写为全球永居前提。
- 美国移民与学生：EB-5须考虑INA 212(a)(3)(D)及例外，F-1不直接适用同一党派成员条款；两者仍须分别考虑PP10998的类别、时间、所在地及双重国籍例外。
- MDEC担保：以2024-08-26后续公告修正旧FAQ的中国／孟加拉国银行担保方式；保留非科技扩展完整现行清单及其他执行缺口。

上述大部分是补齐已有政策的身份范围，不是宣称2026-09-09新生效。正式政策日期保留在方案文本和来源中。塞浦路斯投资永居因本轮身份核心证据不足、哥伦比亚数字游民因附条件免签适用待确认，由A降B；不据一次访问阻断宣布项目关闭。

## 台湾反馈后的关联名单补查

原台湾页及PR已有免签国籍前提，但未完整列出关联名单的证件、出生地和公民身份脚注。本次增加显著准入提示，并用2026年1月资格公告和4月修正要点及附表补齐法源、家属及不足6个月停留的延期边界。两份公报均明定自2026-01-01生效。

同时定向复查阿根廷、哥伦比亚和日本的相关条款：哥伦比亚的免签法还包含中国等国附条件及第三国永居情形，不能简单改写成单一国籍名单，现将其适用于数字游民的边界标为待确认。日本主名单PDF此次访问被阻断，仅确认外交部仍按项目名单指引，不计为整张名单再次核实。详细来源、访问结果和边界见[taiwan-linked-list-followup.json](./taiwan-linked-list-followup.json)。这次补查并未重新完整核实全库，当前汇总调整为64项documented、80项partial、7项gap、30项历史／暂不可递交。

## 验收

每个方案块均有单独身份字段，现行、留学与历史页面的字段计数纳入仓库校验；逐方案核查记录须与公开字段逐字匹配。执行仓库测试、结构／时效／导航检查、外部临时目录严格构建及中英文搜索校验，结果写入PR说明。构建和字段检查只验证交付完整性，不验证法律结论。
